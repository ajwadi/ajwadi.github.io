CATIA Component Renamer v4

Preview, rename, undo, English / Korean, and now a credit image centered at the bottom of the window. Three code blocks to paste: the form, the module and the button class.

New in v4

  • Credit image centered at the bottom. The image is stored inside the code as text, at the bottom of the Renamer module, so there is no image file to install and no wording typed into the code.
  • Everything else is the same as v3, including the fix for the "Type mismatch" error in the Korean text decoding.

Updating from v3

  1. Open the code of frmComponentRenamer, select all, delete, and paste block 1. Keep the form itself; only its code changes.
  2. Do the same in the Renamer module with block 2.
  3. Block 3, clsButtonHandler, has not changed. It is here so the page is complete.
  4. Debug, Compile, then run CATMain.

Names must match exactly: the form's (Name) is frmComponentRenamer, the module is Renamer, and the class module is clsButtonHandler.

Red lines near the top of Renamer are normal. The module holds two versions of a Windows declaration, and the editor colors the unused one red. It still compiles and runs.

First run: this version was written and reviewed but not run inside CATIA. Check that the image appears, and try Rename and then Undo on a copy of a small assembly before using it on real work.

Public Sub RunUndo()

    Dim csvFile As String
    Dim loaded As Boolean
    Dim errText As String

    If Not SelectDocument() Then
        Exit Sub
    End If

    '---------------------------------------
    'WHICH RENAME MAP?
    'The last rename done in this window, or a file you pick.
    '---------------------------------------

    csvFile = mLastCsv

    If csvFile = "" Then

        On Error Resume Next
        csvFile = CATIA.FileSelectionBox(T("undo_pick"), "*.csv", 0)   '0 = open
        On Error GoTo 0

        If csvFile = "" Then
            SetStatus T("st_ready")
            Exit Sub
        End If

    End If

    '---------------------------------------
    'BUILD THE REVERSE PLAN (reads only)
    '---------------------------------------

    On Error GoTo PlanError
    loaded = Renamer.BuildUndoPlan(mDoc.Product, csvFile)
    On Error GoTo 0

    FillList

    If Not loaded Then
        Renamer.ShowMessage T("undo_badfile", csvFile), vbExclamation
        SetStatus T("st_ready")
        Exit Sub
    End If

    ExecutePlan True
    Exit Sub

PlanError:

    errText = "Error " & CStr(Err.Number) & ": " & Err.Description
    On Error GoTo 0

    SetStatus T("st_error")
    Renamer.ShowMessage T("msg_read_error", errText), vbCritical

End Sub

'=========================================================
' CONFIRM, SAVE THE MAP, APPLY, REPORT
' Used by both Rename and Undo.
'=========================================================

Private Sub ExecutePlan(ByVal isUndo As Boolean)

    Dim partCount As Long
    Dim instCount As Long
    Dim confirmText As String
    Dim csvPath As String
    Dim errText As String
    Dim updateNote As String
    Dim summary As String
    Dim okCount As Long
    Dim failCount As Long
    Dim skipCount As Long

    partCount = Renamer.CountKind(KIND_PART)
    instCount = Renamer.CountKind(KIND_INST)

    If partCount + instCount = 0 Then

        If isUndo Then
            Renamer.ShowMessage T("undo_nomatch"), vbExclamation
        Else
            Renamer.ShowMessage T("msg_nothing"), vbInformation
        End If

        SetStatus T("st_nothing")
        Exit Sub

    End If

    '---------------------------------------
    'CONFIRM
    '---------------------------------------

    If isUndo Then
        confirmText = T("confirm_undo", mDoc.Name, partCount, instCount)
    Else
        confirmText = T("confirm_rename", mDoc.Name, partCount, instCount)
    End If

    If Renamer.ShowMessage(confirmText, vbYesNo + vbQuestion) <> vbYes Then
        SetStatus T("st_cancelled")
        Exit Sub
    End If

    '---------------------------------------
    'SAVE THE OLD-TO-NEW MAP BEFORE CHANGING ANYTHING
    '---------------------------------------

    csvPath = Renamer.SavePlanCsv(mDoc)

    If csvPath = "" Then

        If Renamer.ShowMessage(T("msg_csv_fail"), vbYesNo + vbExclamation) <> vbYes Then
            SetStatus T("st_cancelled")
            Exit Sub
        End If

    End If

    '---------------------------------------
    'APPLY
    '---------------------------------------

    SetBusy True

    If isUndo Then
        SetStatus T("st_undoing")
    Else
        SetStatus T("st_working")
    End If

    On Error Resume Next
    CATIA.RefreshDisplay = False
    On Error GoTo RenameError

    Renamer.ApplyPlan

Finish:

    '---------------------------------------
    'UPDATE AND REFRESH CATIA
    '---------------------------------------

    On Error Resume Next

    Err.Clear
    mDoc.Product.Update

    If Err.Number <> 0 Then
        updateNote = T("sum_update", Err.Description)
        Err.Clear
    End If

    CATIA.RefreshDisplay = True

    On Error GoTo 0

    '---------------------------------------
    'REPORT
    '---------------------------------------

    Renamer.UpdatePlanCsv
    FillList
    SetBusy False

    'After a rename, Undo uses this map. After an undo, it asks for a file.
    If isUndo Then
        mLastCsv = ""
    Else
        mLastCsv = csvPath
    End If

    okCount = Renamer.CountResults(RESULT_OK)
    failCount = Renamer.CountResults(RESULT_FAILED)
    skipCount = Renamer.CountResults(RESULT_SKIPPED)

    summary = T("sum_counts", okCount, failCount, skipCount)

    SetStatus T("st_done", summary)

    If csvPath <> "" Then
        summary = summary & vbCrLf & vbCrLf & T("sum_csv", csvPath)
    End If

    If updateNote <> "" Then
        summary = summary & vbCrLf & vbCrLf & updateNote
    End If

    If errText <> "" Then
        summary = summary & vbCrLf & vbCrLf & T("sum_stopped", errText)
    End If

    If failCount > 0 Or errText <> "" Then
        Renamer.ShowMessage summary & vbCrLf & vbCrLf & T("sum_details"), vbExclamation
    Else
        Renamer.ShowMessage summary, vbInformation
    End If

    Exit Sub

RenameError:

    errText = "Error " & CStr(Err.Number) & ": " & Err.Description
    Resume Finish

End Sub

Private Function SelectDocument() As Boolean

    SelectDocument = False

    If Me.Controls("cmbDocument").ListIndex = -1 Then
        Renamer.ShowMessage T("msg_pick_doc"), vbExclamation
        Exit Function
    End If

    Set mDoc = Nothing

    On Error GoTo 0

    If mDoc Is Nothing Then
        Renamer.ShowMessage T("msg_no_access"), vbCritical
        Exit Function
    End If

    'Load everything in design mode so every part can be read
    SetStatus T("st_reading")

    On Error Resume Next
    mDoc.Product.ApplyWorkMode DESIGN_MODE
    On Error GoTo 0

    SelectDocument = True

End Function


Private Function PreparePlan() As Boolean

    Dim prefix As String
    Dim startText As String
    Dim digitsText As String
    Dim errText As String

    PreparePlan = False

    '---------------------------------------
    'CHECK PREFIX
    '---------------------------------------

    prefix = Trim$(Me.Controls("txtPrefix").Text)

    If prefix = "" Then
        Renamer.ShowMessage T("msg_prefix"), vbExclamation
        Exit Function
    End If

    '---------------------------------------
    'CHECK START NUMBER
    '---------------------------------------

    startText = Trim$(Me.Controls("txtStartNumber").Text)

    If Not IsWholeNumber(startText) Then
        Renamer.ShowMessage T("msg_start"), vbExclamation
        Exit Function
    End If

    '---------------------------------------
    'CHECK DIGITS
    '---------------------------------------

    digitsText = Trim$(Me.Controls("txtDigits").Text)

    If Not IsWholeNumber(digitsText) Then
        Renamer.ShowMessage T("msg_digits"), vbExclamation
        Exit Function
    End If

    If CLng(digitsText) < 1 Or CLng(digitsText) > 10 Then
        Renamer.ShowMessage T("msg_digits"), vbExclamation
        Exit Function
    End If

    '---------------------------------------
    'GET CATPRODUCT
    '---------------------------------------

    If Not SelectDocument() Then
        Exit Function
    End If

    '---------------------------------------
    'BUILD PLAN (reads only, changes nothing)
    '---------------------------------------

    On Error GoTo PlanError

    Renamer.BuildPlan _
        mDoc.Product, _
        prefix, _
        CLng(startText), _
        CInt(digitsText), _
        CBool(Me.Controls("chkRecursive").Value), _
        CBool(Me.Controls("chkInstanceName").Value)

    PreparePlan = True
    Exit Function

PlanError:

    errText = "Error " & CStr(Err.Number) & ": " & Err.Description
    On Error GoTo 0

    SetStatus T("st_error")
    Renamer.ShowMessage T("msg_read_error", errText), vbCritical

End Function


Private Function IsWholeNumber(ByVal textValue As String) As Boolean

    Dim i As Long
    Dim ch As String

    IsWholeNumber = False

    If Len(textValue) = 0 Or Len(textValue) > 9 Then
        Exit Function
    End If

    For i = 1 To Len(textValue)

        ch = Mid$(textValue, i, 1)

        If ch < "0" Or ch > "9" Then
            Exit Function
        End If

    Next i

    IsWholeNumber = True

End Function

'Results are stored in English. This translates them for display.
Private Function ResultText(ByVal resultValue As String) As String

    If resultValue = RESULT_OK Then

        resultValue = T("res_ok")

    ElseIf resultValue = RESULT_SAME Then

        resultValue = T("res_same")

    ElseIf Left$(resultValue, Len(RESULT_FAILED)) = RESULT_FAILED Then

        resultValue = T("res_failed") & Mid$(resultValue, Len(RESULT_FAILED) + 1)

    ElseIf Left$(resultValue, Len(RESULT_SKIPPED)) = RESULT_SKIPPED Then

        resultValue = T("res_skipped") & Mid$(resultValue, Len(RESULT_SKIPPED) + 1)

    End If

    resultValue = Replace(resultValue, REASON_UNREAD, T("rsn_unread"))
    resultValue = Replace(resultValue, REASON_KEPT, T("rsn_kept"))
    resultValue = Replace(resultValue, REASON_RESTORED, T("rsn_restored"))
    resultValue = Replace(resultValue, REASON_LEFT, T("rsn_left"))

    ResultText = resultValue

End Function

Option Explicit

'=========================================================
' Renamer
' Entry point, rename plan, rename engine, undo, the
' English / Korean text table, and the credit image.
'
' How it works:
'   1. BuildPlan walks the assembly and only READS it.
'      Each unique part or subassembly gets one new number,
'      no matter how many times it is used.
'   2. ApplyPlan renames in two passes (temporary names
'      first, final names second) so new names can never
'      collide with old ones, and checks every result.
'   3. Every rename saves a CSV map. BuildUndoPlan reads a
'      map and builds the reverse plan, which is applied by
'      the same engine.
'=========================================================

'Windows message box that can show Korean on any PC.
'One of the two halves below will look red in the editor.
'That is normal: VBA only uses the half that fits your version.
#If VBA7 Then

Public Const APP_TITLE As String = "CATIA Component Renamer"

'These values are written to the CSV map. Keep them in English.
Public Const KIND_PART As String = "Part number"
Public Const KIND_INST As String = "Instance"

Public Const RESULT_OK As String = "OK"
Public Const RESULT_SAME As String = "No change"
Public Const RESULT_FAILED As String = "FAILED"
Public Const RESULT_SKIPPED As String = "SKIPPED"
Public Const RESULT_PLANNED As String = "Planned"

Public Const REASON_UNREAD As String = "could not be read (broken link or not loaded)"
Public Const REASON_KEPT As String = "CATIA kept the name"
Public Const REASON_RESTORED As String = "original name restored"
Public Const REASON_LEFT As String = "left as"

'True = Korean, False = English

    Target As Product

'=========================================================
' BUILD THE RENAME PLAN (reads only, changes nothing)
'=========================================================

Public Sub BuildPlan( _
    ByVal rootProduct As Product, _
    ByVal prefix As String, _
    ByVal startNumber As Long, _
    ByVal digits As Integer, _
    ByVal recursive As Boolean, _
    ByVal renameInstance As Boolean)

    Dim counter As Long

    ResetPlan

    counter = startNumber

    mVisited.Add rootProduct.PartNumber, True

    PlanChildren rootProduct, rootProduct.PartNumber, prefix, counter, digits, _
                 recursive, renameInstance

End Sub


Private Sub ResetPlan()

    Set mMap = CreateObject("Scripting.Dictionary")
    Set mVisited = CreateObject("Scripting.Dictionary")

    ReDim mItems(1 To 256)
    mCount = 0
    mCsvPath = ""

End Sub


Private Sub PlanChildren( _
    ByVal parentProduct As Product, _
    ByVal parentNewName As String, _
    ByVal prefix As String, _
    ByRef counter As Long, _
    ByVal digits As Integer, _
    ByVal recursive As Boolean, _
    ByVal renameInstance As Boolean)

    Dim childProducts As Products
    Dim childProduct As Product
    Dim instCount As Object

    Dim i As Long
    Dim n As Long
    Dim key As String
    Dim newPartNumber As String

    'Counts instances of each part under THIS parent,
    'so instance names become NEWNAME.1, NEWNAME.2, ...
    Set instCount = CreateObject("Scripting.Dictionary")

    Set childProducts = parentProduct.Products

    For i = 1 To childProducts.Count

        Set childProduct = childProducts.Item(i)

        '-----------------------------------
        'READ THE CURRENT PART NUMBER
        '-----------------------------------

        key = ""

        On Error Resume Next
        key = childProduct.PartNumber
        On Error GoTo 0

        If key = "" Then

            AddPlanItem KIND_PART, childProduct, parentNewName, _
                SafeInstanceName(childProduct), "", _
                RESULT_SKIPPED & ": " & REASON_UNREAD

        Else

            '-------------------------------
            'ONE NEW NUMBER PER UNIQUE PART
            '-------------------------------

            If mMap.Exists(key) Then

                newPartNumber = mMap(key)

            Else

                newPartNumber = prefix & FormatRenameNumber(counter, digits)
                counter = counter + 1

                mMap.Add key, newPartNumber

                AddPlanItem KIND_PART, childProduct, parentNewName, _
                            key, newPartNumber, ""

            End If

            '-------------------------------
            'INSTANCE NAME
            '-------------------------------

            If renameInstance Then

                n = 0

                If instCount.Exists(newPartNumber) Then
                    n = instCount(newPartNumber)
                End If

                n = n + 1
                instCount(newPartNumber) = n

                AddPlanItem KIND_INST, childProduct, parentNewName, _
                    SafeInstanceName(childProduct), _
                    newPartNumber & "." & CStr(n), ""

            End If

            '-------------------------------
            'SUBASSEMBLIES (each one walked once,
            'even if it is used several times)
            '-------------------------------

            If recursive Then

                If childProduct.Products.Count > 0 Then

                    If Not mVisited.Exists(key) Then

                        mVisited.Add key, True

                        PlanChildren childProduct, newPartNumber, prefix, counter, _
                                     digits, recursive, renameInstance

                    End If

                End If

            End If

        End If

    Next i

End Sub


Private Sub AddPlanItem( _
    ByVal kind As String, _
    ByVal target As Product, _
    ByVal parentName As String, _
    ByVal oldName As String, _

        Set .Target = target

        .NewName = newName
        .Result = result
    End With

'=========================================================
' BUILD THE UNDO PLAN (reads only, changes nothing)
' Returns False if the CSV map could not be read.
'=========================================================

Public Function BuildUndoPlan( _
    ByVal rootProduct As Product, _
    ByVal csvPath As String) As Boolean

    BuildUndoPlan = False

    ResetPlan

    Set mUndoParts = CreateObject("Scripting.Dictionary")
    Set mUndoInst = CreateObject("Scripting.Dictionary")

    If Not LoadUndoMap(csvPath) Then
        Exit Function
    End If

    mVisited.Add rootProduct.PartNumber, True

    UndoChildren rootProduct

    BuildUndoPlan = True

End Function


Private Function LoadUndoMap(ByVal csvPath As String) As Boolean

    Dim fileNum As Integer
    Dim isOpen As Boolean
    Dim lineText As String
    Dim fields() As String
    Dim n As Long
    Dim rowCount As Long

    Dim kind As String
    Dim parentName As String
    Dim oldName As String
    Dim newName As String
    Dim resultText As String
    Dim instKey As String

    LoadUndoMap = False

    On Error GoTo ReadFailed

    fileNum = FreeFile
    Open csvPath For Input As #fileNum
    isOpen = True

    Do While Not EOF(fileNum)

        Line Input #fileNum, lineText

        n = SplitCsvLine(lineText, fields)

        kind = ""
        parentName = ""
        oldName = ""
        newName = ""
        resultText = ""

        If n >= 5 Then
            kind = fields(1)
            parentName = fields(2)
            oldName = fields(3)
            newName = fields(4)
            resultText = fields(5)
        ElseIf n = 4 Then
            'Map written by the previous version (no Parent column):
            'part numbers can be restored, instance names cannot.
            kind = fields(1)
            oldName = fields(2)
            newName = fields(3)
            resultText = fields(4)
        End If

        If resultText = RESULT_OK Or resultText = RESULT_PLANNED Then

            If newName <> "" And oldName <> "" Then

                If kind = KIND_PART Then

                    If Not mUndoParts.Exists(newName) Then
                        mUndoParts.Add newName, oldName
                        rowCount = rowCount + 1
                    End If

                ElseIf kind = KIND_INST And parentName <> "" Then

                    instKey = parentName & "|" & newName

                    If Not mUndoInst.Exists(instKey) Then
                        mUndoInst.Add instKey, oldName
                        rowCount = rowCount + 1
                    End If

                End If

            End If

        End If

    Loop

    Close #fileNum

    LoadUndoMap = (rowCount > 0)
    Exit Function

ReadFailed:

    On Error Resume Next

    If isOpen Then
        Close #fileNum
    End If

End Function


Private Sub UndoChildren(ByVal parentProduct As Product)

    Dim childProducts As Products
    Dim childProduct As Product

    Dim i As Long
    Dim key As String
    Dim parentNow As String
    Dim parentAfter As String
    Dim instName As String
    Dim instKey As String

    parentNow = parentProduct.PartNumber
    parentAfter = parentNow

    If mUndoParts.Exists(parentNow) Then
        parentAfter = mUndoParts(parentNow)
    End If

    Set childProducts = parentProduct.Products

    For i = 1 To childProducts.Count

        Set childProduct = childProducts.Item(i)

        key = ""

        On Error Resume Next
        key = childProduct.PartNumber
        On Error GoTo 0

        If key <> "" Then

            '-------------------------------
            'PART NUMBER (once per unique part)
            '-------------------------------

            If mUndoParts.Exists(key) Then

                If Not mMap.Exists(key) Then

                    mMap.Add key, True

                    AddPlanItem KIND_PART, childProduct, parentAfter, _
                                key, mUndoParts(key), ""

                End If

            End If

            '-------------------------------
            'INSTANCE NAME
            '-------------------------------

            instName = SafeInstanceName(childProduct)
            instKey = parentNow & "|" & instName

            If mUndoInst.Exists(instKey) Then

                AddPlanItem KIND_INST, childProduct, parentAfter, _
                            instName, mUndoInst(instKey), ""

            End If

            '-------------------------------
            'SUBASSEMBLIES
            '-------------------------------

            If childProduct.Products.Count > 0 Then

                If Not mVisited.Exists(key) Then

                    mVisited.Add key, True
                    UndoChildren childProduct

                End If

            End If

        End If

    Next i

End Sub


'=========================================================
' APPLY THE PLAN (used for both rename and undo)
'=========================================================

Public Sub ApplyPlan()

    Dim i As Long

    'Anything that already has the right name is left alone
    For i = 1 To mCount

        If mItems(i).Result = "" Then
            If mItems(i).OldName = mItems(i).NewName Then
                mItems(i).Result = RESULT_SAME
            End If
        End If

    Next i

    'Part numbers first, then instance names
    ApplyKind KIND_PART
    ApplyKind KIND_INST

End Sub


Private Sub ApplyKind(ByVal kind As String)

    Dim i As Long
    Dim tempTag As String
    Dim reason As String
    Dim ignored As String

    tempTag = "RNTMP_" & Format(Now, "hhnnss") & "_"

    '---------------------------------------
    'PASS 1: TEMPORARY NAMES
    '---------------------------------------

    For i = 1 To mCount

        If mItems(i).Kind = kind And mItems(i).Result = "" Then

            If Not TrySetName(mItems(i).Target, kind, tempTag & CStr(i), reason) Then

                'Put the original name back in case it was half applied
                TrySetName mItems(i).Target, kind, mItems(i).OldName, ignored

                mItems(i).Result = RESULT_FAILED & ": " & reason

            End If

        End If

    Next i

    '---------------------------------------
    'PASS 2: FINAL NAMES
    '---------------------------------------

    For i = 1 To mCount

        If mItems(i).Kind = kind And mItems(i).Result = "" Then

            If TrySetName(mItems(i).Target, kind, mItems(i).NewName, reason) Then

                mItems(i).Result = RESULT_OK

            ElseIf TrySetName(mItems(i).Target, kind, mItems(i).OldName, ignored) Then

                mItems(i).Result = RESULT_FAILED & ": " & reason & _
                                   " (" & REASON_RESTORED & ")"

            Else

                mItems(i).Result = RESULT_FAILED & ": " & reason & _
                                   " (" & REASON_LEFT & " " & tempTag & CStr(i) & ")"

            End If

        End If

    Next i

End Sub


'Sets one name, then reads it back to confirm CATIA accepted it.
Private Function TrySetName( _
    ByVal target As Product, _
    ByVal kind As String, _
    ByVal newValue As String, _
    ByRef reason As String) As Boolean

    Dim actual As String

    TrySetName = False
    reason = ""
    actual = ""

    On Error Resume Next
    Err.Clear

    If kind = KIND_PART Then

        target.PartNumber = newValue

        If Err.Number <> 0 Then
            'Direct rename failed, try the reference product
            Err.Clear
            target.ReferenceProduct.PartNumber = newValue
        End If

        If Err.Number = 0 Then
            actual = target.PartNumber
        End If

    Else

        target.Name = newValue

        If Err.Number = 0 Then
            actual = target.Name
        End If

    End If

    If Err.Number <> 0 Then

        reason = Err.Description

        If reason = "" Then
            reason = "error " & CStr(Err.Number)
        End If

    ElseIf actual <> newValue Then

        reason = REASON_KEPT & " " & actual

    Else

        TrySetName = True

    End If

    Err.Clear
    On Error GoTo 0

End Function

'=========================================================
' RENAME MAP (CSV)
'=========================================================

'Saves the old-to-new map next to the CATProduct, or in the
'Windows TEMP folder if that fails. Returns the file path,
'or an empty string if nothing could be written.
Public Function SavePlanCsv(ByVal productDoc As ProductDocument) As String

    Dim baseName As String
    Dim fileName As String
    Dim folderPath As String
    Dim dotPos As Long

    mCsvPath = ""

    baseName = productDoc.Name
    dotPos = InStrRev(baseName, ".")

    If dotPos > 1 Then
        baseName = Left$(baseName, dotPos - 1)
    End If

    fileName = baseName & "_rename_map_" & Format(Now, "yyyymmdd_hhnnss") & ".csv"

    folderPath = ""

    On Error Resume Next
    folderPath = productDoc.Path
    On Error GoTo 0

    If folderPath <> "" Then
        If WriteCsv(folderPath & "\" & fileName) Then
            mCsvPath = folderPath & "\" & fileName
        End If
    End If

    If mCsvPath = "" Then
        folderPath = Environ$("TEMP")
        If WriteCsv(folderPath & "\" & fileName) Then
            mCsvPath = folderPath & "\" & fileName
        End If
    End If

    SavePlanCsv = mCsvPath

End Function

'Splits one CSV line into fields(1..n) and returns n
Private Function SplitCsvLine( _
    ByVal lineText As String, _
    ByRef fields() As String) As Long

    Dim i As Long
    Dim n As Long
    Dim ch As String
    Dim current As String
    Dim inQuotes As Boolean

    ReDim fields(1 To 8)

    i = 1

    Do While i <= Len(lineText)

        ch = Mid$(lineText, i, 1)

        If inQuotes Then

            If ch = """" Then

                If Mid$(lineText, i + 1, 1) = """" Then
                    current = current & """"
                    i = i + 1
                Else
                    inQuotes = False
                End If

            Else
                current = current & ch
            End If

        ElseIf ch = """" Then

            inQuotes = True

        ElseIf ch = "," Then

            n = n + 1

            If n <= 8 Then
                fields(n) = current
            End If

            current = ""

        Else

            current = current & ch

        End If

        i = i + 1

    Loop

    n = n + 1

    If n <= 8 Then
        fields(n) = current
    End If

    SplitCsvLine = n

End Function

'=========================================================
' LANGUAGE
'
' T("title") returns the text for "title" in the current language.
' In a text, | means a new line and {0} {1} {2} are
' replaced by the extra values passed to T.
'
' The Korean text is stored as \uXXXX codes so it survives
' copy and paste into the VBA editor on any PC. To change
' a Korean text, edit it on the web page table and convert
' it, or replace the code string with one from any
' "Unicode escape" converter.
'=========================================================

Public Function T(ByVal textKey As String, ParamArray args() As Variant) As String

    Dim s As String
    Dim i As Long

    If gKorean Then
        s = DecodeUnicode(TextKO(textKey))
    End If

    If s = "" Then
        s = TextEN(textKey)
    End If

    s = Replace(s, "|", vbCrLf)

    For i = LBound(args) To UBound(args)
        s = Replace(s, "{" & CStr(i) & "}", CStr(args(i)))
    Next i

    T = s

End Function

Private Function DecodeUnicode(ByVal s As String) As String

    Dim p As Long
    Dim startPos As Long
    Dim result As String

    startPos = 1
    p = InStr(startPos, s, "\u")

    Do While p > 0

        result = result & Mid$(s, startPos, p - startPos) & _
                 ChrW$(CLng("&H1" & Mid$(s, p + 2, 4)) - 65536)

        startPos = p + 6
        p = InStr(startPos, s, "\u")

    Loop

    DecodeUnicode = result & Mid$(s, startPos)

End Function

'Puts the picture into an Image control.
'Returns False if the picture could not be loaded.
Public Function LoadCreditImage(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    LoadCreditImage = False

    On Error GoTo Failed

    data = HexToBytes(CreditImageHex())

    'VBA can only load a picture from a file, so the data is
    'written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_renamer_credit.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    LoadCreditImage = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


'Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim byteCount As Long
    Dim i As Long
    Dim data() As Byte

    byteCount = Len(hexText) \ 2

    ReDim data(0 To byteCount - 1)

    For i = 0 To byteCount - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

How Undo works

  • Every rename saves a CSV map next to the CATProduct, or in the Windows TEMP folder. The final message shows where.
  • Undo reads that map, finds the components that currently have the new names, and renames them back with the same checked two-pass process.
  • Select the same CATProduct in the dropdown that the rename was run on.
  • An undo also saves its own map, so an undo can itself be reversed.
  • Keep the CSV files. Without the map, there is nothing to undo from.

Known limitations

  • It renames Part Numbers and instance names only. Files on disk keep their names.
  • Parts are told apart by their current Part Number. Two different documents that share a Part Number are treated as one part.
  • Undo matches by name. Components renamed by hand after the macro ran will not be found and are left as they are.
  • A new name that matches another document open in the session, or a deeper part when "Include subassemblies" is off, may be rejected by CATIA and will show as FAILED.
  • Read-only or PDM-locked parts will show as FAILED and keep their original names.
  • Results in the CSV file are always written in English so that Undo can read them in either language.
  • The credit image's background is the standard Windows form gray. On a PC with a different window color theme, it shows as a slightly different gray box.
  • If the image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
