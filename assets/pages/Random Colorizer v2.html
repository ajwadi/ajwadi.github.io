CATIA Random Colorizer v2

Color templates, an in-order repeating option, a safer Reset, and an English / Korean button. Two code blocks to paste: the form and the module.

What changed

  • Color template picker. A dropdown with the seven templates shown above, plus "Any color (fully random)". The ten colors of the selected template show as swatches in the window.
  • In order, repeating. Components 1 to 10 get colors 1 to 10 of the template, 11 to 20 start again at color 1, and so on until everything is colored. The other choice picks randomly from the template and never uses the same color twice in a row.
  • Reset goes back to the true original. The original colors are saved once, before the first run. Run it as many times as you like, in any mode, and Reset still returns to how the document looked at the start.
  • Default Colors button. Switches the whole document to CATIA default colors: in an assembly, components stop forcing a color so each part shows its own; in a part, every body gets the standard CATIA part color. Reset can undo it.
  • English / Korean button in the top right corner. The language, template and order are remembered for next time.
  • No pop-up boxes. Every result and error shows on the status line, so Korean text displays correctly without extra Windows declarations.
  • Credit image centered at the bottom. The image is stored inside the code as text, at the bottom of the module, so there is no image file to install and no wording typed into the code.
  • Buttons cannot get stuck. An unexpected error is caught and shown, and the buttons come back.

Setup

  1. In the VBA editor, select your form and set its (Name) to frmRandomColorizer in the Properties window. The form stays empty in the designer.
  2. Open the form's code, select all, delete, and paste the Form code below.
  3. Open your module, select all, delete, and paste the Module code below. Any module name works; Colorizer is suggested.
  4. Run CATMain.

First run: this code was written and reviewed but not run inside CATIA. Try Apply and then Reset on a copy of a small assembly, and on a copy of a part, before using it on real work.

Private Sub DetectDocument()

    Dim docType As String

    mDocKind = 0

    On Error Resume Next

    If CATIA.Documents.Count > 0 Then
        docType = TypeName(CATIA.ActiveDocument)
    End If

    On Error GoTo 0

    If docType = "ProductDocument" Then

        mDocKind = 1
        mOptLeaf.Value = True

    ElseIf docType = "PartDocument" Then

        mDocKind = 2
        Me.Controls("optBodies").Value = True

    ElseIf Len(docType) > 0 Then

        mDocKind = 3

    End If

    mOptAll.Enabled = (mDocKind = 1)
    mOptLeaf.Enabled = (mDocKind = 1)
    Me.Controls("optBodies").Enabled = (mDocKind = 2)

End Sub

        Case 3: ShowStatus Txt("stUnsupported")
        Case Else: ShowStatus Txt("stNoDoc")
    End Select

End Sub

Private Sub UpdateState()

    Dim anyColor As Boolean
    Dim canRun As Boolean
    Dim i As Integer
    Dim r As Long
    Dim g As Long
    Dim b As Long

    If mLoading Then Exit Sub

    canRun = (mDocKind = 1 Or mDocKind = 2)
    anyColor = (mPaletteCombo.ListIndex = PALETTE_ANY)

    Me.Controls("chkRecursive").Enabled = _
        (mDocKind = 1) And (mOptLeaf.Value = True)

    Me.Controls("optSeq").Enabled = canRun And Not anyColor
    Me.Controls("optRnd").Enabled = canRun And Not anyColor

    mPaletteCombo.Enabled = canRun
    mRandomizeButton.Enabled = canRun
    mResetButton.Enabled = HasSavedColors()
    mDefaultButton.Enabled = canRun

    For i = 1 To PALETTE_SIZE

        With Me.Controls("lblSwatch" & i)

            .Visible = Not anyColor

            If Not anyColor Then
                GetPaletteColor mPaletteCombo.ListIndex, i, r, g, b
                .BackColor = RGB(r, g, b)
            End If

        End With

    Next i

End Sub

Private Sub mRandomizeButton_Click()

    Dim colorMode As Integer
    Dim orderMode As Integer
    Dim paletteIndex As Integer
    Dim resultMessage As String

    If mOptAll.Value = True Then
        colorMode = COLOR_MODE_ALL_COMPONENTS
    ElseIf mOptLeaf.Value = True Then
        colorMode = COLOR_MODE_LEAF_PARTS
    ElseIf Me.Controls("optBodies").Value = True Then
        colorMode = COLOR_MODE_BODIES
    Else
        ShowStatus Txt("msgWrongDoc")
        Exit Sub
    End If

    If Me.Controls("optRnd").Value = True Then
        orderMode = ORDER_RANDOM
    Else
        orderMode = ORDER_SEQUENCE
    End If

    paletteIndex = mPaletteCombo.ListIndex

    If paletteIndex < 0 Then paletteIndex = 1

    SaveChoice "Palette", paletteIndex
    SaveChoice "Order", orderMode

    ShowStatus Txt("stApplying")
    SetBusy True

    On Error Resume Next

    RandomizeActiveDocument _
        colorMode, _
        (Me.Controls("chkRecursive").Value = True), _
        paletteIndex, _
        orderMode, _
        resultMessage

    If Err.Number <> 0 Then
        resultMessage = Fmt(Txt("msgError"), Err.Description)
        Err.Clear
    End If

    On Error GoTo 0

    SetBusy False
    UpdateState
    ShowStatus resultMessage

End Sub

' COLOR TEMPLATES
' Each template is 10 colors written as RRGGBB.
' To add one: add a Case here, raise PALETTE_LAST by 1,
' and add a "palN" name to TextEN and TextKO.

Private Function PaletteHex(ByVal paletteIndex As Integer) As String

    Select Case paletteIndex

        Case 1  ' Standard 10 colors
            PaletteHex = "E53935,FB8C00,FDD835,7CB342,00897B,039BE5,3949AB,8E24AA,D81B60,6D4C41"

        Case 2  ' Pastel
            PaletteHex = "F4A6A6,F9C99B,F8E9A1,C5E1A5,A5D6C8,A9D4F5,B3B9E8,D1B3E0,F3B0CC,CFC4BC"

        Case 3  ' High contrast
            PaletteHex = "FF0000,00C000,0000FF,FFFF00,FF00FF,00FFFF,FF8000,8000FF,804000,008060"

        Case 4  ' Earth tones
            PaletteHex = "6D4C41,A0522D,C68642,D2B48C,BDB76B,8A9A5B,556B2F,5F7A76,8B7D6B,B5651D"

        Case 5  ' Cool
            PaletteHex = "0D47A1,1976D2,42A5F5,90CAF9,006064,00ACC1,4DD0E1,00695C,26A69A,5C6BC0"

        Case 6  ' Warm
            PaletteHex = "B71C1C,E53935,FF7043,FB8C00,FFB300,FDD835,F06292,AD1457,8D6E63,FFCC80"

        Case 7  ' Grayscale
            PaletteHex = "2E2E2E,ABABAB,606060,D0D0D0,474747,BEBEBE,797979,E0E0E0,929292,F0F0F0"

        Case Else

    End Select

End Function


Public Sub GetPaletteColor( _
        ByVal paletteIndex As Integer, _
        ByVal colorIndex As Integer, _
        ByRef r As Long, _
        ByRef g As Long, _
        ByRef b As Long)

    Dim parts() As String
    Dim hexText As String

    parts = Split(PaletteHex(paletteIndex), ",")
    hexText = parts(colorIndex - 1)

    r = CLng("&H" & Mid$(hexText, 1, 2))
    g = CLng("&H" & Mid$(hexText, 3, 2))
    b = CLng("&H" & Mid$(hexText, 5, 2))

End Sub


' Any color, but kept bright enough to tell parts apart
Private Sub RandomBrightColor( _
        ByRef r As Long, _
        ByRef g As Long, _
        ByRef b As Long)

    Dim hue As Double
    Dim sat As Double
    Dim bright As Double
    Dim sector As Long
    Dim frac As Double
    Dim v1 As Double
    Dim v2 As Double
    Dim v3 As Double
    Dim rr As Double
    Dim gg As Double
    Dim bb As Double

    hue = Rnd * 6
    sat = 0.45 + Rnd * 0.5
    bright = 0.7 + Rnd * 0.3

    sector = Int(hue)
    If sector > 5 Then sector = 5
    frac = hue - sector

    v1 = bright * (1 - sat)
    v2 = bright * (1 - sat * frac)
    v3 = bright * (1 - sat * (1 - frac))

    Select Case sector
        Case 0: rr = bright: gg = v3: bb = v1
        Case 1: rr = v2: gg = bright: bb = v1
        Case 2: rr = v1: gg = bright: bb = v3
        Case 3: rr = v1: gg = v2: bb = bright
        Case 4: rr = v3: gg = v1: bb = bright
        Case Else: rr = bright: gg = v1: bb = v2
    End Select

    r = CLng(rr * 255)
    g = CLng(gg * 255)
    b = CLng(bb * 255)

End Sub


Private Sub PickColor( _
        ByVal paletteIndex As Integer, _
        ByVal orderMode As Integer, _
        ByVal position As Long, _
        ByRef lastPick As Integer, _
        ByRef r As Long, _
        ByRef g As Long, _
        ByRef b As Long)

    Dim k As Integer

    If paletteIndex = PALETTE_ANY Then
        RandomBrightColor r, g, b
        Exit Sub
    End If

    If orderMode = ORDER_SEQUENCE Then

        ' 1-10, then 11-20 start again at color 1, and so on
        k = CInt((position - 1) Mod PALETTE_SIZE) + 1

    Else

        ' Random pick, never the same color twice in a row
        Do
            k = Int(Rnd * PALETTE_SIZE) + 1
        Loop While k = lastPick

    End If

    lastPick = k

    GetPaletteColor paletteIndex, k, r, g, b

End Sub

Public Function RandomizeActiveDocument( _
        ByVal colorMode As Integer, _
        ByVal recursive As Boolean, _
        ByVal paletteIndex As Integer, _
        ByVal orderMode As Integer, _
        ByRef resultMessage As String) As Boolean

    Dim doc As Object
    Dim sel As Selection
    Dim targets As Collection
    Dim item As Object
    Dim position As Long
    Dim okCount As Long
    Dim failCount As Long
    Dim restoredOk As Long
    Dim restoredFail As Long
    Dim lastPick As Integer
    Dim r As Long
    Dim g As Long
    Dim b As Long

    RandomizeActiveDocument = False

    On Error GoTo Failed

    If CATIA.Documents.Count = 0 Then
        resultMessage = Txt("stNoDoc")
        Exit Function
    End If

    Set doc = CATIA.ActiveDocument

    If colorMode = COLOR_MODE_BODIES Then
        If TypeName(doc) <> "PartDocument" Then
            resultMessage = Txt("msgWrongDoc")
            Exit Function
        End If
    Else
        If TypeName(doc) <> "ProductDocument" Then
            resultMessage = Txt("msgWrongDoc")
            Exit Function
        End If
    End If

    ' Build the list of things to color, in tree order
    Set targets = New Collection

    Select Case colorMode

        Case COLOR_MODE_ALL_COMPONENTS
            CollectProducts doc.Product, False, False, targets

        Case COLOR_MODE_LEAF_PARTS
            CollectProducts doc.Product, True, recursive, targets

        Case COLOR_MODE_BODIES
            CollectBodies doc, targets

    End Select

    If targets.Count = 0 Then
        resultMessage = Txt("msgNothing")
        Exit Function
    End If

    CATIA.RefreshDisplay = False

    ' First run on this document: remember the original colors.
    ' Later runs: put the originals back first, so every run starts
    ' clean and Reset always returns to the true original.
    If mSavedCount > 0 And mSavedDocName = doc.FullName Then

        RestoreSnapshot doc, restoredOk, restoredFail

        If restoredOk = 0 Then TakeSnapshot doc

    Else

        TakeSnapshot doc

    End If

    Set sel = doc.Selection

    Randomize

    position = 0
    lastPick = 0

    For Each item In targets

        position = position + 1

        PickColor paletteIndex, orderMode, position, lastPick, r, g, b

        If PaintItem(sel, item, r, g, b, 1) Then
            okCount = okCount + 1
        Else
            failCount = failCount + 1
        End If

    Next item

    sel.Clear

    CATIA.RefreshDisplay = True

    If failCount = 0 Then
        resultMessage = Fmt(Txt("msgDone"), CStr(okCount))
    Else
        resultMessage = Fmt(Txt("msgDoneFail"), CStr(okCount), CStr(failCount))
    End If

    RandomizeActiveDocument = (okCount > 0)

    Exit Function

Failed:

    resultMessage = Fmt(Txt("msgError"), Err.Description)

    On Error Resume Next
    CATIA.RefreshDisplay = True

End Function

Public Function HasSavedColors() As Boolean

    HasSavedColors = (mSavedCount > 0)

End Function


Public Function ResetSavedColors( _
        ByRef resultMessage As String) As Boolean

    Dim doc As Object
    Dim okCount As Long
    Dim failCount As Long

    ResetSavedColors = False

    On Error GoTo Failed

    If mSavedCount = 0 Then
        resultMessage = Txt("msgNoSaved")
        Exit Function
    End If

    If CATIA.Documents.Count = 0 Then
        resultMessage = Txt("stNoDoc")
        Exit Function
    End If

    Set doc = CATIA.ActiveDocument

    If doc.FullName <> mSavedDocName Then
        resultMessage = Fmt(Txt("msgDocChanged"), mSavedDocName)
        Exit Function
    End If

    CATIA.RefreshDisplay = False

    RestoreSnapshot doc, okCount, failCount

    CATIA.RefreshDisplay = True

    ClearSnapshot

    If failCount = 0 Then
        resultMessage = Fmt(Txt("msgRestored"), CStr(okCount))
    Else
        resultMessage = Fmt(Txt("msgRestoredFail"), CStr(okCount), CStr(failCount))
    End If

    ResetSavedColors = (okCount > 0)

    Exit Function

Failed:

    resultMessage = Fmt(Txt("msgError"), Err.Description)

    On Error Resume Next
    CATIA.RefreshDisplay = True

End Function


'=========================================================
' DEFAULT COLORS
' CATIA has no "Auto" color command for macros, so this is
' the closest match:
'   Assembly: every component at every level stops forcing
'             a color, so each part shows its own colors.
'   Part:     every body gets CATIA's standard part color.
' The originals are saved first, so Reset can undo this.
'=========================================================

Public Function SetDefaultColors( _
        ByRef resultMessage As String) As Boolean

    Dim doc As Object
    Dim sel As Selection
    Dim targets As Collection
    Dim item As Object
    Dim inheritFlag As Long
    Dim okCount As Long
    Dim failCount As Long

    SetDefaultColors = False

    On Error GoTo Failed

    If CATIA.Documents.Count = 0 Then
        resultMessage = Txt("stNoDoc")
        Exit Function
    End If

    Set doc = CATIA.ActiveDocument

    Set targets = New Collection

    If TypeName(doc) = "PartDocument" Then
        CollectBodies doc, targets
        inheritFlag = 1
    ElseIf TypeName(doc) = "ProductDocument" Then
        CollectProducts doc.Product, False, True, targets
        inheritFlag = 0
    Else
        resultMessage = Txt("stUnsupported")
        Exit Function
    End If

    If targets.Count = 0 Then
        resultMessage = Txt("msgNothing")
        Exit Function
    End If

    CATIA.RefreshDisplay = False

    If Not (mSavedCount > 0 And mSavedDocName = doc.FullName) Then
        TakeSnapshot doc
    End If

    Set sel = doc.Selection

    For Each item In targets

        If PaintItem(sel, item, _
                DEFAULT_RED, DEFAULT_GREEN, DEFAULT_BLUE, inheritFlag) Then
            okCount = okCount + 1
        Else
            failCount = failCount + 1
        End If

    Next item

    sel.Clear

    CATIA.RefreshDisplay = True

    If failCount = 0 Then
        resultMessage = Fmt(Txt("msgDefault"), CStr(okCount))
    Else
        resultMessage = Fmt(Txt("msgDefaultFail"), CStr(okCount), CStr(failCount))
    End If

    SetDefaultColors = (okCount > 0)

    Exit Function

Failed:

    resultMessage = Fmt(Txt("msgError"), Err.Description)

    On Error Resume Next
    CATIA.RefreshDisplay = True

End Function


'=========================================================
' TREE WALKING
'=========================================================

' leafOnly = True : only components that have no children
' deep = True     : also go inside subassemblies
Private Sub CollectProducts( _
        ByVal parent As Object, _
        ByVal leafOnly As Boolean, _
        ByVal deep As Boolean, _
        ByVal items As Collection)

    Dim i As Long
    Dim child As Object

    For i = 1 To parent.Products.Count

        Set child = parent.Products.Item(i)

        If leafOnly Then

            If child.Products.Count = 0 Then
                items.Add child
            ElseIf deep Then
                CollectProducts child, leafOnly, deep, items
            End If

        Else

            items.Add child

            If deep Then
                CollectProducts child, leafOnly, deep, items
            End If

        End If

    Next i

End Sub


Private Sub CollectBodies( _
        ByVal doc As Object, _
        ByVal items As Collection)

    Dim i As Long
    Dim bodyList As Object

    Set bodyList = doc.Part.Bodies

    For i = 1 To bodyList.Count
        items.Add bodyList.Item(i)
    Next i

End Sub


'=========================================================
' SAVED COLORS
'=========================================================

Private Sub ClearSnapshot()

    mSavedCount = 0
    mSavedDocName = ""

    Erase mSavedObj
    Erase mSavedR
    Erase mSavedG
    Erase mSavedB
    Erase mSavedInh

End Sub


' Saves the color and the inheritance flag of every component
' at every level (or every body), whatever mode is selected.
Private Sub TakeSnapshot(ByVal doc As Object)

    Dim items As Collection
    Dim item As Object
    Dim sel As Selection
    Dim vis As VisPropertySet
    Dim r As Long
    Dim g As Long
    Dim b As Long
    Dim inh As Long

    ClearSnapshot

    Set items = New Collection

    If TypeName(doc) = "PartDocument" Then
        CollectBodies doc, items
    Else
        CollectProducts doc.Product, False, True, items
    End If

    If items.Count = 0 Then Exit Sub

    ReDim mSavedObj(1 To items.Count)
    ReDim mSavedR(1 To items.Count)
    ReDim mSavedG(1 To items.Count)
    ReDim mSavedB(1 To items.Count)
    ReDim mSavedInh(1 To items.Count)

    Set sel = doc.Selection

    On Error Resume Next

    For Each item In items

        r = 0
        g = 0
        b = 0
        inh = 0

        Err.Clear

        sel.Clear
        sel.Add item

        Set vis = sel.VisProperties

        vis.GetRealColor r, g, b
        vis.GetRealInheritance catVisPropertyColor, inh

        If Err.Number = 0 Then

            mSavedCount = mSavedCount + 1

            Set mSavedObj(mSavedCount) = item
            mSavedR(mSavedCount) = r
            mSavedG(mSavedCount) = g
            mSavedB(mSavedCount) = b
            mSavedInh(mSavedCount) = inh

        End If

    Next item

    sel.Clear

    Err.Clear

    mSavedDocName = doc.FullName

End Sub


Private Sub RestoreSnapshot( _
        ByVal doc As Object, _
        ByRef okCount As Long, _
        ByRef failCount As Long)

    Dim i As Long
    Dim sel As Selection

    okCount = 0
    failCount = 0

    Set sel = doc.Selection

    For i = 1 To mSavedCount

        If PaintItem(sel, mSavedObj(i), _
                mSavedR(i), mSavedG(i), mSavedB(i), mSavedInh(i)) Then
            okCount = okCount + 1
        Else
            failCount = failCount + 1
        End If

    Next i

    On Error Resume Next
    sel.Clear

End Sub


Private Function PaintItem( _
        ByVal sel As Selection, _
        ByVal item As Object, _
        ByVal r As Long, _
        ByVal g As Long, _
        ByVal b As Long, _
        ByVal inheritFlag As Long) As Boolean

    On Error Resume Next

    Err.Clear

    sel.Clear
    sel.Add item

    sel.VisProperties.SetRealColor r, g, b, inheritFlag

    PaintItem = (Err.Number = 0)

    Err.Clear

End Function

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

'=========================================================
' LOGO
' The logo picture is stored below as text.
' Any form in this project can show it:
'     LoadLogo Me.Controls("imgLogo")
'=========================================================

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function LoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    LoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    LoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

What each option colors

  • Top-level components. Each item directly under the root product gets one color. A subassembly gets a single color for everything inside it.
  • Individual parts. Each part gets its own color. With "Include parts inside subassemblies" ticked, that covers parts at every level; unticked, only parts directly under the root.
  • Bodies in active CATPart. Each body in the part gets its own color.

In CATIA, a color placed on a subassembly covers everything inside it. That is why a subassembly and its parts cannot both show their own colors, and why the first option colors the top level only.

Adding your own template

  1. In PaletteHex, add Case 8 with ten colors written as RRGGBB, separated by commas.
  2. Change PALETTE_LAST from 7 to 8.
  3. Add a "pal8" line with the template's name to TextEN and TextKO.

{0} and {1} are filled in with counts and names. The window title bar stays in English in both languages.

Known limitations

  • Reset works while CATIA stays open with the same document. The saved colors are lost if CATIA is closed, the document is closed, or the VBA project is reset.
  • Colors on assembly components are instance colors set in the assembly. Colors on parts inside a subassembly may be stored in that subassembly's document and mark it as modified.
  • A subassembly used more than once may only show the new colors correctly on one of its copies.
  • Only color is changed and restored. Transparency, materials and face-level colors are left alone, so a part with a material applied may not show its new color in a material view mode.
  • The current selection in CATIA is cleared when the macro runs.
  • Macros have no command for CATIA's "Auto" color, so Default Colors uses the closest match described above. Bodies get the standard color 210, 210, 255; if your site uses a different default, change DEFAULT_RED, DEFAULT_GREEN and DEFAULT_BLUE at the top of the module.
  • Default Colors does not remove colors placed on single faces or features inside a part.
  • The credit image's background is the standard Windows form gray. On a PC with a different window color theme, it shows as a slightly different gray box.
  • If the image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
Prepared for CATIA V5 VBA. Colors assembly components or part bodies and can restore the original colors.
