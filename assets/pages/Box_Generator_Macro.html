CATIA V5 R21 Box Generator

VBA macro for generating a 10 × 10 grid of 20 mm box parts inside an open CATProduct

Project Structure

VBAProject │ └── Modules └── BoxGenerator └── CATMain

Recommended setup: create one standard VBA module named BoxGenerator and paste the full code below into that module.

What the Macro Does

SettingValue
Grid size10 × 10
Total components100
Box footprint20 mm × 20 mm
Pad height20 mm
Grid spacing50 mm
Generated filenamesTempBox_Part_001.CATPart through TempBox_Part_100.CATPart
Temporary save locationWindows system temporary folder

R21 compatibility changes included: the macro avoids writing directly to partObj.Name, uses four CreateLine calls instead of CreateClosedLine, and passes component files using a Variant array.

Full VBA Code

Module: BoxGenerator 
Option Explicit

Sub CATMain()

    Dim productDoc As ProductDocument
    Dim rootProduct As Product
    Dim prodsObj As Object
    Dim docs As Documents

    Dim fso As Object
    Dim tempFolder As String

    Dim i As Integer
    Dim j As Integer
    Dim count As Integer

    Dim xOffset As Double
    Dim yOffset As Double

    Dim partDoc As PartDocument
    Dim partObj As Part
    Dim bodyObj As Body
    Dim skt As Sketch
    Dim geomDF As Factory2D

    Dim line1 As Line2D
    Dim line2 As Line2D
    Dim line3 As Line2D
    Dim line4 As Line2D

    Dim shapeFact As ShapeFactory
    Dim padObj As Pad

    Dim partName As String
    Dim filePath As String
    Dim fileArray As Variant

    '---------------------------------------
    ' Check active document
    '---------------------------------------

    If CATIA.Documents.Count = 0 Then
        MsgBox "Please open a CATProduct before running this script.", _
               vbCritical, "Error"
        Exit Sub
    End If

    If TypeName(CATIA.ActiveDocument) <> "ProductDocument" Then
        MsgBox "Active document must be a CATProduct.", _
               vbCritical, "Error"
        Exit Sub
    End If

    Set productDoc = CATIA.ActiveDocument
    Set rootProduct = productDoc.Product
    Set prodsObj = rootProduct.Products
    Set docs = CATIA.Documents

    '---------------------------------------
    ' Get Windows temporary folder
    '---------------------------------------

    Set fso = CreateObject("Scripting.FileSystemObject")
    tempFolder = fso.GetSpecialFolder(2).Path & "\"

    count = 1

    '---------------------------------------
    ' Generate 100 boxes
    '---------------------------------------

    For i = 0 To 9

        For j = 0 To 9

            xOffset = i * 50#
            yOffset = j * 50#

            partName = "TempBox_Part_" & Format(count, "000")
            filePath = tempFolder & partName & ".CATPart"

            '---------------------------------------
            ' Create new CATPart
            '---------------------------------------

            Set partDoc = docs.Add("Part")
            Set partObj = partDoc.Part

            ' Do NOT use:
            ' partObj.Name = partName
            '
            ' CATIA V5 R21 may throw Error 445 here.

            ' Optional: set Product Part Number
            On Error Resume Next
            partDoc.Product.PartNumber = partName
            On Error GoTo 0

            '---------------------------------------
            ' Get Main Body
            '---------------------------------------

            Set bodyObj = partObj.MainBody

            '---------------------------------------
            ' Create sketch on XY Plane
            '---------------------------------------

            Set skt = bodyObj.Sketches.Add( _
                      partObj.OriginElements.PlaneXY)

            Set geomDF = skt.OpenEdition()

            '---------------------------------------
            ' Create 20 mm x 20 mm square
            '---------------------------------------

            Set line1 = geomDF.CreateLine( _
                        xOffset, _
                        yOffset, _
                        xOffset + 20#, _
                        yOffset)

            Set line2 = geomDF.CreateLine( _
                        xOffset + 20#, _
                        yOffset, _
                        xOffset + 20#, _
                        yOffset + 20#)

            Set line3 = geomDF.CreateLine( _
                        xOffset + 20#, _
                        yOffset + 20#, _
                        xOffset, _
                        yOffset + 20#)

            Set line4 = geomDF.CreateLine( _
                        xOffset, _
                        yOffset + 20#, _
                        xOffset, _
                        yOffset)

            skt.CloseEdition

            partObj.Update

            '---------------------------------------
            ' Create 20 mm Pad
            '---------------------------------------

            Set shapeFact = partObj.ShapeFactory

            Set padObj = shapeFact.AddNewPad( _
                         skt, _
                         20#)

            partObj.Update

            '---------------------------------------
            ' Save CATPart
            '---------------------------------------

            partDoc.SaveAs filePath

            '---------------------------------------
            ' Close CATPart
            '---------------------------------------

            partDoc.Close

            '---------------------------------------
            ' Add saved CATPart to CATProduct
            '---------------------------------------

            fileArray = Array(filePath)

            Call prodsObj.AddComponentsFromFiles( _
                 fileArray, _
                 "All")

            count = count + 1

        Next j

    Next i

    '---------------------------------------
    ' Update assembly
    '---------------------------------------

    rootProduct.Update

    MsgBox "Successfully generated and inserted 100 box parts!", _
           vbInformation, "Complete"

End Sub

How to Install

StepAction
1Open the CATIA VBA editor.
2Create a new standard module using Insert → Module.
3Rename the module to BoxGenerator.
4Paste the full VBA code from this page into the module.
5Use Debug → Compile VBAProject.
6Open a CATProduct in CATIA before running the macro.
7Run CATMain.

Important Behavior

This version creates 100 separate CATPart files and inserts them into the current CATProduct. The geometry is offset inside each CATPart to create the visible grid.

A more advanced version could instead create one box CATPart and insert it 100 times using assembly-position transforms. That approach would usually be faster and produce a cleaner CATIA assembly structure.

Prepared for CATIA V5 R21 VBA.
