CATIA Fastener Populator

Places one fastener part on every hole or point you selected in the active assembly. Each fastener is moved to the hole origin and turned so its Z axis lines up with the hole. Two code blocks to paste: the form and the module.

What it does

  • Select, then run. Select hole features or points in the tree, run the macro, choose the fastener CATPart, and click Place.
  • One file, many instances. The fastener is loaded once and every other copy is an instance of the same part, so the bill of material shows one part with a quantity.
  • Aligned to the hole. The origin of the fastener sits on the hole origin and its Z axis points out of the hole. Tick Reverse if your fastener is modeled the other way.
  • Offset along the axis in mm, for example to seat a washer or a clip.
  • Optional Fix constraint on each fastener, so an assembly update does not move it.
  • English / Korean button in the top right corner. The language is remembered for next time.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with Fas, so it does not clash with the other macros in the same VBA project.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmFastenerPopulator. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. In the Properties window set its (Name) to FastenerPopulator, then paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATProduct, select the holes or points, then run CATMain from the FastenerPopulator module.

First run: this code was written and checked for structure, but not run inside CATIA. Try it on a plate with two holes and a simple bolt first. Use Undo in CATIA if the result is not right.

Private Sub DoAction(ByVal actionId As Long)

    Dim message As String
    Dim ok As Boolean

    If mBusy Then Exit Sub

    If Not DocReady() Then
        ShowDocStatus
        Exit Sub
    End If

    SaveInputs

    SetBusy True

    ShowStatus FasTxt("stWorking")

    On Error GoTo Failed

    ok = FasRun(Me, actionId, message)

    On Error Resume Next

    CATIA.RefreshDisplay = True
    CATIA.DisplayFileAlerts = True

    SetBusy False

    ShowStatus message

    Exit Sub

Failed:

    message = Err.Description

    On Error Resume Next

    CATIA.RefreshDisplay = True
    CATIA.DisplayFileAlerts = True

    SetBusy False

    ShowStatus FasFmt(FasTxt("msgError"), message)

End Sub

The long block of letters and numbers at the bottom is the credit image. Do not edit it.

Option Explicit

' CATIA FASTENER POPULATOR - MAIN MODULE
' Module name: FastenerPopulator
' Run CATMain to open the window.
'=========================================================

Private Const REG_APP As String = "CatiaFastenerPopulator"
Private Const REG_SEC As String = "Settings"

' "EN" or "KO"
Public gFasLang As String


'=========================================================
' ENTRY POINT
'=========================================================

Sub CATMain()

    FasLoadLanguage
    frmFastenerPopulator.Show

End Sub

'=========================================================
' PLACE
'=========================================================

Public Function FasRun( _
        ByVal frm As Object, _
        ByVal actionId As Long, _
        ByRef message As String) As Boolean

    Dim d As Object
    Dim root As Object
    Dim kids As Object
    Dim sel As Object
    Dim inst As Object
    Dim refProd As Object
    Dim targets As New Collection
    Dim t As Variant
    Dim fileArray As Variant
    Dim filePath As String
    Dim offsetText As String
    Dim offsetMm As Double
    Dim flip As Boolean
    Dim addFix As Boolean
    Dim i As Long
    Dim picked As Long
    Dim skipped As Long
    Dim placed As Long

    FasRun = False

    filePath = CtlText(frm, "txtFile")

    If Not FileExists(filePath) Or LCase$(Right$(filePath, 8)) <> ".catpart" Then
        message = FasTxt("msgNoFile")
        Exit Function
    End If

    offsetText = Replace(CtlText(frm, "txtOffset"), ",", ".")

    If Len(offsetText) = 0 Then offsetText = "0"

    If Not IsNumeric(offsetText) Then
        message = FasTxt("msgBadOffset")
        Exit Function
    End If

    offsetMm = Val(offsetText)
    flip = CtlOn(frm, "chkFlip")
    addFix = CtlOn(frm, "chkFix")

    Set d = CATIA.ActiveDocument
    Set root = d.Product
    Set kids = root.Products
    Set sel = d.Selection

    picked = sel.Count

    If picked = 0 Then
        message = FasTxt("msgNoSel")
        Exit Function
    End If

    ' Read every target first. Adding components changes the selection.
    For i = 1 To picked

        If TargetOf(sel.Item(i), kids, t) Then
            targets.Add t
        Else
            skipped = skipped + 1
        End If

    Next i

    If targets.Count = 0 Then
        message = FasFmt(FasTxt("msgNoTarget"), CStr(picked))
        Exit Function
    End If

    CATIA.RefreshDisplay = False

    For i = 1 To targets.Count

        Say frm, FasFmt(FasTxt("stItem"), CStr(i), CStr(targets.Count))

        If refProd Is Nothing Then

            ' The first fastener is loaded from the file
            fileArray = Array(filePath)

            kids.AddComponentsFromFiles fileArray, "All"

            Set inst = kids.Item(kids.Count)
            Set refProd = inst.ReferenceProduct

        Else

            ' The others are new instances of the same part
            Set inst = kids.AddComponent(refProd)

        End If

        t = targets.Item(i)

        PlaceInstance inst, t, flip, offsetMm

        If addFix Then FixInstance root, inst

        placed = placed + 1

    Next i

    On Error Resume Next
    root.Update
    On Error GoTo 0

    CATIA.RefreshDisplay = True

    message = FasFmt(FasTxt("msgDone"), CStr(placed), CStr(skipped))

    FasRun = True

End Function


'=========================================================
' WHERE A FASTENER GOES
' Fills t with the position (0 to 2) and the direction
' (3 to 5) of one selected hole or point, in the axis
' system of the active product.
'=========================================================

Private Function TargetOf( _
        ByVal item As Object, _
        ByVal kids As Object, _
        ByRef t As Variant) As Boolean

    Dim obj As Object
    Dim leaf As Object
    Dim check As Object
    Dim prt As Object
    Dim partDoc As Object
    Dim spa As Object
    Dim meas As Object
    Dim pos As Object
    Dim o(2) As Variant
    Dim v(2) As Variant
    Dim m(11) As Variant
    Dim guard As Long

    TargetOf = False

    On Error GoTo Failed

    Set obj = item.Value
    Set leaf = item.LeafProduct

    ' Only parts directly under the active product are supported
    Set check = kids.Item(leaf.Name)

    If check Is Nothing Then Exit Function

    If TypeName(obj) = "Hole" Then

        obj.GetOrigin o
        obj.GetDirection v

    Else

        ' A point: find the part it belongs to and measure it there
        Set prt = obj

        Do While TypeName(prt) <> "Part" And guard < 12
            Set prt = prt.Parent
            guard = guard + 1
        Loop

        If TypeName(prt) <> "Part" Then Exit Function

        Set partDoc = prt.Parent
        Set spa = partDoc.GetWorkbench("SPAWorkbench")
        Set meas = spa.GetMeasurable(prt.CreateReferenceFromObject(obj))

        meas.GetPoint o

        ' A point has no direction, so the Z axis of its part is used
        v(0) = 0
        v(1) = 0
        v(2) = 1

    End If

    ' Position of the part in the product: 9 numbers for the
    ' X, Y and Z axes, then 3 for the origin
    Set pos = check.Position

    pos.GetComponents m

    t = Array( _
        m(9) + o(0) * m(0) + o(1) * m(3) + o(2) * m(6), _
        m(10) + o(0) * m(1) + o(1) * m(4) + o(2) * m(7), _
        m(11) + o(0) * m(2) + o(1) * m(5) + o(2) * m(8), _
        v(0) * m(0) + v(1) * m(3) + v(2) * m(6), _
        v(0) * m(1) + v(1) * m(4) + v(2) * m(7), _
        v(0) * m(2) + v(1) * m(5) + v(2) * m(8))

    TargetOf = True

    Exit Function

Failed:

    TargetOf = False

End Function


'=========================================================
' MOVE ONE FASTENER INTO PLACE
' The origin of the fastener goes on the target and its
' Z axis points out of the hole.
'=========================================================

Private Sub PlaceInstance( _
        ByVal inst As Object, _
        ByVal t As Variant, _
        ByVal flip As Boolean, _
        ByVal offsetMm As Double)

    Dim pos As Object
    Dim m(11) As Variant
    Dim zx As Double
    Dim zy As Double
    Dim zz As Double
    Dim hx As Double
    Dim hy As Double
    Dim hz As Double
    Dim xx As Double
    Dim xy As Double
    Dim xz As Double
    Dim yx As Double
    Dim yy As Double
    Dim yz As Double
    Dim size As Double

    ' Z axis of the fastener: opposite to the drilling direction
    zx = -CDbl(t(3))
    zy = -CDbl(t(4))
    zz = -CDbl(t(5))

    If flip Then
        zx = -zx
        zy = -zy
        zz = -zz
    End If

    size = Sqr(zx * zx + zy * zy + zz * zz)

    If size < 0.000001 Then
        zx = 0
        zy = 0
        zz = 1
    Else
        zx = zx / size
        zy = zy / size
        zz = zz / size
    End If

    ' Any direction that is not parallel to Z
    If Abs(zx) < 0.9 Then
        hx = 1
        hy = 0
        hz = 0
    Else
        hx = 0
        hy = 1
        hz = 0
    End If

    ' X = helper x Z
    xx = hy * zz - hz * zy
    xy = hz * zx - hx * zz
    xz = hx * zy - hy * zx

    size = Sqr(xx * xx + xy * xy + xz * xz)

    xx = xx / size
    xy = xy / size
    xz = xz / size

    ' Y = Z x X
    yx = zy * xz - zz * xy
    yy = zz * xx - zx * xz
    yz = zx * xy - zy * xx

    m(0) = xx
    m(1) = xy
    m(2) = xz
    m(3) = yx
    m(4) = yy
    m(5) = yz
    m(6) = zx
    m(7) = zy
    m(8) = zz
    m(9) = CDbl(t(0)) + zx * offsetMm
    m(10) = CDbl(t(1)) + zy * offsetMm
    m(11) = CDbl(t(2)) + zz * offsetMm

    Set pos = inst.Position

    pos.SetComponents m

End Sub


' Adds a Fix constraint so the fastener stays where it was put
Private Sub FixInstance(ByVal root As Object, ByVal inst As Object)

    Dim csts As Object
    Dim ref As Object
    Dim cst As Object
    Dim pathText As String

    On Error Resume Next

    Set csts = root.Connections("CATIAConstraints")

    pathText = root.Name & "/" & inst.Name & "/"

    Set ref = root.CreateReferenceFromName(pathText & "!" & pathText)

    ' 0 = Fix
    Set cst = csts.AddMonoEltCst(0, ref)

End Sub

' Replaces characters that are not allowed in a file name
Private Function CleanName(ByVal rawName As String) As String

    Dim i As Long
    Dim ch As String
    Dim code As Long
    Dim result As String

    For i = 1 To Len(rawName)

        ch = Mid$(rawName, i, 1)
        code = AscW(ch)

        If InStr("\/:*?""<>|", ch) > 0 Or (code >= 0 And code < 32) Then
            result = result & "_"
        Else
            result = result & ch
        End If

    Next i

    If Len(result) = 0 Then result = "Unnamed"

    CleanName = result

End Function

' Splits one CSV line into its fields
Private Function CsvSplit(ByVal lineText As String) As Collection

    Dim fields As New Collection
    Dim i As Long
    Dim ch As String
    Dim cur As String
    Dim inQuotes As Boolean

    i = 1

    Do While i <= Len(lineText)

        ch = Mid$(lineText, i, 1)

        If inQuotes Then
            If ch = """" Then
                If Mid$(lineText, i + 1, 1) = """" Then
                    cur = cur & """"
                    i = i + 1
                Else
                    inQuotes = False
                End If
            Else
                cur = cur & ch
            End If
        ElseIf ch = """" Then
            inQuotes = True
        ElseIf ch = "," Then
            fields.Add cur
            cur = ""
        Else
            cur = cur & ch
        End If

        i = i + 1

    Loop

    fields.Add cur

    Set CsvSplit = fields

End Function

    Set d = prod.ReferenceProduct.Parent

    If d Is Nothing Then Exit Function

    If Right$(TypeName(d), 8) = "Document" Then Set DocOf = d

End Function


Private Sub AddDoc(ByVal docs As Object, ByVal d As Object)

    Dim key As String

    key = UCase$(d.FullName)

    If Not docs.Exists(key) Then docs.Add key, d

End Sub


' Fills docs (a Dictionary) with every loaded document under prod
Private Sub CollectDocs( _
        ByVal prod As Object, _
        ByVal docs As Object, _
        ByVal wantParts As Boolean, _
        ByVal wantProducts As Boolean)

    Dim kids As Object
    Dim child As Object
    Dim d As Object
    Dim kind As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set d = DocOf(child)

        If Not d Is Nothing Then

            kind = TypeName(d)

            If kind = "PartDocument" And wantParts Then AddDoc docs, d
            If kind = "ProductDocument" And wantProducts Then AddDoc docs, d

            CollectDocs child, docs, wantParts, wantProducts

        End If

    Next i

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function FasLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    FasLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    FasLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

How to model the fastener

  • Put the origin of the fastener part where it should touch the hole, for example the underside of the bolt head.
  • Point the Z axis of the part from the tip toward the head, so the shank goes into the hole when Z points out of it. If it is the other way round, tick Reverse the direction.
  • For points, there is no hole direction, so the Z axis of the part that owns the point is used.

Known limitations

  • When I suggested this macro I said "with constraints". Real coincidence and contact constraints between a fastener and a hole cannot be built reliably from a macro, so this version positions each fastener exactly and can add a Fix constraint. If the part with the holes moves later, the fasteners do not follow.
  • The holes or points must belong to parts directly under the active product. Items inside a sub-assembly are skipped and counted on the status line. Open the sub-assembly in its own window to populate it.
  • Select hole features in the tree. A hole edge or face picked in 3D is not a hole feature and is skipped.
  • Holes that come from a pattern are not separate features, so a patterned hole gets one fastener, on the original.
  • The rotation of the fastener around its own axis is not controlled, which matters only for parts that are not round.
  • The window is modal, so CATIA cannot be clicked while it is open. Anything that must be selected in CATIA has to be selected before running the macro.
  • If the credit image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
Prepared for CATIA V5 R21 and later, VBA. Places a fastener on every selected hole or point.
