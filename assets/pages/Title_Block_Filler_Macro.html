CATIA Title Block Filler

Fills the title block texts on every sheet of the active drawing from the properties of the part or assembly the sheet shows: part number, revision, description, mass, plus the sheet number, scale, date and your name. Two code blocks to paste: the form and the module.

What it does

  • List Text Names shows every text in the title block area with its name and current content, so you can see what your company title block calls each field.
  • You map the fields once. Type the name, or part of the name, of the text that should receive each value. The mapping is remembered.
  • Fill Title Blocks writes the values on every sheet. Each sheet takes its properties from the 3D model shown by its first view.
  • Sheet numbering. "1 / 3", "2 / 3" and so on are written automatically. Detail sheets are not counted.
  • Safe to run again. Texts are found by name, not by content, so running it after a revision change updates the same fields.
  • English / Korean button in the top right corner. The language is remembered for next time.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with TB, so it does not clash with the other macros in the same VBA project.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmTitleBlockFiller. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. In the Properties window set its (Name) to TitleBlockFiller, then paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATDrawing, then run CATMain from the TitleBlockFiller module. Click List Text Names first.

First run: this code was written and checked for structure, but not run inside CATIA. Try it on a copy of a drawing first. Click List Text Names, adjust the boxes to match your title block, then fill.

        Exit Sub

    ok = TBRun(Me, actionId, message)

    CATIA.DisplayFileAlerts = True

    ShowStatus message

    Exit Sub

    message = Err.Description

    On Error Resume Next

    CATIA.RefreshDisplay = True
    CATIA.DisplayFileAlerts = True

    SetBusy False

    ShowStatus TBFmt(TBTxt("msgError"), message)

' Module name: TitleBlockFiller
' Run CATMain to open the window.
'=========================================================

Private Const REG_APP As String = "CatiaTitleBlockFiller"
Private Const REG_SEC As String = "Settings"

' "EN" or "KO"

' ENTRY POINT
'=========================================================

    TBLoadLanguage

End Sub

'=========================================================
' BUTTONS
' 1 = List Text Names, 2 = Fill Title Blocks
'=========================================================

Public Function TBRun( _
        ByVal frm As Object, _
        ByVal actionId As Long, _
        ByRef message As String) As Boolean

    If actionId = 1 Then
        TBRun = ListTexts(frm, message)
    Else
        TBRun = FillAll(frm, message)
    End If

End Function


' The texts of the background view, where a title block lives.
' View 1 is the main view and view 2 is the background view.
Private Function BackgroundTexts(ByVal sheet As Object) As Object

    On Error Resume Next

    Set BackgroundTexts = sheet.Views.Item(2).Texts

End Function


Private Function IsDetailSheet(ByVal sheet As Object) As Boolean

    On Error Resume Next

    IsDetailSheet = sheet.IsDetail

End Function


'=========================================================
' LIST TEXT NAMES
'=========================================================

Private Function ListTexts(ByVal frm As Object, ByRef message As String) As Boolean

    Dim sheets As Object
    Dim sheet As Object
    Dim texts As Object
    Dim t As Object
    Dim lst As Object
    Dim i As Long
    Dim j As Long
    Dim found As Long
    Dim sheetCount As Long

    Set sheets = CATIA.ActiveDocument.Sheets
    Set lst = frm.Controls("lstRows")

    lst.Clear

    For i = 1 To sheets.Count

        Set sheet = sheets.Item(i)

        If Not IsDetailSheet(sheet) Then

            sheetCount = sheetCount + 1

            Set texts = BackgroundTexts(sheet)

            If Not texts Is Nothing Then

                For j = 1 To texts.Count

                    Set t = texts.Item(j)

                    lst.AddItem sheet.Name
                    lst.List(lst.ListCount - 1, 1) = t.Name
                    lst.List(lst.ListCount - 1, 2) = Left$(Replace(t.Text, vbLf, " "), 80)

                    found = found + 1

                Next j

            End If

        End If

    Next i

    message = TBFmt(TBTxt("msgListed"), CStr(found), CStr(sheetCount))

    ListTexts = True

End Function


'=========================================================
' FILL
'=========================================================

Private Function FillAll(ByVal frm As Object, ByRef message As String) As Boolean

    Dim sheets As Object
    Dim sheet As Object
    Dim texts As Object
    Dim t As Object
    Dim src As Object
    Dim textName As String
    Dim massText As String
    Dim i As Long
    Dim j As Long
    Dim sheetNo As Long
    Dim sheetCount As Long
    Dim changed As Long
    Dim noModel As Long

    FillAll = False

    Set sheets = CATIA.ActiveDocument.Sheets

    For i = 1 To sheets.Count
        If Not IsDetailSheet(sheets.Item(i)) Then sheetCount = sheetCount + 1
    Next i

    If sheetCount = 0 Then
        message = TBTxt("msgNoSheets")
        Exit Function
    End If

    For i = 1 To sheets.Count

        Set sheet = sheets.Item(i)

        If Not IsDetailSheet(sheet) Then

            sheetNo = sheetNo + 1

            Say frm, TBTxt("stWorking") & " " & sheet.Name

            Set src = LinkedProduct(sheet)

            If src Is Nothing Then noModel = noModel + 1

            massText = ""

            If Not src Is Nothing And Len(CtlText(frm, "txtWeight")) > 0 Then massText = MassOf(src)

            Set texts = BackgroundTexts(sheet)

            If Not texts Is Nothing Then

                For j = 1 To texts.Count

                    Set t = texts.Item(j)

                    textName = t.Name

                    ' Values that come from the 3D model
                    If Not src Is Nothing Then

                        If Hit(textName, CtlText(frm, "txtNumber")) Then changed = changed + PutText(t, PropText(src, 0))
                        If Hit(textName, CtlText(frm, "txtRev")) Then changed = changed + PutText(t, PropText(src, 1))
                        If Hit(textName, CtlText(frm, "txtDef")) Then changed = changed + PutText(t, PropText(src, 2))
                        If Hit(textName, CtlText(frm, "txtNom")) Then changed = changed + PutText(t, PropText(src, 3))
                        If Hit(textName, CtlText(frm, "txtTitle")) Then changed = changed + PutText(t, PropText(src, 4))

                        If Len(massText) > 0 Then
                            If Hit(textName, CtlText(frm, "txtWeight")) Then changed = changed + PutText(t, massText)
                        End If

                    End If

                    ' Values that come from the drawing itself
                    If Hit(textName, CtlText(frm, "txtSheet")) Then changed = changed + PutText(t, CStr(sheetNo) & " / " & CStr(sheetCount))
                    If Hit(textName, CtlText(frm, "txtScale")) Then changed = changed + PutText(t, ScaleText(sheet))
                    If Hit(textName, CtlText(frm, "txtDate")) Then changed = changed + PutText(t, Format$(Date, "yyyy-mm-dd"))

                    If Len(CtlText(frm, "txtByValue")) > 0 Then
                        If Hit(textName, CtlText(frm, "txtBy")) Then changed = changed + PutText(t, CtlText(frm, "txtByValue"))
                    End If

                Next j

            End If

        End If

    Next i

    message = TBFmt(TBTxt("msgDone"), CStr(changed), CStr(sheetCount), CStr(noModel))

    FillAll = True

End Function


' True when the text name contains what was typed in the box
Private Function Hit(ByVal textName As String, ByVal wanted As String) As Boolean

    If Len(wanted) = 0 Then Exit Function

    Hit = (InStr(1, textName, wanted, vbTextCompare) > 0)

End Function


' Writes the value. Returns 1 when the text really changed.
Private Function PutText(ByVal t As Object, ByVal newText As String) As Long

    On Error GoTo Failed

    If t.Text <> newText Then
        t.Text = newText
        PutText = 1
    End If

    Exit Function

Failed:

End Function


' 0 = Part Number, 1 = Revision, 2 = Definition,
' 3 = Nomenclature, 4 = Description
Private Function PropText(ByVal src As Object, ByVal which As Long) As String

    On Error Resume Next

    Select Case which
        Case 0: PropText = src.PartNumber
        Case 1: PropText = src.Revision
        Case 2: PropText = src.Definition
        Case 3: PropText = src.Nomenclature
        Case 4: PropText = src.DescriptionRef
    End Select

End Function


Private Function MassOf(ByVal src As Object) As String

    Dim massKg As Double

    On Error GoTo Failed

    massKg = src.Analyze.Mass

    MassOf = Num(massKg, 3) & " kg"

    Exit Function

Failed:

End Function


' 0.5 becomes 1:2, 2 becomes 2:1
Private Function ScaleText(ByVal sheet As Object) As String

    Dim s As Double

    On Error GoTo Failed

    s = sheet.Scale

    If s <= 0 Then Exit Function

    If s >= 1 Then
        ScaleText = TrimZeros(Num(s, 2)) & ":1"
    Else
        ScaleText = "1:" & TrimZeros(Num(1 / s, 2))
    End If

    Exit Function

Failed:

End Function


Private Function TrimZeros(ByVal numberText As String) As String

    If InStr(numberText, ".") > 0 Then

        Do While Right$(numberText, 1) = "0"
            numberText = Left$(numberText, Len(numberText) - 1)
        Loop

        If Right$(numberText, 1) = "." Then numberText = Left$(numberText, Len(numberText) - 1)

    End If

    TrimZeros = numberText

End Function


' The part or assembly shown by the first generated view of the
' sheet, or Nothing when the sheet has no view of a 3D model
Private Function LinkedProduct(ByVal sheet As Object) As Object

    Dim views As Object
    Dim obj As Object
    Dim i As Long
    Dim guard As Long

    On Error Resume Next

    Set views = sheet.Views

    If views Is Nothing Then Exit Function

    ' Views 1 and 2 are the main view and the background view
    For i = 3 To views.Count

        Set obj = Nothing
        Set obj = views.Item(i).GenerativeBehavior.Document

        If Not obj Is Nothing Then

            If TypeName(obj) = "Product" Then

                Set LinkedProduct = obj.ReferenceProduct

                If LinkedProduct Is Nothing Then Set LinkedProduct = obj

                Exit Function

            End If

            ' A part or a body: climb up to its document
            guard = 0

            Do While Right$(TypeName(obj), 8) <> "Document" And guard < 12
                Set obj = obj.Parent
                guard = guard + 1
            Loop

            If Right$(TypeName(obj), 8) = "Document" Then
                Set LinkedProduct = obj.Product
                Exit Function
            End If

        End If

    Next i

End Function

' "" = nothing open, otherwise Product, Part, Drawing or Other
Public Function TBDocKind() As String

    Dim t As String

    On Error Resume Next

    If CATIA.Documents.Count > 0 Then t = TypeName(CATIA.ActiveDocument)

    On Error GoTo 0

    Select Case t
        Case "ProductDocument": TBDocKind = "Product"
        Case "PartDocument": TBDocKind = "Part"
        Case "DrawingDocument": TBDocKind = "Drawing"
        Case "": TBDocKind = ""
        Case Else: TBDocKind = "Other"
    End Select

End Function

' Replaces characters that are not allowed in a file name
Private Function CleanName(ByVal rawName As String) As String

    Dim i As Long
    Dim ch As String
    Dim code As Long
    Dim result As String

    For i = 1 To Len(rawName)

        ch = Mid$(rawName, i, 1)
        code = AscW(ch)

        If InStr("\/:*?""<>|", ch) > 0 Or (code >= 0 And code < 32) Then
            result = result & "_"
        Else
            result = result & ch
        End If

    Next i

    If Len(result) = 0 Then result = "Unnamed"

    CleanName = result

End Function


Private Function StripExt(ByVal fileName As String) As String

    Dim p As Long

    If p > 1 Then
        StripExt = Left$(fileName, p - 1)

        StripExt = fileName
    End If

End Function

' Splits one CSV line into its fields
Private Function CsvSplit(ByVal lineText As String) As Collection

    Dim fields As New Collection
    Dim i As Long
    Dim ch As String
    Dim cur As String
    Dim inQuotes As Boolean

    i = 1

    Do While i <= Len(lineText)

        ch = Mid$(lineText, i, 1)

        If inQuotes Then
            If ch = """" Then
                If Mid$(lineText, i + 1, 1) = """" Then
                    cur = cur & """"
                    i = i + 1
                Else
                    inQuotes = False
                End If
            Else
                cur = cur & ch
            End If
        ElseIf ch = """" Then
            inQuotes = True
        ElseIf ch = "," Then
            fields.Add cur
            cur = ""
        Else
            cur = cur & ch
        End If

        i = i + 1

    Loop

    fields.Add cur

    Set CsvSplit = fields

End Function

' Fills docs (a Dictionary) with every loaded document under prod
Private Sub CollectDocs( _
        ByVal prod As Object, _
        ByVal docs As Object, _
        ByVal wantParts As Boolean, _
        ByVal wantProducts As Boolean)

    Dim kids As Object
    Dim child As Object
    Dim d As Object
    Dim kind As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set d = DocOf(child)

        If Not d Is Nothing Then

            kind = TypeName(d)

            If kind = "PartDocument" And wantParts Then AddDoc docs, d
            If kind = "ProductDocument" And wantProducts Then AddDoc docs, d

            CollectDocs child, docs, wantParts, wantProducts

        End If

    Next i

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

'     TBLoadLogo Me.Controls("imgLogo")

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function TBLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    TBLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    TBLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

Matching your title block

  • The boxes start with the text names used by the sample title block that ships with CATIA, such as TitleBlock_Text_Number. Your company title block probably uses other names. List Text Names shows them.
  • Matching is by "contains" and ignores upper and lower case, so Text_Number matches TitleBlock_Text_Number_1.
  • If your title block texts have no useful names (Text.1, Text.2 and so on), rename them once in the drawing template: right-click the text, Properties, Feature Properties, Feature Name.
  • The Description, Definition and Nomenclature boxes refer to the three fields on the Product tab of the 3D properties. Use the one your team fills in.

Known limitations

  • The title block must be made of texts in the sheet background. A title block inserted as a picture or as a 2D component (detail instance) is not reached.
  • A sheet with no view of a 3D model gets only the sheet number, scale, date and name.
  • When a sheet shows more than one model, the first view decides which model the properties come from.
  • The mass is read from CATIA when the macro runs and written as text, in kg with three decimals. It does not update by itself afterwards.
  • The scale is written as 1:2 or 2:1 from the sheet scale, not from individual views.
  • Text formatting such as font and size is kept, but a text that mixed several formats may come back in one format.
  • The window is modal, so CATIA cannot be clicked while it is open. Anything that must be selected in CATIA has to be selected before running the macro.
  • If the credit image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
