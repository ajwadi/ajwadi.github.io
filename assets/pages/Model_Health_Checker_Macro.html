CATIA Model Health Checker

Checks the active assembly or part for the problems that usually surface late: missing files, broken or deactivated constraints, deactivated or failing features, and components that nothing holds in place. Two code blocks to paste: the form and the module.

What it does

  • Four checks, each with its own tick box: missing or unloaded files, constraints, features, and loose components.
  • Results in a list in the window, with the check, where it was found, and the detail.
  • Export CSV saves the list as DocumentName_Health.csv and opens it.
  • Each document is checked once, however many times it is used in the assembly.
  • Works on a single CATPart too, where it runs the feature check.
  • English / Korean button in the top right corner. The language is remembered for next time.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with Hlth, so it does not clash with the other macros in the same VBA project.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmHealthChecker. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. In the Properties window set its (Name) to HealthChecker, then paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATProduct or CATPart, then run CATMain from the HealthChecker module and click Run Check.

First run: this code was written and checked for structure, but not run inside CATIA. Try it on a small assembly where you deactivate one feature and delete one constraint on purpose, and confirm both are found.

Private Sub DoAction(ByVal actionId As Long)

    Dim message As String
    Dim ok As Boolean

    If mBusy Then Exit Sub

    If Not DocReady() Then
        ShowDocStatus
        Exit Sub
    End If

    SaveInputs

    SetBusy True

    ShowStatus HlthTxt("stWorking")

    On Error GoTo Failed

    ok = HlthRun(Me, actionId, message)

    On Error Resume Next

    CATIA.RefreshDisplay = True
    CATIA.DisplayFileAlerts = True

    SetBusy False

    ShowStatus message

    Exit Sub

Failed:

    message = Err.Description

    On Error Resume Next

    CATIA.RefreshDisplay = True
    CATIA.DisplayFileAlerts = True

    SetBusy False

    ShowStatus HlthFmt(HlthTxt("msgError"), message)

End Sub

Module code

HealthChecker

The long block of letters and numbers at the bottom is the credit image. Do not edit it.

Option Explicit

'=========================================================
' CATIA MODEL HEALTH CHECKER - MAIN MODULE
' Module name: HealthChecker
' Run CATMain to open the window.
'=========================================================

Private Const REG_APP As String = "CatiaHealthChecker"
Private Const REG_SEC As String = "Settings"

' "EN" or "KO"
Public gHlthLang As String

Private mRows As Collection

Private mLinks As Boolean
Private mCst As Boolean
Private mFeat As Boolean
Private mFree As Boolean


'=========================================================
' ENTRY POINT
'=========================================================

Sub CATMain()

    HlthLoadLanguage
    frmHealthChecker.Show

End Sub

'=========================================================
' BUTTONS
' 1 = Run Check, 2 = Export CSV
'=========================================================

Public Function HlthRun( _
        ByVal frm As Object, _
        ByVal actionId As Long, _
        ByRef message As String) As Boolean

    Dim d As Object
    Dim seen As Object

    If actionId = 2 Then
        HlthRun = ExportIssues(frm, "_Health", message)
        Exit Function
    End If

    Set d = CATIA.ActiveDocument
    Set mRows = New Collection

    frm.Controls("lstRows").Clear

    mLinks = CtlOn(frm, "chkLinks")
    mCst = CtlOn(frm, "chkCst")
    mFeat = CtlOn(frm, "chkFeat")
    mFree = CtlOn(frm, "chkFree")

    If TypeName(d) = "ProductDocument" Then

        ' Missing files only show up once CATIA tries to load everything
        On Error Resume Next
        d.Product.ApplyWorkMode 2
        On Error GoTo 0

        Set seen = CreateObject("Scripting.Dictionary")

        CheckAssembly frm, d.Product, d.Product.PartNumber
        CheckTree frm, d.Product, d.Product.PartNumber, seen

    Else

        If mFeat Then CheckPart frm, d, d.Name

    End If

    message = HlthFmt(HlthTxt("msgDone"), CStr(mRows.Count))

    HlthRun = True

End Function


'=========================================================
' WALK THE TREE
'=========================================================

Private Sub CheckTree( _
        ByVal frm As Object, _
        ByVal prod As Object, _
        ByVal pathText As String, _
        ByVal seen As Object)

    Dim kids As Object
    Dim child As Object
    Dim rp As Object
    Dim d As Object
    Dim childPath As String
    Dim key As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)

        childPath = pathText & " / " & SafeName(child)

        Set rp = RefOf(child)

        If rp Is Nothing Then

            If mLinks Then AddIssue frm, HlthTxt("kLink"), childPath, HlthTxt("dNotLoaded")

        Else

            Set d = DocOf(child)

            If Not d Is Nothing Then

                key = UCase$(d.FullName)

                ' Each document is checked once, however often it is used
                If Not seen.Exists(key) Then

                    seen.Add key, 1

                    Say frm, HlthTxt("stItem") & " " & d.Name

                    If TypeName(d) = "PartDocument" Then
                        If mFeat Then CheckPart frm, d, childPath
                    ElseIf TypeName(d) = "ProductDocument" Then
                        CheckAssembly frm, rp, childPath
                    End If

                End If

            End If

            CheckTree frm, child, childPath, seen

        End If

    Next i

End Sub


'=========================================================
' CONSTRAINTS OF ONE ASSEMBLY
'=========================================================

Private Sub CheckAssembly( _
        ByVal frm As Object, _
        ByVal prodRef As Object, _
        ByVal whereText As String)

    Dim csts As Object
    Dim c As Object
    Dim r As Object
    Dim kids As Object
    Dim usedNames As String
    Dim cstName As String
    Dim kidName As String
    Dim i As Long
    Dim j As Long
    Dim total As Long
    Dim kidCount As Long
    Dim statusCode As Long
    Dim broken As Long
    Dim notUpdated As Long
    Dim flag As Boolean
    Dim gotStatus As Boolean

    If Not (mCst Or mFree) Then Exit Sub

    On Error Resume Next

    Set csts = prodRef.Connections("CATIAConstraints")
    Set kids = prodRef.Products

    If Not csts Is Nothing Then total = csts.Count
    If Not kids Is Nothing Then kidCount = kids.Count

    If total > 0 And mCst Then

        broken = csts.BrokenConstraintsCount
        notUpdated = csts.UnUpdatedConstraintsCount

        If broken > 0 Or notUpdated > 0 Then
            AddIssue frm, HlthTxt("kCst"), whereText, HlthFmt(HlthTxt("dBroken"), CStr(broken), CStr(notUpdated))
        End If

    End If

    For i = 1 To total

        Set c = csts.Item(i)

        cstName = ""
        cstName = c.Name

        If mCst Then

            statusCode = 0
            Err.Clear
            statusCode = c.Status
            gotStatus = (Err.Number = 0)
            Err.Clear

            If gotStatus And statusCode <> 0 Then
                AddIssue frm, HlthTxt("kCst"), whereText, HlthFmt(HlthTxt("dStatus"), cstName, CStr(statusCode))
            End If

            flag = False
            flag = c.IsInactive

            If flag Then AddIssue frm, HlthTxt("kCst"), whereText, cstName & ": " & HlthTxt("dInactive")

        End If

        ' Remember which components this constraint touches
        If mFree Then

            For j = 1 To 3

                Set r = Nothing
                Set r = c.GetConstraintElement(j)

                If Not r Is Nothing Then usedNames = usedNames & "|" & r.DisplayName

            Next j

        End If

    Next i

    Err.Clear

    On Error GoTo 0

    If mFree And kidCount > 1 Then

        If total = 0 Then

            AddIssue frm, HlthTxt("kFree"), whereText, HlthTxt("dNoCsts")

        Else

            For i = 1 To kidCount

                kidName = SafeName(kids.Item(i))

                If Len(kidName) > 0 Then
                    If InStr(1, usedNames, "/" & kidName & "/", vbTextCompare) = 0 Then
                        AddIssue frm, HlthTxt("kFree"), whereText & " / " & kidName, HlthTxt("dFree")
                    End If
                End If

            Next i

        End If

    End If

End Sub


'=========================================================
' FEATURES OF ONE PART
'=========================================================

Private Sub CheckPart( _
        ByVal frm As Object, _
        ByVal d As Object, _
        ByVal whereText As String)

    Dim prt As Object
    Dim bodies As Object
    Dim b As Object
    Dim items As Object
    Dim s As Object
    Dim i As Long
    Dim j As Long
    Dim pass As Long
    Dim bodyCount As Long
    Dim itemCount As Long
    Dim flag As Boolean
    Dim label As String

    On Error Resume Next

    Set prt = d.Part

    If prt Is Nothing Then Exit Sub

    Set bodies = prt.Bodies

    If Not bodies Is Nothing Then bodyCount = bodies.Count

    For i = 1 To bodyCount

        Set b = bodies.Item(i)

        ' pass 1 = solid features, pass 2 = sketches
        For pass = 1 To 2

            Set items = Nothing

            If pass = 1 Then
                Set items = b.Shapes
            Else
                Set items = b.Sketches
            End If

            itemCount = 0

            If Not items Is Nothing Then itemCount = items.Count

            For j = 1 To itemCount

                Set s = items.Item(j)

                label = ""
                label = b.Name & " / " & s.Name

                flag = False
                flag = prt.IsInactive(s)

                If flag Then

                    AddIssue frm, HlthTxt("kFeat"), whereText, label & ": " & HlthTxt("dInactive")

                Else

                    flag = True
                    flag = prt.IsUpToDate(s)

                    If Not flag Then AddIssue frm, HlthTxt("kFeat"), whereText, label & ": " & HlthTxt("dNotUpToDate")

                End If

            Next j

        Next pass

    Next i

    Err.Clear

End Sub

' Adds one finding to the list in the window
Private Sub AddIssue( _
        ByVal frm As Object, _
        ByVal checkName As String, _
        ByVal whereText As String, _
        ByVal detail As String)

    Dim lst As Object

    Set lst = frm.Controls("lstRows")

    lst.AddItem checkName
    lst.List(lst.ListCount - 1, 1) = whereText
    lst.List(lst.ListCount - 1, 2) = detail

    mRows.Add Array(checkName, whereText, detail)

End Sub


' Saves the list as a CSV file
Private Function ExportIssues( _
        ByVal frm As Object, _
        ByVal fileTag As String, _
        ByRef message As String) As Boolean

    Dim outFolder As String
    Dim target As String
    Dim content As String
    Dim rowData As Variant
    Dim i As Long

    ExportIssues = False

    If mRows Is Nothing Then
        message = HlthTxt("msgRunFirst")
        Exit Function
    End If

    outFolder = WithSlash(CtlText(frm, "txtOut"))

    If Not FolderExists(outFolder) Then
        message = HlthTxt("msgNoOut")
        Exit Function
    End If

    content = Csv(HlthTxt("hCheck")) & "," & Csv(HlthTxt("hWhere")) & "," & Csv(HlthTxt("hDetail")) & vbCrLf

    For i = 1 To mRows.Count
        rowData = mRows.Item(i)
        content = content & Csv(CStr(rowData(0))) & "," & Csv(CStr(rowData(1))) & "," & Csv(CStr(rowData(2))) & vbCrLf
    Next i

    target = outFolder & CleanName(StripExt(HlthDocName())) & fileTag & ".csv"

    If Not WriteTextFile(target, content) Then
        message = HlthTxt("msgWriteFail")
        Exit Function
    End If

    OpenFile target

    message = HlthFmt(HlthTxt("msgExported"), CStr(mRows.Count), target)

    ExportIssues = True

End Function

' "" = nothing open, otherwise Product, Part, Drawing or Other
Public Function HlthDocKind() As String

    Dim t As String

    On Error Resume Next

    If CATIA.Documents.Count > 0 Then t = TypeName(CATIA.ActiveDocument)

    On Error GoTo 0

    Select Case t
        Case "ProductDocument": HlthDocKind = "Product"
        Case "PartDocument": HlthDocKind = "Part"
        Case "DrawingDocument": HlthDocKind = "Drawing"
        Case "": HlthDocKind = ""
        Case Else: HlthDocKind = "Other"
    End Select

End Function


Public Function HlthDocName() As String

    On Error Resume Next

    HlthDocName = CATIA.ActiveDocument.Name

End Function

    Set picked = sh.BrowseForFolder(0, title, 1)

    If Not picked Is Nothing Then HlthBrowseFolder = picked.Self.Path

End Function

' Replaces characters that are not allowed in a file name
Private Function CleanName(ByVal rawName As String) As String

    Dim i As Long
    Dim ch As String
    Dim code As Long
    Dim result As String

    For i = 1 To Len(rawName)

        ch = Mid$(rawName, i, 1)
        code = AscW(ch)

        If InStr("\/:*?""<>|", ch) > 0 Or (code >= 0 And code < 32) Then
            result = result & "_"
        Else
            result = result & ch
        End If

    Next i

    If Len(result) = 0 Then result = "Unnamed"

    CleanName = result

End Function


Private Function StripExt(ByVal fileName As String) As String

    Dim p As Long

    p = InStrRev(fileName, ".")

    If p > 1 Then
        StripExt = Left$(fileName, p - 1)
    Else
        StripExt = fileName
    End If

End Function


Private Function FileNameOf(ByVal filePath As String) As String

    FileNameOf = Mid$(filePath, InStrRev(filePath, "\") + 1)

End Function


Private Function WithSlash(ByVal folderPath As String) As String

    If Len(folderPath) > 0 And Right$(folderPath, 1) <> "\" Then folderPath = folderPath & "\"

    WithSlash = folderPath

End Function


Private Function FolderExists(ByVal folderPath As String) As Boolean

    Dim fso As Object

    If Len(folderPath) = 0 Then Exit Function

    On Error Resume Next

    Set fso = CreateObject("Scripting.FileSystemObject")

    FolderExists = fso.FolderExists(folderPath)

End Function

    Dim fso As Object

    If Len(filePath) = 0 Then Exit Function

    On Error Resume Next

    Set fso = CreateObject("Scripting.FileSystemObject")

Private Sub DeleteFile(ByVal filePath As String)

    On Error Resume Next

    Set fso = CreateObject("Scripting.FileSystemObject")

End Sub


Private Sub OpenFile(ByVal filePath As String)

    Dim sh As Object

    On Error Resume Next

    Set sh = CreateObject("WScript.Shell")

Private Function IsDocOpen(ByVal fileName As String) As Boolean

    Dim d As Object

    On Error Resume Next

    Set d = CATIA.Documents.Item(fileName)

    IsDocOpen = (Err.Number = 0) And Not (d Is Nothing)

    Err.Clear

End Function


' One CSV field, always in quotes
Private Function Csv(ByVal fieldText As String) As String

    Csv = """" & Replace(fieldText, """", """""") & """"

End Function


' A number written with a decimal point on every PC
Private Function Num(ByVal numberValue As Variant, Optional ByVal decimals As Long = 3) As String

    Dim pattern As String

    On Error Resume Next

    pattern = "0"

    If decimals > 0 Then pattern = "0." & String$(decimals, "0")

    Num = Replace(Format$(CDbl(numberValue), pattern), ",", ".")

End Function


' Saves text as UTF-8 so Excel shows Korean correctly
Private Function WriteTextFile(ByVal filePath As String, ByVal content As String) As Boolean

    Dim stm As Object

    On Error GoTo Failed

    Set stm = CreateObject("ADODB.Stream")

    stm.Type = 2
    stm.Charset = "utf-8"
    stm.Open
    stm.WriteText content
    stm.SaveToFile filePath, 2
    stm.Close

    WriteTextFile = True

    Exit Function

Failed:

    On Error Resume Next
    stm.Close

End Function


Private Function ReadTextFile(ByVal filePath As String) As String

    Dim stm As Object

    On Error GoTo Failed

    Set stm = CreateObject("ADODB.Stream")

    stm.Type = 2
    stm.Charset = "utf-8"
    stm.Open

' Splits one CSV line into its fields
Private Function CsvSplit(ByVal lineText As String) As Collection

    Dim fields As New Collection
    Dim i As Long
    Dim ch As String
    Dim cur As String
    Dim inQuotes As Boolean

    i = 1

    Do While i <= Len(lineText)

        ch = Mid$(lineText, i, 1)

        If inQuotes Then
            If ch = """" Then
                If Mid$(lineText, i + 1, 1) = """" Then
                    cur = cur & """"
                    i = i + 1
                Else
                    inQuotes = False
                End If
            Else
                cur = cur & ch
            End If
        ElseIf ch = """" Then
            inQuotes = True
        ElseIf ch = "," Then
            fields.Add cur
            cur = ""
        Else
            cur = cur & ch
        End If

        i = i + 1

    Loop

    fields.Add cur

    Set CsvSplit = fields

End Function

' The document behind a component, or Nothing when it has none
Private Function DocOf(ByVal prod As Object) As Object

    On Error Resume Next

    If d Is Nothing Then Exit Function

    If Right$(TypeName(d), 8) = "Document" Then Set DocOf = d

Private Sub AddDoc(ByVal docs As Object, ByVal d As Object)

    Dim key As String

    key = UCase$(d.FullName)

    If Not docs.Exists(key) Then docs.Add key, d

End Sub


' Fills docs (a Dictionary) with every loaded document under prod
Private Sub CollectDocs( _
        ByVal prod As Object, _
        ByVal docs As Object, _
        ByVal wantParts As Boolean, _
        ByVal wantProducts As Boolean)

    Dim kids As Object
    Dim child As Object
    Dim d As Object
    Dim kind As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set d = DocOf(child)

        If Not d Is Nothing Then

            kind = TypeName(d)

            If kind = "PartDocument" And wantParts Then AddDoc docs, d
            If kind = "ProductDocument" And wantProducts Then AddDoc docs, d

            CollectDocs child, docs, wantParts, wantProducts

        End If

    Next i

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

'     HlthLoadLogo Me.Controls("imgLogo")

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function HlthLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    HlthLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    HlthLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

{0}, {1} and {2} are filled in with numbers, names and error details. The window title bar stays in English in both languages.

Known limitations

  • The loose-component check is a hint, not a proof. It lists components that no constraint in their own assembly refers to. A component can be referred to by a constraint and still be free to move in some directions.
  • Constraint problems are reported with CATIA's numeric status code. 0 means OK. Anything else means CATIA does not consider the constraint resolved.
  • The feature check covers solid features and sketches inside bodies. Surfaces and wireframe in geometrical sets are not checked.
  • "Needs an update" also appears for parts that are simply not updated yet. Update the assembly first to see only real errors.
  • The assembly is switched to design mode, which can take a while on a large assembly.
  • The macro only reports. It does not fix anything.
  • The window is modal, so CATIA cannot be clicked while it is open. Anything that must be selected in CATIA has to be selected before running the macro.
  • If the credit image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
Prepared for CATIA V5 R21 and later, VBA. Reports missing files, constraint problems and feature errors.
