CATIA Tree Exporter

Pick any open CATIA window, CATProduct or CATPart, and save its specification tree as a .csv file. Two code blocks to paste: the form and the module.

What it does

  • Window picker. The window lists every window open in CATIA with its type. The window that is active in CATIA is selected to start with. Refresh rebuilds the list.
  • Works on a CATProduct. Every product, component and part is written on its own row, at every level, with its part number, instance name and properties.
  • Works on a CATPart. The part is the top row, followed by its bodies, geometrical sets, sketches and features.
  • Optional part contents in assemblies. Tick the box to also list the bodies and features inside each part of an assembly. It is off by default because the assembly must be switched to design mode, which can take a while on a large one.
  • Body names only. Tick "Export body names only" and the file holds one row for each body and nothing else. Each row also carries the part number, instance name and file of the part the body belongs to. It works on a CATPart and on a CATProduct, where the parts are loaded in design mode first.
  • Saved as .csv. A file name is suggested from the document name, ending in _Tree.csv. Type another path or use Browse. The folder is remembered for next time.
  • English / Korean button in the top right corner. The column headings in the file follow the language of the window.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with TreeExp, so it does not clash with the box generator, colorizer, renamer, BOM exporter or text generator in the same project.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmTreeExporter. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. In the Properties window set its (Name) to TreeExporter, then paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATProduct or CATPart, then run CATMain from the TreeExporter module.

First run: this code was written and checked for structure, but not run inside CATIA. Try it on a small assembly first and compare a few rows with the tree on screen.

' Lists every window open in CATIA.
' keepIndex is the row to select again, or -1 to select
' the window that is active in CATIA.
Private Sub FillWindows(ByVal keepIndex As Long)

    Dim n As Long
    Dim i As Long
    Dim pick As Long
    Dim cap As String
    Dim activeCap As String

    mLoading = True

    mWindowList.Clear

    n = TreeExpWindowCount()
    activeCap = TreeExpActiveCaption()
    pick = -1

    ReDim mKinds(0 To n)

    For i = 1 To n

        cap = TreeExpWindowCaption(i)

        mKinds(i - 1) = TreeExpDocKind(TreeExpFindDocument(cap))

        mWindowList.AddItem cap
        mWindowList.List(i - 1, 1) = KindText(mKinds(i - 1))

        If pick < 0 And cap = activeCap Then pick = i - 1

    Next i

    If keepIndex >= 0 And keepIndex < n Then pick = keepIndex
    If pick < 0 And n > 0 Then pick = 0

    If n > 0 Then mWindowList.ListIndex = pick

    mLoading = False

    SelectionChanged

End Sub


Private Function KindText(ByVal kind As Integer) As String

    Select Case kind
        Case 1: KindText = TreeExpTxt("kindProduct")
        Case 2: KindText = TreeExpTxt("kindPart")
        Case 3: KindText = TreeExpTxt("kindOther")
        Case Else: KindText = TreeExpTxt("kindUnknown")
    End Select

End Function


' Document type of the selected row, or -1 if nothing is selected
Private Function SelectedKind() As Integer

    Dim idx As Long

    idx = mWindowList.ListIndex

    If idx < 0 Or mWindowList.ListCount = 0 Then
        SelectedKind = -1
    Else
        SelectedKind = mKinds(idx)
    End If

End Function


Private Sub SelectionChanged()

    Dim kind As Integer

    kind = SelectedKind()

    mExportButton.Enabled = (kind = 0 Or kind = 1 Or kind = 2)

    Select Case kind
        Case 1: ShowStatus TreeExpTxt("stProduct")
        Case 2: ShowStatus TreeExpTxt("stPart")
        Case 3: ShowStatus TreeExpTxt("stOther")
        Case 0: ShowStatus TreeExpTxt("stUnknown")
        Case Else: ShowStatus TreeExpTxt("stNoWindow")
    End Select

    UpdateDefaultPath

End Sub

'=========================================================
' EXPORT BUTTON
'=========================================================

Private Sub mExportButton_Click()

    Dim doc As Object
    Dim idx As Long
    Dim kind As Integer
    Dim filePath As String
    Dim folderPath As String
    Dim includeFeatures As Boolean
    Dim bodiesOnly As Boolean
    Dim openAfter As Boolean
    Dim rowCount As Long
    Dim errorText As String
    Dim ok As Boolean

    idx = mWindowList.ListIndex

    If idx < 0 Or mWindowList.ListCount = 0 Then
        ShowStatus TreeExpTxt("stNoWindow")
        Exit Sub
    End If

    '---------------------------------------
    ' Check the file path
    '---------------------------------------

    filePath = Trim$(Me.Controls("txtPath").Text)

    If Len(filePath) = 0 Then
        ShowStatus TreeExpTxt("msgNoPath")
        Exit Sub
    End If

    If LCase$(Right$(filePath, 4)) <> ".csv" Then filePath = filePath & ".csv"

    ' A bare file name is saved in the Documents folder
    If InStr(filePath, "\") = 0 Then
        filePath = TreeExpDocumentsFolder() & "\" & filePath
    End If

    folderPath = Left$(filePath, InStrRev(filePath, "\") - 1)

    If Not TreeExpFolderExists(folderPath) Then
        ShowStatus TreeExpFmt(TreeExpTxt("msgBadFolder"), folderPath)
        Exit Sub
    End If

    If Me.Controls("txtPath").Text = mAutoPath Then mAutoPath = filePath

    Me.Controls("txtPath").Text = filePath

    includeFeatures = (Me.Controls("chkFeatures").Value = True)
    openAfter = (Me.Controls("chkOpen").Value = True)
    bodiesOnly = (mBodiesCheck.Value = True)

    On Error GoTo Failed

    SetBusy True

    '---------------------------------------
    ' Bring the picked window to the front
    ' and take its document
    '---------------------------------------

    ShowStatus TreeExpTxt("stActivating")
    Me.Repaint

    Set doc = TreeExpActivateWindow(idx + 1, CStr(mWindowList.List(idx, 0)))

    If doc Is Nothing Then
        SetBusy False
        FillWindows -1
        ShowStatus TreeExpTxt("msgWindowGone")
        Exit Sub
    End If

    kind = TreeExpDocKind(doc)

    If kind <> 1 And kind <> 2 Then
        SetBusy False
        ShowStatus TreeExpTxt("stOther")
        Exit Sub
    End If

    TreeExpSaveChoice "Features", IIf(includeFeatures, 1, 0)
    TreeExpSaveChoice "OpenAfter", IIf(openAfter, 1, 0)
    TreeExpSaveChoice "BodiesOnly", IIf(bodiesOnly, 1, 0)
    TreeExpSaveText "Folder", folderPath

    '---------------------------------------
    ' Read the tree and write the file
    '---------------------------------------

    ok = TreeExpExport(doc, filePath, includeFeatures, bodiesOnly, rowCount, errorText)

    SetBusy False

    If ok Then
        ShowStatus TreeExpFmt(TreeExpTxt("msgDone"), CStr(rowCount), filePath)
        If openAfter Then TreeExpOpenFile filePath
    Else
        ShowStatus TreeExpFmt(TreeExpTxt("msgError"), errorText)
    End If

    Exit Sub

Failed:

    errorText = Err.Description

    SetBusy False

    ShowStatus TreeExpFmt(TreeExpTxt("msgError"), errorText)

End Sub

' CATIA TREE EXPORTER - MAIN MODULE
' Module name: TreeExporter
' Run CATMain to open the window.
'
' Saves the specification tree of a CATProduct or a
' CATPart as a CSV file. Every public name starts with
' TreeExp so this module can sit beside the other macros.
'=========================================================

Private Const REG_APP As String = "CatiaTreeExporter"
Private Const REG_SEC As String = "Settings"

' Spaces added to the Tree column for each level
Private Const INDENT_SIZE As Long = 4

' The status line is refreshed every this many rows
Private Const PROGRESS_STEP As Long = 50

' "EN" or "KO"
Public gTreeExpLang As String

' State of the export that is running
Private mFileNo As Integer
Private mFileOpen As Boolean
Private mRowCount As Long
Private mWriteError As String
Private mIncludeFeatures As Boolean
Private mBodiesOnly As Boolean

' The part being read, written on each row in body-names-only mode
Private mPartNumber As String
Private mPartInstance As String
Private mPartFile As String
Private mPartPath As String


'=========================================================
' ENTRY POINT
'=========================================================

Sub CATMain()

    TreeExpLoadLanguage
    frmTreeExporter.Show

End Sub


'=========================================================
' CATIA WINDOWS
'=========================================================

Public Function TreeExpWindowCount() As Long

    On Error Resume Next

    TreeExpWindowCount = CATIA.Windows.Count

End Function


Public Function TreeExpWindowCaption(ByVal windowIndex As Long) As String

    On Error Resume Next

    TreeExpWindowCaption = CATIA.Windows.Item(windowIndex).Caption

End Function


Public Function TreeExpActiveCaption() As String

    On Error Resume Next

    TreeExpActiveCaption = CATIA.ActiveWindow.Caption

End Function


' Finds the open document a window belongs to by comparing
' the window caption with the document names. A caption is
' the document name, sometimes followed by ":2" and so on.
' Returns Nothing if no document matches.
Public Function TreeExpFindDocument(ByVal caption As String) As Object

    Dim i As Long
    Dim total As Long
    Dim d As Object
    Dim best As Object
    Dim bestLen As Long
    Dim docName As String

    On Error Resume Next

    total = CATIA.Documents.Count

    For i = 1 To total

        Set d = Nothing
        docName = ""

        Set d = CATIA.Documents.Item(i)

        If Not d Is Nothing Then docName = d.Name

        If Len(docName) > bestLen Then
            If StrComp(Left$(caption, Len(docName)), docName, vbTextCompare) = 0 Then
                Set best = d
                bestLen = Len(docName)
            End If
        End If

    Next i

    Set TreeExpFindDocument = best

End Function


' 0 = unknown, 1 = CATProduct, 2 = CATPart, 3 = other
Public Function TreeExpDocKind(ByVal doc As Object) As Integer

    If doc Is Nothing Then
        TreeExpDocKind = 0
        Exit Function
    End If

    Select Case TypeName(doc)
        Case "ProductDocument": TreeExpDocKind = 1
        Case "PartDocument": TreeExpDocKind = 2
        Case Else: TreeExpDocKind = 3
    End Select

End Function


' Brings a window to the front and returns its document.
' Returns Nothing if the window is gone or has changed.
Public Function TreeExpActivateWindow( _
        ByVal windowIndex As Long, _
        ByVal expectedCaption As String) As Object

    Dim w As Object

    On Error GoTo Failed

    Set w = CATIA.Windows.Item(windowIndex)

    If w.Caption <> expectedCaption Then Exit Function

    w.Activate

    Set TreeExpActivateWindow = CATIA.ActiveDocument

    Exit Function

Failed:

    Set TreeExpActivateWindow = Nothing

End Function


'=========================================================
' FILES AND FOLDERS
'=========================================================

Public Function TreeExpDocumentsFolder() As String

    Dim folderPath As String

    On Error Resume Next

    folderPath = CreateObject("WScript.Shell").SpecialFolders("MyDocuments")

    If Len(folderPath) = 0 Then folderPath = Environ$("USERPROFILE")

    TreeExpDocumentsFolder = folderPath

End Function


Public Function TreeExpFolderExists(ByVal folderPath As String) As Boolean

    On Error Resume Next

    If Len(folderPath) = 0 Then Exit Function

    TreeExpFolderExists = CreateObject("Scripting.FileSystemObject").FolderExists(folderPath)

End Function


' Suggested file for a window: the last folder used, or the
' document's own folder, or Documents, then <name>_Tree.csv
Public Function TreeExpDefaultPath(ByVal caption As String) As String

    Dim doc As Object
    Dim folderPath As String
    Dim baseName As String
    Dim dotPos As Long

    On Error Resume Next

    Set doc = TreeExpFindDocument(caption)

    folderPath = TreeExpLoadText("Folder", "")

    If Not TreeExpFolderExists(folderPath) Then
        folderPath = ""
        If Not doc Is Nothing Then folderPath = doc.Path
    End If

    If Not TreeExpFolderExists(folderPath) Then folderPath = TreeExpDocumentsFolder()

    If Right$(folderPath, 1) = "\" Then folderPath = Left$(folderPath, Len(folderPath) - 1)

    baseName = caption

    If Not doc Is Nothing Then baseName = doc.Name

    dotPos = InStrRev(baseName, ".")

    If dotPos > 1 Then baseName = Left$(baseName, dotPos - 1)

    baseName = SafeFileName(baseName)

    If Len(baseName) = 0 Then baseName = "Export"

    TreeExpDefaultPath = folderPath & "\" & baseName & "_Tree.csv"

End Function


' Replaces the characters Windows does not allow in a file name
Private Function SafeFileName(ByVal fileName As String) As String

    Dim i As Long
    Dim ch As String
    Dim result As String

    For i = 1 To Len(fileName)

        ch = Mid$(fileName, i, 1)

        If InStr("\/:*?""<>|", ch) > 0 Then ch = "_"

        result = result & ch

    Next i

    SafeFileName = Trim$(result)

End Function


' CATIA's own Save dialog. Returns "" if it was cancelled.
Public Function TreeExpBrowse(ByVal title As String) As String

    On Error Resume Next

    ' 1 = CatFileSelectionModeSave
    TreeExpBrowse = CATIA.FileSelectionBox(title, "*.csv", 1)

End Function


' Opens a file with the program Windows uses for it

End Sub


'=========================================================
' EXPORT
' Reads the tree of a CATProduct or CATPart document and
' writes it to filePath as a CSV file (UTF-8, so Korean
' names open correctly in Excel).
' With bodiesOnly, the file holds one row for each body
' and nothing else.
' Returns False and fills errorText if anything fails.
'=========================================================

Public Function TreeExpExport( _
        ByVal doc As Object, _
        ByVal filePath As String, _
        ByVal includeFeatures As Boolean, _
        ByVal bodiesOnly As Boolean, _
        ByRef rowCount As Long, _
        ByRef errorText As String) As Boolean

    Dim kind As Integer
    Dim refDoc As Object
    Dim bom(0 To 2) As Byte

    TreeExpExport = False

    mRowCount = 0
    mWriteError = ""
    mFileOpen = False
    mIncludeFeatures = includeFeatures
    mBodiesOnly = bodiesOnly

    On Error GoTo Failed

    kind = TreeExpDocKind(doc)

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    mFileNo = FreeFile

    Open filePath For Binary Access Write As #mFileNo
    mFileOpen = True

    ' Marks the file as UTF-8 for Excel
    bom(0) = &HEF
    bom(1) = &HBB
    bom(2) = &HBF

    Put #mFileNo, , bom

    PutLine HeaderLine()

    If kind = 1 Then

        ' Features can only be read from parts that are
        ' fully loaded, so the assembly goes to design mode.
        If includeFeatures Or bodiesOnly Then LoadDesignMode doc

        WriteProductRow doc.Product, 0, doc, refDoc
        WalkProducts doc.Product, 1

    Else

        WritePartRoot doc

    End If

    Close #mFileNo
    mFileOpen = False

    If Len(mWriteError) > 0 Then
        errorText = mWriteError
        Exit Function
    End If

    rowCount = mRowCount

    TreeExpExport = True

    Exit Function

Failed:

    Select Case Err.Number
        Case 70, 75: errorText = TreeExpTxt("msgLocked")
        Case Else: errorText = Err.Description
    End Select

    On Error Resume Next

    If mFileOpen Then Close #mFileNo

    mFileOpen = False

End Function


Private Sub LoadDesignMode(ByVal doc As Object)

    On Error Resume Next

    ' 2 = DESIGN_MODE
    doc.Product.ApplyWorkMode 2

End Sub


'=========================================================
' PRODUCT STRUCTURE
'=========================================================

' Reads a text property and returns "" if CATIA refuses,
' for example on a component whose file is not loaded.
Private Function PropText( _
        ByVal source As Object, _
        ByVal propName As String) As String

    On Error Resume Next

    PropText = CStr(CallByName(source, propName, VbGet))

End Function


' Writes the row of one product, part or component.
' rootDoc is the document for the top row, Nothing below it.
' refDoc returns the document the row points to.
' Returns 1 = product, 2 = part, 3 = component, 0 = not loaded
Private Function WriteProductRow( _
        ByVal prod As Object, _
        ByVal level As Long, _
        ByVal rootDoc As Object, _
        ByRef refDoc As Object) As Integer

    Dim ref As Object
    Dim kind As Integer

    Dim partNumber As String
    Dim instName As String
    Dim refNumber As String
    Dim treeName As String
    Dim typeText As String
    Dim fileName As String
    Dim fullPath As String

    Set refDoc = Nothing

    partNumber = PropText(prod, "PartNumber")
    instName = PropText(prod, "Name")

    On Error Resume Next

    If Not rootDoc Is Nothing Then

        Set refDoc = rootDoc
        kind = 1
        instName = ""

    Else

        Set ref = prod.ReferenceProduct

        If Not ref Is Nothing Then Set refDoc = ref.Parent

        Select Case TypeName(refDoc)

            Case "PartDocument"
                kind = 2

            Case "ProductDocument"
                ' A component has no file of its own, so it
                ' points to the file of the product above it.
                refNumber = refDoc.Product.PartNumber

                If StrComp(refNumber, partNumber, vbBinaryCompare) = 0 Then
                    kind = 1
                Else
                    kind = 3
                End If

            Case Else
                kind = 0
                Set refDoc = Nothing

        End Select

    End If

    Select Case kind
        Case 1: typeText = TreeExpTxt("typeProduct")
        Case 2: typeText = TreeExpTxt("typePart")
        Case 3: typeText = TreeExpTxt("typeComponent")
        Case Else: typeText = TreeExpTxt("typeNotLoaded")
    End Select

    If kind = 1 Or kind = 2 Then
        fileName = refDoc.Name
        fullPath = refDoc.FullName
    End If

    ' Same wording as the CATIA tree: Part Number (Instance Name)
    If Len(partNumber) = 0 Then
        treeName = instName
    ElseIf Len(instName) = 0 Then
        treeName = partNumber
    Else
        treeName = partNumber & " (" & instName & ")"
    End If

    ' Remembered for the body rows of this part
    mPartNumber = partNumber
    mPartInstance = instName
    mPartFile = fileName
    mPartPath = fullPath

    If Not mBodiesOnly Then

        WriteRow level, treeName, typeText, partNumber, instName, _
                 PropText(prod, "Revision"), _
                 PropText(prod, "Definition"), _
                 PropText(prod, "Nomenclature"), _
                 PropText(prod, "DescriptionRef"), _
                 fileName, fullPath

    End If

    WriteProductRow = kind

End Function


' Writes everything below a product, level by level
Private Sub WalkProducts(ByVal parentProduct As Object, ByVal level As Long)

    Dim kids As Object
    Dim child As Object
    Dim refDoc As Object
    Dim total As Long
    Dim i As Long
    Dim kind As Integer

    On Error Resume Next

    Set kids = parentProduct.Products

    If kids Is Nothing Then Exit Sub

    total = kids.Count

    For i = 1 To total

        Set child = Nothing
        Set child = kids.Item(i)

        If Not child Is Nothing Then

            kind = WriteProductRow(child, level, Nothing, refDoc)

            If kind = 2 Then
                If mIncludeFeatures Or mBodiesOnly Then WritePartContents refDoc.Part, level + 1
            Else
                WalkProducts child, level + 1
            End If

        End If

    Next i

End Sub

' Top row and contents of a CATPart opened in its own window
Private Sub WritePartRoot(ByVal doc As Object)

    Dim partNumber As String

    On Error Resume Next

    partNumber = PropText(doc.Product, "PartNumber")

    If Len(partNumber) = 0 Then partNumber = doc.Part.Name

    mPartNumber = partNumber
    mPartInstance = ""
    mPartFile = doc.Name
    mPartPath = doc.FullName

    If Not mBodiesOnly Then

        WriteRow 0, partNumber, TreeExpTxt("typePart"), partNumber, "", _
                 PropText(doc.Product, "Revision"), _
                 PropText(doc.Product, "Definition"), _
                 PropText(doc.Product, "Nomenclature"), _
                 PropText(doc.Product, "DescriptionRef"), _
                 mPartFile, mPartPath

    End If

    WritePartContents doc.Part, 1

End Sub


' Bodies, geometrical sets and ordered geometrical sets of a part
Private Sub WritePartContents(ByVal partObj As Object, ByVal level As Long)

    If partObj Is Nothing Then Exit Sub

    WalkSet partObj, "Bodies", level, True
    WalkSet partObj, "HybridBodies", level, True
    WalkSet partObj, "OrderedGeometricalSets", level, True

End Sub


' Writes one row for each item of a collection, for example
' the Shapes of a body. If the items can hold other items
' (bodies and sets), their contents are written below them.
Private Sub WalkSet( _
        ByVal owner As Object, _
        ByVal setName As String, _
        ByVal level As Long, _
        ByVal isContainer As Boolean)

    Dim items As Object
    Dim node As Object
    Dim total As Long
    Dim i As Long

    ' Features and sketches are never bodies
    If mBodiesOnly And Not isContainer Then Exit Sub

    On Error Resume Next

    Set items = CallByName(owner, setName, VbGet)

    If items Is Nothing Then Exit Sub

    total = items.Count

    For i = 1 To total

        Set node = Nothing
        Set node = items.Item(i)

        If Not node Is Nothing Then

            If Not mBodiesOnly Then

                WriteRow level, PropText(node, "Name"), TypeName(node), _
                         "", "", "", "", "", "", "", ""

            ElseIf TypeName(node) = "Body" Then

                ' The body name, with the part it belongs to
                WriteRow level, PropText(node, "Name"), "Body", _
                         mPartNumber, mPartInstance, "", "", "", "", _
                         mPartFile, mPartPath

            End If

            If isContainer Then WalkContainer node, level + 1

        End If

    Next i

End Sub


Private Sub WalkContainer(ByVal container As Object, ByVal level As Long)

    Select Case TypeName(container)

        Case "Body"
            WalkSet container, "Shapes", level, False
            WalkSet container, "Sketches", level, False
            WalkSet container, "HybridShapes", level, False
            WalkSet container, "HybridBodies", level, True
            WalkSet container, "OrderedGeometricalSets", level, True

        Case "HybridBody"
            WalkSet container, "HybridShapes", level, False
            WalkSet container, "HybridSketches", level, False
            WalkSet container, "HybridBodies", level, True
            WalkSet container, "Bodies", level, True

        Case "OrderedGeometricalSet"
            WalkSet container, "HybridShapes", level, False
            WalkSet container, "OrderedSketches", level, False
            WalkSet container, "OrderedGeometricalSets", level, True
            WalkSet container, "Bodies", level, True

    End Select

End Sub

' Writes one line of text to the file as UTF-8.
' The first error is kept and reported when the export ends.
Private Sub PutLine(ByVal lineText As String)

    Dim data() As Byte

    If Len(mWriteError) > 0 Then Exit Sub

    On Error GoTo Failed

    data = Utf8Bytes(lineText & vbCrLf)

    Put #mFileNo, , data

    Exit Sub

Failed:

    mWriteError = Err.Description

End Sub


' Converts text to UTF-8 bytes. The text must not be empty.
Private Function Utf8Bytes(ByVal source As String) As Byte()

    Dim data() As Byte
    Dim total As Long
    Dim i As Long
    Dim p As Long
    Dim cp As Long
    Dim low As Long

    total = Len(source)

    ReDim data(0 To total * 3 + 3)

    i = 1
    p = 0

    Do While i <= total

        cp = AscW(Mid$(source, i, 1)) And &HFFFF&

        ' Two-part characters (surrogate pairs) become one code
        If cp >= &HD800& And cp <= &HDBFF& And i < total Then

            low = AscW(Mid$(source, i + 1, 1)) And &HFFFF&

            If low >= &HDC00& And low <= &HDFFF& Then
                cp = &H10000 + (cp - &HD800&) * &H400& + (low - &HDC00&)
                i = i + 1
            End If

        End If

        If cp < &H80& Then

            data(p) = cp
            p = p + 1

        ElseIf cp < &H800& Then

            data(p) = &HC0& Or (cp \ &H40&)
            data(p + 1) = &H80& Or (cp And &H3F&)
            p = p + 2

        ElseIf cp < &H10000 Then

            data(p) = &HE0& Or (cp \ &H1000&)
            data(p + 1) = &H80& Or ((cp \ &H40&) And &H3F&)
            data(p + 2) = &H80& Or (cp And &H3F&)
            p = p + 3

        Else

            data(p) = &HF0& Or (cp \ &H40000)
            data(p + 1) = &H80& Or ((cp \ &H1000&) And &H3F&)
            data(p + 2) = &H80& Or ((cp \ &H40&) And &H3F&)
            data(p + 3) = &H80& Or (cp And &H3F&)
            p = p + 4

        End If

        i = i + 1

    Loop

    ReDim Preserve data(0 To p - 1)

    Utf8Bytes = data

End Function

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

' The logo picture is stored below as text.
' The form shows it with:
'     TreeExpLoadLogo Me.Controls("imgLogo")

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function TreeExpLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    TreeExpLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_tree_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    TreeExpLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

Columns in the file

ColumnWhat it holds
Level0 for the top row, 1 for its children, and so on. Use it to filter or rebuild the tree.
TreeThe name as CATIA shows it, Part Number (Instance Name), indented 4 spaces per level.
TypeProduct, Part, Component or Not loaded. For rows inside a part it is CATIA's own type name, such as Body, Pad, Pocket or Sketch.
Part Number, Instance NameThe two names separately, for sorting and lookups.
Revision, Definition, Nomenclature, DescriptionThe standard product properties.
File Name, File PathThe CATProduct or CATPart file behind the row. Empty for components, which have no file of their own.

Good to know

  • The picked window is brought to the front in CATIA when you press Export Tree. That is how the macro gets the right document.
  • If a file with the same name already exists, it is replaced. If it is open in Excel, the status line asks you to close it.
  • The file is saved as UTF-8, so Korean part names open correctly when you double-click it into Excel.
  • Excel reformats some values when it opens a .csv. A part number like 00123 shows as 123. The file itself keeps the full text. To see it unchanged, use Data, From Text/CSV in Excel.
  • With body names only ticked, the Tree column holds the body name with no indent, Type is Body, and the features option is greyed out because it has no effect. Bodies inside geometrical sets are included.
  • Parts in visualization mode or with a broken link show as Not loaded. Tick the part contents box to load them in design mode.
  • Inside a part, rows are grouped by kind (features, then sketches, then sets), so their order can differ slightly from the tree on screen. A sketch used by a pad is listed with the body's sketches.
  • Results and errors appear on the status line, with no pop-up boxes, so Korean text displays correctly.
