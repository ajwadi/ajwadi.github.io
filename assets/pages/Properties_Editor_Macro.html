CATIA Properties Editor

Lists every part and sub-assembly of the active document with its Part Number, Revision, Definition, Nomenclature and Description. Edit one row in the window, or export everything to a CSV, edit it in Excel and import it back. Two code blocks to paste: the form and the module.

What it does

  • Load fills the list with every part and sub-assembly, each part number once.
  • Click a row to put its values in the five fields. Change them and click Apply to Row.
  • Export CSV writes all rows to PartNumber_Properties.csv, including every custom (user-added) property as its own column.
  • Import CSV reads the file back and writes the changed values into CATIA. Custom properties that do not exist yet are added as text properties.
  • Nothing is saved for you. The macro changes the properties in the session. Save the documents yourself when you are happy with the result.
  • English / Korean button in the top right corner. The language is remembered for next time.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with Prop, so it does not clash with the other macros in the same VBA project.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmPropertiesEditor. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. In the Properties window set its (Name) to PropertiesEditor, then paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATProduct or CATPart, then run CATMain from the PropertiesEditor module and click Load.

First run: this code was written and checked for structure, but not run inside CATIA. Try it on a copy of a small assembly first: Load, Export CSV, change two cells in Excel, Import CSV, and check the parts in CATIA.

Private Sub DoAction(ByVal actionId As Long)

    Dim message As String
    Dim ok As Boolean

    If mBusy Then Exit Sub

    If Not DocReady() Then
        ShowDocStatus
        Exit Sub
    End If

    SaveInputs

    SetBusy True

    ShowStatus PropTxt("stWorking")

    On Error GoTo Failed

    ok = PropRun(Me, actionId, message)

    On Error Resume Next

    CATIA.RefreshDisplay = True
    CATIA.DisplayFileAlerts = True

    SetBusy False

    ShowStatus message

    Exit Sub

Failed:

    message = Err.Description

    On Error Resume Next

    CATIA.RefreshDisplay = True
    CATIA.DisplayFileAlerts = True

    SetBusy False

    ShowStatus PropFmt(PropTxt("msgError"), message)

End Sub

PropertiesEditor

The long block of letters and numbers at the bottom is the credit image. Do not edit it.

Option Explicit

'=========================================================
' CATIA PROPERTIES EDITOR - MAIN MODULE
' Module name: PropertiesEditor
' Run CATMain to open the window.
'=========================================================

Private Const REG_APP As String = "CatiaPropertiesEditor"
Private Const REG_SEC As String = "Settings"

' "EN" or "KO"
Public gPropLang As String

' The reference products shown in the list, in the same order
Private mProds As Collection


'=========================================================
' ENTRY POINT
'=========================================================

Sub CATMain()

    PropLoadLanguage
    frmPropertiesEditor.Show

End Sub

'=========================================================
' BUTTONS
' 1 = Load, 2 = Apply to Row, 3 = Export CSV, 4 = Import CSV
'=========================================================

Public Function PropRun( _
        ByVal frm As Object, _
        ByVal actionId As Long, _
        ByRef message As String) As Boolean

    Select Case actionId
        Case 1: PropRun = LoadRows(frm, message)
        Case 2: PropRun = ApplyRow(frm, message)
        Case 3: PropRun = ExportCsv(frm, message)
        Case 4: PropRun = ImportCsv(frm, message)
    End Select

End Function


'=========================================================
' LOAD
'=========================================================

Private Function LoadRows(ByVal frm As Object, ByRef message As String) As Boolean

    Dim d As Object
    Dim seen As Object
    Dim lst As Object

    Set d = CATIA.ActiveDocument
    Set mProds = New Collection
    Set seen = CreateObject("Scripting.Dictionary")
    Set lst = frm.Controls("lstRows")

    lst.Clear

    AddProd lst, d.Product, seen

    If TypeName(d) = "ProductDocument" Then WalkProds lst, d.Product, seen

    message = PropFmt(PropTxt("msgLoaded"), CStr(mProds.Count))

    LoadRows = True

End Function


Private Sub WalkProds(ByVal lst As Object, ByVal prod As Object, ByVal seen As Object)

    Dim kids As Object
    Dim child As Object
    Dim rp As Object
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set rp = RefOf(child)

        If Not rp Is Nothing Then
            AddProd lst, rp, seen
            WalkProds lst, child, seen
        End If

    Next i

End Sub


' Adds one row. Each part number is listed once.
Private Sub AddProd(ByVal lst As Object, ByVal rp As Object, ByVal seen As Object)

    Dim key As String

    key = UCase$(PropOf(rp, 0))

    If seen.Exists(key) Then Exit Sub

    seen.Add key, 1

    mProds.Add rp

    lst.AddItem PropOf(rp, 0)

    FillRow lst, lst.ListCount - 1, rp

End Sub


Private Sub FillRow(ByVal lst As Object, ByVal rowIndex As Long, ByVal rp As Object)

    Dim c As Long

    For c = 0 To 4
        lst.List(rowIndex, c) = PropOf(rp, c)
    Next c

    lst.List(rowIndex, 5) = FileOf(rp)

End Sub


' 0 = Part Number, 1 = Revision, 2 = Definition,
' 3 = Nomenclature, 4 = Description
Private Function PropOf(ByVal rp As Object, ByVal which As Long) As String

    On Error Resume Next

    Select Case which
        Case 0: PropOf = rp.PartNumber
        Case 1: PropOf = rp.Revision
        Case 2: PropOf = rp.Definition
        Case 3: PropOf = rp.Nomenclature
        Case 4: PropOf = rp.DescriptionRef
    End Select

End Function


Private Sub SetProp(ByVal rp As Object, ByVal which As Long, ByVal newValue As String)

    On Error Resume Next

    Select Case which
        Case 0
            ' A part number is never cleared
            If Len(newValue) > 0 Then rp.PartNumber = newValue
        Case 1: rp.Revision = newValue
        Case 2: rp.Definition = newValue
        Case 3: rp.Nomenclature = newValue
        Case 4: rp.DescriptionRef = newValue
    End Select

End Sub


Private Function FileOf(ByVal rp As Object) As String

    Dim d As Object

    On Error Resume Next

    Set d = rp.Parent

    If Right$(TypeName(d), 8) = "Document" Then FileOf = d.Name

End Function

    If mProds Is Nothing Then Exit Sub

Private Function ApplyRow(ByVal frm As Object, ByRef message As String) As Boolean

    Dim rp As Object
    Dim idx As Long

    ApplyRow = False

    If mProds Is Nothing Then
        message = PropTxt("msgLoadFirst")
        Exit Function
    End If

    idx = frm.Controls("lstRows").ListIndex

    If idx < 0 Or idx > mProds.Count - 1 Then
        message = PropTxt("msgPickRow")
        Exit Function
    End If

    Set rp = mProds.Item(idx + 1)

    SetProp rp, 0, CtlText(frm, "txtPN")
    SetProp rp, 1, CtlText(frm, "txtRev")
    SetProp rp, 2, CtlText(frm, "txtDef")
    SetProp rp, 3, CtlText(frm, "txtNom")
    SetProp rp, 4, CtlText(frm, "txtDesc")

    FillRow frm.Controls("lstRows"), idx, rp

    message = PropFmt(PropTxt("msgApplied"), PropOf(rp, 0))

    ApplyRow = True

End Function


'=========================================================
' CUSTOM PROPERTIES
'=========================================================

' Value of a custom property. found is False when the part has none.
Private Function UserValue( _
        ByVal rp As Object, _
        ByVal propName As String, _
        ByRef found As Boolean) As String

    Dim ps As Object
    Dim p As Object
    Dim j As Long

    found = False

    On Error Resume Next

    Set ps = rp.UserRefProperties

    If ps Is Nothing Then Exit Function

    For j = 1 To ps.Count

        Set p = ps.Item(j)

        If StrComp(ShortName(p.Name), propName, vbTextCompare) = 0 Then
            UserValue = p.ValueAsString
            found = True
            Exit Function
        End If

    Next j

End Function


' Changes a custom property, or adds it as text when it is new
Private Sub SetUserValue( _
        ByVal rp As Object, _
        ByVal propName As String, _
        ByVal newValue As String)

    Dim ps As Object
    Dim p As Object
    Dim j As Long

    On Error Resume Next

    Set ps = rp.UserRefProperties

    If ps Is Nothing Then Exit Sub

    For j = 1 To ps.Count

        Set p = ps.Item(j)

        If StrComp(ShortName(p.Name), propName, vbTextCompare) = 0 Then
            If p.ValueAsString <> newValue Then p.ValuateFromString newValue
            Exit Sub
        End If

    Next j

    If Len(newValue) > 0 Then ps.CreateString propName, newValue

End Sub


'=========================================================
' EXPORT CSV
'=========================================================

Private Function ExportCsv(ByVal frm As Object, ByRef message As String) As Boolean

    Dim names As Object
    Dim nameKeys As Variant
    Dim rp As Object
    Dim ps As Object
    Dim outFolder As String
    Dim target As String
    Dim content As String
    Dim lineText As String
    Dim propName As String
    Dim found As Boolean
    Dim i As Long
    Dim j As Long
    Dim c As Long

    ExportCsv = False

    If mProds Is Nothing Then
        If Not LoadRows(frm, message) Then Exit Function
    End If

    outFolder = WithSlash(CtlText(frm, "txtOut"))

    If Not FolderExists(outFolder) Then
        message = PropTxt("msgNoOut")
        Exit Function
    End If

    ' Every custom property name used anywhere in the assembly
    Set names = CreateObject("Scripting.Dictionary")

    For i = 1 To mProds.Count

        Set rp = mProds.Item(i)
        Set ps = Nothing

        On Error Resume Next

        Set ps = rp.UserRefProperties

        If Not ps Is Nothing Then

            For j = 1 To ps.Count

                propName = ShortName(ps.Item(j).Name)

                If Len(propName) > 0 Then
                    If Not names.Exists(LCase$(propName)) Then names.Add LCase$(propName), propName
                End If

            Next j

        End If

        On Error GoTo 0

    Next i

    ' The column titles stay in English so the file can be imported again
    content = "Key,Part Number,Revision,Definition,Nomenclature,Description"

    nameKeys = names.Keys

    For j = 0 To names.Count - 1
        content = content & "," & Csv(CStr(names.Item(nameKeys(j))))
    Next j

    content = content & vbCrLf

    For i = 1 To mProds.Count

        Set rp = mProds.Item(i)

        lineText = Csv(PropOf(rp, 0))

        For c = 0 To 4
            lineText = lineText & "," & Csv(PropOf(rp, c))
        Next c

        For j = 0 To names.Count - 1
            lineText = lineText & "," & Csv(UserValue(rp, CStr(names.Item(nameKeys(j))), found))
        Next j

        content = content & lineText & vbCrLf

    Next i

    target = outFolder & CleanName(PropOf(mProds.Item(1), 0)) & "_Properties.csv"

    If Not WriteTextFile(target, content) Then
        message = PropTxt("msgWriteFail")
        Exit Function
    End If

    frm.Controls("txtFile").Text = target

    message = PropFmt(PropTxt("msgExported"), CStr(mProds.Count), target)

    ExportCsv = True

End Function


'=========================================================
' IMPORT CSV
'=========================================================

Private Function ImportCsv(ByVal frm As Object, ByRef message As String) As Boolean

    Dim index As Object
    Dim head As Collection
    Dim f As Collection
    Dim rp As Object
    Dim lines As Variant
    Dim content As String
    Dim filePath As String
    Dim key As String
    Dim colName As String
    Dim cellText As String
    Dim r As Long
    Dim c As Long
    Dim i As Long
    Dim updated As Long
    Dim missing As Long
    Dim note As String

    ImportCsv = False

    filePath = CtlText(frm, "txtFile")

    If Not FileExists(filePath) Then
        message = PropTxt("msgNoFile")
        Exit Function
    End If

    If mProds Is Nothing Then
        If Not LoadRows(frm, message) Then Exit Function
    End If

    content = ReadTextFile(filePath)

    If Len(content) > 0 Then
        If AscW(Left$(content, 1)) = -257 Then content = Mid$(content, 2)
    End If

    content = Replace(content, vbCrLf, vbLf)
    content = Replace(content, vbCr, vbLf)

    lines = Split(content, vbLf)

    If UBound(lines) < 1 Then
        message = PropTxt("msgBadFile")
        Exit Function
    End If

    Set head = CsvSplit(CStr(lines(0)))

    If StrComp(Trim$(CStr(head.Item(1))), "Key", vbTextCompare) <> 0 Then
        message = PropTxt("msgBadFile")
        Exit Function
    End If

    ' The keys are the part numbers as they are now, before any change
    Set index = CreateObject("Scripting.Dictionary")

    For i = 1 To mProds.Count
        key = UCase$(PropOf(mProds.Item(i), 0))
        If Not index.Exists(key) Then index.Add key, i
    Next i

    For r = 1 To UBound(lines)

        If Len(Trim$(CStr(lines(r)))) > 0 Then

            Set f = CsvSplit(CStr(lines(r)))

            key = UCase$(Trim$(CStr(f.Item(1))))

            If index.Exists(key) Then

                Set rp = mProds.Item(CLng(index.Item(key)))

                Say frm, PropTxt("stWorking") & " " & key

                For c = 2 To head.Count

                    If c <= f.Count Then

                        colName = Trim$(CStr(head.Item(c)))
                        cellText = CStr(f.Item(c))

                        Select Case LCase$(colName)
                            Case "part number": SetProp rp, 0, Trim$(cellText)
                            Case "revision": SetProp rp, 1, cellText
                            Case "definition": SetProp rp, 2, cellText
                            Case "nomenclature": SetProp rp, 3, cellText
                            Case "description": SetProp rp, 4, cellText
                            Case "": ' Empty column title, ignored
                            Case Else: SetUserValue rp, colName, cellText
                        End Select

                    End If

                Next c

                updated = updated + 1

            Else

                missing = missing + 1

            End If

        End If

    Next r

    LoadRows frm, note

    message = PropFmt(PropTxt("msgImported"), CStr(updated), CStr(missing))

    ImportCsv = True

End Function

' "" = nothing open, otherwise Product, Part, Drawing or Other
Public Function PropDocKind() As String

    Dim t As String

    On Error Resume Next

    If CATIA.Documents.Count > 0 Then t = TypeName(CATIA.ActiveDocument)

    On Error GoTo 0

    Select Case t
        Case "ProductDocument": PropDocKind = "Product"
        Case "PartDocument": PropDocKind = "Part"
        Case "DrawingDocument": PropDocKind = "Drawing"
        Case "": PropDocKind = ""
        Case Else: PropDocKind = "Other"
    End Select

End Function


Public Function PropDocName() As String

    On Error Resume Next

    PropDocName = CATIA.ActiveDocument.Name

End Function


' Folder picker. Returns "" when cancelled.
Public Function PropBrowseFolder(ByVal title As String) As String

    Dim sh As Object
    Dim picked As Object

    On Error Resume Next

    Set sh = CreateObject("Shell.Application")
    Set picked = sh.BrowseForFolder(0, title, 1)

    If Not picked Is Nothing Then PropBrowseFolder = picked.Self.Path

End Function

' Replaces characters that are not allowed in a file name
Private Function CleanName(ByVal rawName As String) As String

    Dim i As Long
    Dim ch As String
    Dim code As Long
    Dim result As String

    For i = 1 To Len(rawName)

        ch = Mid$(rawName, i, 1)
        code = AscW(ch)

        If InStr("\/:*?""<>|", ch) > 0 Or (code >= 0 And code < 32) Then
            result = result & "_"
        Else
            result = result & ch
        End If

    Next i

    If Len(result) = 0 Then result = "Unnamed"

    CleanName = result

End Function

' Splits one CSV line into its fields
Private Function CsvSplit(ByVal lineText As String) As Collection

    Dim fields As New Collection
    Dim i As Long
    Dim ch As String
    Dim cur As String
    Dim inQuotes As Boolean

    i = 1

    Do While i <= Len(lineText)

        ch = Mid$(lineText, i, 1)

        If inQuotes Then
            If ch = """" Then
                If Mid$(lineText, i + 1, 1) = """" Then
                    cur = cur & """"
                    i = i + 1
                Else
                    inQuotes = False
                End If
            Else
                cur = cur & ch
            End If
        ElseIf ch = """" Then
            inQuotes = True
        ElseIf ch = "," Then
            fields.Add cur
            cur = ""
        Else
            cur = cur & ch
        End If

        i = i + 1

    Loop

    fields.Add cur

    Set CsvSplit = fields

End Function

' Fills docs (a Dictionary) with every loaded document under prod
Private Sub CollectDocs( _
        ByVal prod As Object, _
        ByVal docs As Object, _
        ByVal wantParts As Boolean, _
        ByVal wantProducts As Boolean)

    Dim kids As Object
    Dim child As Object
    Dim d As Object
    Dim kind As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set d = DocOf(child)

        If Not d Is Nothing Then

            kind = TypeName(d)

            If kind = "PartDocument" And wantParts Then AddDoc docs, d
            If kind = "ProductDocument" And wantProducts Then AddDoc docs, d

            CollectDocs child, docs, wantParts, wantProducts

        End If

    Next i

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

'     PropLoadLogo Me.Controls("imgLogo")

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function PropLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    PropLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    PropLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

Rules for the CSV file

  • The first column, Key, is the part number at the time of the export. Do not change it. It is how each row finds its part. To rename a part, change the Part Number column.
  • After an import that changed part numbers, export again before the next round of edits, so the keys match.
  • The column titles in the first row stay in English in both languages. Do not rename the first six.
  • An empty cell clears that property, except Part Number, which is never cleared.
  • To add a new custom property for all parts, add a column with the property name as its title.
  • If your properties contain Korean text, save from Excel as "CSV UTF-8 (Comma delimited)".

Known limitations

  • A VBA window has no true spreadsheet grid, so the list is read-only and editing is done in the fields below it. Bulk edits go through the CSV.
  • One row is selected at a time. To give many parts the same value, use the CSV.
  • Parts that are not loaded (missing files) are not listed.
  • A cell that contains a line break is not supported on import.
  • Custom properties that are numbers or lengths are changed with the text you type, in the unit CATIA shows. New custom properties are always created as text.
  • CATIA does not allow two documents with the same part number in one session. If an import would create a duplicate, CATIA rejects that one change and the old part number stays.
  • The window is modal, so CATIA cannot be clicked while it is open. Anything that must be selected in CATIA has to be selected before running the macro.
  • If the credit image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
