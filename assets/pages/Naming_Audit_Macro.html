CATIA Naming Audit

Audits the active assembly for naming and housekeeping problems: part numbers that are almost duplicates, instance names that break the convention, part numbers that do not match the file name or your pattern, default names, empty parts and unsaved files. Two code blocks to paste: the form and the module.

What it does

  • Seven checks, each with its own tick box, plus an optional part number pattern.
  • Pattern check. Type a pattern such as #####-### and every part number that does not fit is listed. # is one digit, ? is any one character, * is anything.
  • Near-duplicate part numbers. CATIA already blocks exact duplicates, so this check finds the ones it lets through: numbers that differ only by spaces or by upper and lower case.
  • Results in a list, and Export CSV saves them as DocumentName_Naming.csv and opens the file.
  • Each document is checked once. Instance names are checked for every instance.
  • English / Korean button in the top right corner. The language is remembered for next time.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with Aud, so it does not clash with the other macros in the same VBA project.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmNamingAudit. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. In the Properties window set its (Name) to NamingAudit, then paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATProduct or CATPart, then run CATMain from the NamingAudit module and click Run Audit.

First run: this code was written and checked for structure, but not run inside CATIA. Try it on a small assembly first, with the pattern field empty.

NamingAudit

The long block of letters and numbers at the bottom is the credit image. Do not edit it.

Option Explicit

'=========================================================
' CATIA NAMING AUDIT - MAIN MODULE
' Module name: NamingAudit
' Run CATMain to open the window.
'=========================================================

Private Const REG_APP As String = "CatiaNamingAudit"
Private Const REG_SEC As String = "Settings"

' "EN" or "KO"
Public gAudLang As String

Private mRows As Collection

Private mDup As Boolean
Private mInst As Boolean
Private mFile As Boolean
Private mDefault As Boolean
Private mRev As Boolean
Private mEmpty As Boolean
Private mSaved As Boolean
Private mPattern As String


'=========================================================
' ENTRY POINT
'=========================================================

Sub CATMain()

    AudLoadLanguage
    frmNamingAudit.Show

End Sub

'=========================================================
' BUTTONS
' 1 = Run Audit, 2 = Export CSV
'=========================================================

Public Function AudRun( _
        ByVal frm As Object, _
        ByVal actionId As Long, _
        ByRef message As String) As Boolean

    Dim d As Object
    Dim seen As Object
    Dim numbers As Object

    If actionId = 2 Then
        AudRun = ExportIssues(frm, "_Naming", message)
        Exit Function
    End If

    Set d = CATIA.ActiveDocument
    Set mRows = New Collection

    frm.Controls("lstRows").Clear

    mDup = CtlOn(frm, "chkDup")
    mInst = CtlOn(frm, "chkInst")
    mFile = CtlOn(frm, "chkFile")
    mDefault = CtlOn(frm, "chkDefault")
    mRev = CtlOn(frm, "chkRev")
    mEmpty = CtlOn(frm, "chkEmpty")
    mSaved = CtlOn(frm, "chkSaved")
    mPattern = CtlText(frm, "txtPattern")

    Set seen = CreateObject("Scripting.Dictionary")
    Set numbers = CreateObject("Scripting.Dictionary")

    If TypeName(d) = "ProductDocument" Then
        On Error Resume Next
        d.Product.ApplyWorkMode 2
        On Error GoTo 0
    End If

    seen.Add UCase$(d.FullName), 1

    AuditDoc frm, d, d.Name, numbers

    If TypeName(d) = "ProductDocument" Then WalkAudit frm, d.Product, d.Product.PartNumber, seen, numbers

    message = AudFmt(AudTxt("msgDone"), CStr(mRows.Count))

    AudRun = True

End Function


Private Sub WalkAudit( _
        ByVal frm As Object, _
        ByVal prod As Object, _
        ByVal pathText As String, _
        ByVal seen As Object, _
        ByVal numbers As Object)

    Dim kids As Object
    Dim child As Object
    Dim rp As Object
    Dim d As Object
    Dim childPath As String
    Dim instName As String
    Dim partNo As String
    Dim key As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)

        instName = SafeName(child)
        childPath = pathText & " / " & instName

        Set rp = RefOf(child)

        If rp Is Nothing Then

            AddIssue frm, AudTxt("kLink"), childPath, AudTxt("dNotLoaded")

        Else

            partNo = rp.PartNumber

            If mInst Then
                If Not InstanceNameOk(instName, partNo) Then
                    AddIssue frm, AudTxt("kInst"), childPath, AudFmt(AudTxt("dInst"), instName, partNo)
                End If
            End If

            Set d = DocOf(child)

            If Not d Is Nothing Then

                key = UCase$(d.FullName)

                If Not seen.Exists(key) Then

                    seen.Add key, 1

                    Say frm, AudTxt("stItem") & " " & d.Name

                    AuditDoc frm, d, childPath, numbers

                End If

            End If

            WalkAudit frm, child, childPath, seen, numbers

        End If

    Next i

End Sub


' True when the instance name is the part number, a dot and a number
Private Function InstanceNameOk(ByVal instName As String, ByVal partNo As String) As Boolean

    Dim tail As String

    If Len(instName) < Len(partNo) + 2 Then Exit Function

    If Left$(instName, Len(partNo) + 1) <> partNo & "." Then Exit Function

    tail = Mid$(instName, Len(partNo) + 2)

    InstanceNameOk = IsWholeNumber(tail)

End Function


Private Function IsWholeNumber(ByVal textValue As String) As Boolean

    Dim i As Long

    If Len(textValue) = 0 Then Exit Function

    For i = 1 To Len(textValue)
        If InStr("0123456789", Mid$(textValue, i, 1)) = 0 Then Exit Function
    Next i

    IsWholeNumber = True

End Function


' True when the text fits the pattern. A pattern that VBA
' cannot read counts as a fit, so it never floods the list.
Private Function FitsPattern(ByVal textValue As String, ByVal pattern As String) As Boolean

    FitsPattern = True

    On Error Resume Next

    FitsPattern = (textValue Like pattern)

End Function


'=========================================================
' CHECKS ON ONE DOCUMENT
'=========================================================

Private Sub AuditDoc( _
        ByVal frm As Object, _
        ByVal d As Object, _
        ByVal whereText As String, _
        ByVal numbers As Object)

    Dim partNo As String
    Dim rev As String
    Dim fileBase As String
    Dim key As String
    Dim docPath As String
    Dim isSaved As Boolean

    On Error Resume Next

    partNo = d.Product.PartNumber
    rev = d.Product.Revision
    docPath = d.Path

    isSaved = True
    isSaved = d.Saved

    On Error GoTo 0

    fileBase = StripExt(d.Name)

    If mDup Then

        key = UCase$(Replace(Trim$(partNo), " ", ""))

        If numbers.Exists(key) Then
            If CStr(numbers.Item(key)) <> d.Name Then
                AddIssue frm, AudTxt("kDup"), whereText, AudFmt(AudTxt("dDup"), partNo, CStr(numbers.Item(key)))
            End If
        Else
            numbers.Add key, d.Name
        End If

    End If

    If mFile Then
        If StrComp(partNo, fileBase, vbTextCompare) <> 0 Then
            AddIssue frm, AudTxt("kFile"), whereText, AudFmt(AudTxt("dFile"), partNo, d.Name)
        End If
    End If

    If mDefault Then
        If (partNo Like "Part#*") Or (partNo Like "Product#*") Then
            AddIssue frm, AudTxt("kDefault"), whereText, AudFmt(AudTxt("dDefault"), partNo)
        End If
    End If

    If Len(mPattern) > 0 Then
        If Not FitsPattern(partNo, mPattern) Then
            AddIssue frm, AudTxt("kPattern"), whereText, AudFmt(AudTxt("dPattern"), partNo, mPattern)
        End If
    End If

    If mRev Then
        If Len(Trim$(rev)) = 0 Then AddIssue frm, AudTxt("kRev"), whereText, AudTxt("dRev")
    End If

    If mSaved Then
        If Len(docPath) = 0 Then
            AddIssue frm, AudTxt("kSaved"), whereText, AudTxt("dNeverSaved")
        ElseIf Not isSaved Then
            AddIssue frm, AudTxt("kSaved"), whereText, AudTxt("dModified")
        End If
    End If

    If mEmpty Then
        If TypeName(d) = "PartDocument" Then
            If IsEmptyPart(d) Then AddIssue frm, AudTxt("kEmpty"), whereText, AudTxt("dEmpty")
        End If
    End If

End Sub


' True when the part holds no solid feature, surface or wireframe
Private Function IsEmptyPart(ByVal d As Object) As Boolean

    Dim prt As Object
    Dim total As Long
    Dim i As Long

    On Error GoTo Failed

    Set prt = d.Part

    For i = 1 To prt.Bodies.Count
        total = total + prt.Bodies.Item(i).Shapes.Count
    Next i

    For i = 1 To prt.HybridBodies.Count
        total = total + prt.HybridBodies.Item(i).HybridShapes.Count
        total = total + prt.HybridBodies.Item(i).HybridBodies.Count
    Next i

    IsEmptyPart = (total = 0)

    Exit Function

Failed:

    IsEmptyPart = False

End Function

Private Sub AddIssue( _
        ByVal frm As Object, _
        ByVal checkName As String, _

' Saves the list as a CSV file
Private Function ExportIssues( _
        ByVal frm As Object, _
        ByVal fileTag As String, _
        ByRef message As String) As Boolean

    Dim outFolder As String
    Dim target As String
    Dim content As String
    Dim rowData As Variant
    Dim i As Long

    ExportIssues = False

    If mRows Is Nothing Then
        message = AudTxt("msgRunFirst")
        Exit Function
    End If

    outFolder = WithSlash(CtlText(frm, "txtOut"))

    If Not FolderExists(outFolder) Then
        message = AudTxt("msgNoOut")
        Exit Function
    End If

    content = Csv(AudTxt("hCheck")) & "," & Csv(AudTxt("hWhere")) & "," & Csv(AudTxt("hDetail")) & vbCrLf

    For i = 1 To mRows.Count
        rowData = mRows.Item(i)
        content = content & Csv(CStr(rowData(0))) & "," & Csv(CStr(rowData(1))) & "," & Csv(CStr(rowData(2))) & vbCrLf
    Next i

    target = outFolder & CleanName(StripExt(AudDocName())) & fileTag & ".csv"

    If Not WriteTextFile(target, content) Then
        message = AudTxt("msgWriteFail")
        Exit Function
    End If

    OpenFile target

    message = AudFmt(AudTxt("msgExported"), CStr(mRows.Count), target)

    ExportIssues = True

End Function

' "" = nothing open, otherwise Product, Part, Drawing or Other
Public Function AudDocKind() As String

    Dim t As String

    On Error Resume Next

    If CATIA.Documents.Count > 0 Then t = TypeName(CATIA.ActiveDocument)

    On Error GoTo 0

    Select Case t
        Case "ProductDocument": AudDocKind = "Product"
        Case "PartDocument": AudDocKind = "Part"
        Case "DrawingDocument": AudDocKind = "Drawing"
        Case "": AudDocKind = ""
        Case Else: AudDocKind = "Other"
    End Select

End Function

' Replaces characters that are not allowed in a file name
Private Function CleanName(ByVal rawName As String) As String

    Dim i As Long
    Dim ch As String
    Dim code As Long
    Dim result As String

    For i = 1 To Len(rawName)

        ch = Mid$(rawName, i, 1)
        code = AscW(ch)

        If InStr("\/:*?""<>|", ch) > 0 Or (code >= 0 And code < 32) Then
            result = result & "_"
        Else
            result = result & ch
        End If

    Next i

    If Len(result) = 0 Then result = "Unnamed"

    CleanName = result

End Function


Private Function StripExt(ByVal fileName As String) As String

    Dim p As Long

    p = InStrRev(fileName, ".")

    If p > 1 Then
        StripExt = Left$(fileName, p - 1)
    Else
        StripExt = fileName
    End If

End Function

' One CSV field, always in quotes
Private Function Csv(ByVal fieldText As String) As String

End Function


' A number written with a decimal point on every PC
Private Function Num(ByVal numberValue As Variant, Optional ByVal decimals As Long = 3) As String

    Dim pattern As String

    On Error Resume Next

    pattern = "0"

    If decimals > 0 Then pattern = "0." & String$(decimals, "0")

    Num = Replace(Format$(CDbl(numberValue), pattern), ",", ".")

End Function


' Saves text as UTF-8 so Excel shows Korean correctly
Private Function WriteTextFile(ByVal filePath As String, ByVal content As String) As Boolean

    Dim stm As Object

    On Error GoTo Failed

    Set stm = CreateObject("ADODB.Stream")

    stm.Type = 2
    stm.Charset = "utf-8"
    stm.Open
    stm.WriteText content
    stm.SaveToFile filePath, 2
    stm.Close

    WriteTextFile = True

    Exit Function

Failed:

    On Error Resume Next
    stm.Close

End Function


Private Function ReadTextFile(ByVal filePath As String) As String

    Dim stm As Object

    On Error GoTo Failed

    Set stm = CreateObject("ADODB.Stream")

    stm.Type = 2
    stm.Charset = "utf-8"
    stm.Open
    stm.LoadFromFile filePath

    ReadTextFile = stm.ReadText

    stm.Close

    Exit Function

Failed:

    On Error Resume Next
    stm.Close

End Function


' Splits one CSV line into its fields
Private Function CsvSplit(ByVal lineText As String) As Collection

    Dim fields As New Collection
    Dim i As Long
    Dim ch As String
    Dim cur As String
    Dim inQuotes As Boolean

    i = 1

    Do While i <= Len(lineText)

        ch = Mid$(lineText, i, 1)

        If inQuotes Then
            If ch = """" Then
                If Mid$(lineText, i + 1, 1) = """" Then
                    cur = cur & """"
                    i = i + 1
                Else
                    inQuotes = False
                End If
            Else
                cur = cur & ch
            End If
        ElseIf ch = """" Then
            inQuotes = True
        ElseIf ch = "," Then
            fields.Add cur
            cur = ""
        Else
            cur = cur & ch
        End If

        i = i + 1

    Loop

    fields.Add cur

    Set CsvSplit = fields

End Function

' The document behind a component, or Nothing when it has none
Private Function DocOf(ByVal prod As Object) As Object

    Dim d As Object

    On Error Resume Next

    Set d = prod.ReferenceProduct.Parent

    If d Is Nothing Then Exit Function

    If Right$(TypeName(d), 8) = "Document" Then Set DocOf = d

End Function


Private Sub AddDoc(ByVal docs As Object, ByVal d As Object)

    Dim key As String

    key = UCase$(d.FullName)

    If Not docs.Exists(key) Then docs.Add key, d

End Sub


' Fills docs (a Dictionary) with every loaded document under prod
Private Sub CollectDocs( _
        ByVal prod As Object, _
        ByVal docs As Object, _
        ByVal wantParts As Boolean, _
        ByVal wantProducts As Boolean)

    Dim kids As Object
    Dim child As Object
    Dim d As Object
    Dim kind As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set d = DocOf(child)

        If Not d Is Nothing Then

            kind = TypeName(d)

            If kind = "PartDocument" And wantParts Then AddDoc docs, d
            If kind = "ProductDocument" And wantProducts Then AddDoc docs, d

            CollectDocs child, docs, wantParts, wantProducts

        End If

    Next i

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

'=========================================================
' LOGO
' The logo picture is stored below as text.
' The form shows it with:
'     AudLoadLogo Me.Controls("imgLogo")
'=========================================================

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function AudLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    AudLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    AudLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

{0}, {1} and {2} are filled in with numbers, names and error details. The window title bar stays in English in both languages.

Known limitations

  • The instance name check expects CATIA's own style, the part number followed by a dot and a number. If your team renames instances on purpose, untick it.
  • The default name check looks for part numbers that start with Part or Product followed by a digit.
  • The empty part check looks at bodies and at the top level of geometrical sets.
  • The assembly is switched to design mode, which can take a while on a large assembly.
  • The macro only reports. It does not rename anything. Use your Component Renamer for that.
  • The window is modal, so CATIA cannot be clicked while it is open. Anything that must be selected in CATIA has to be selected before running the macro.
  • If the credit image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
Prepared for CATIA V5 R21 and later, VBA. Audits part numbers, instance names and file states.
