CATIA Mass and CoG Report

Walks the assembly and writes one CSV with the mass, volume, wet area, density, material and center of gravity of every part, and flags parts that have no material applied. Two code blocks to paste: the form and the module.

What it does

  • One row per part with a quantity, or one row per instance. The first row is the whole assembly, so it gives the total mass and overall center of gravity.
  • Columns: Level, Part Number, Instance, Type, Qty, Material, Mass, Volume, Area, Density, CoG X, Y and Z, and a Note.
  • Parts without a material are flagged in the Note column and counted on the status line. Their mass comes from CATIA's default density, so it is usually wrong.
  • Works on a single CATPart too.
  • Saved as PartNumber_Mass.csv in the folder you choose, as UTF-8 so Korean headings show correctly in Excel.
  • English / Korean button in the top right corner. The language is remembered for next time.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with Mass, so it does not clash with the other macros in the same VBA project.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmMassReport. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. In the Properties window set its (Name) to MassReport, then paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATProduct or CATPart, then run CATMain from the MassReport module.

First run: this code was written and checked for structure, but not run inside CATIA. Check one part against Measure Inertia in CATIA before you trust a full report, especially the units of volume and area.

    SetBusy True

    ok = MassRun(Me, actionId, message)

    CATIA.DisplayFileAlerts = True

    Exit Sub

    message = Err.Description

    On Error Resume Next

    CATIA.RefreshDisplay = True
    CATIA.DisplayFileAlerts = True

    SetBusy False

    ShowStatus MassFmt(MassTxt("msgError"), message)

Module code

MassReport

The long block of letters and numbers at the bottom is the credit image. Do not edit it.

Option Explicit

'=========================================================
' CATIA MASS AND COG REPORT - MAIN MODULE
' Module name: MassReport
' Run CATMain to open the window.
'=========================================================

Private Const REG_APP As String = "CatiaMassReport"
Private Const REG_SEC As String = "Settings"

' "EN" or "KO"
Public gMassLang As String

Private mOut As String
Private mRowCount As Long
Private mNoMat As Long


'=========================================================
' ENTRY POINT
'=========================================================

Sub CATMain()

    MassLoadLanguage
    frmMassReport.Show

End Sub

'=========================================================
' REPORT
'=========================================================

Public Function MassRun( _
        ByVal frm As Object, _
        ByVal actionId As Long, _
        ByRef message As String) As Boolean

    Dim d As Object
    Dim root As Object
    Dim qty As Object
    Dim seen As Object
    Dim outFolder As String
    Dim target As String
    Dim perInstance As Boolean
    Dim isProduct As Boolean

    MassRun = False

    outFolder = WithSlash(CtlText(frm, "txtOut"))

    If Not FolderExists(outFolder) Then
        message = MassTxt("msgNoOut")
        Exit Function
    End If

    Set d = CATIA.ActiveDocument
    Set root = d.Product

    isProduct = (TypeName(d) = "ProductDocument")
    perInstance = (CtlIndex(frm, "cboRows") = 1)

    ' Mass can only be measured on parts loaded in design mode
    If isProduct Then
        On Error Resume Next
        root.ApplyWorkMode 2
        On Error GoTo 0
    End If

    mRowCount = 0
    mNoMat = 0

    mOut = Csv(MassTxt("hLevel")) & "," & Csv(MassTxt("hPN")) & "," & Csv(MassTxt("hInst")) & "," & _
           Csv(MassTxt("hType")) & "," & Csv(MassTxt("hQty")) & "," & Csv(MassTxt("hMat")) & "," & _
           Csv(MassTxt("hMass")) & "," & Csv(MassTxt("hVol")) & "," & Csv(MassTxt("hArea")) & "," & _
           Csv(MassTxt("hDens")) & "," & Csv(MassFmt(MassTxt("hCog"), "X")) & "," & _
           Csv(MassFmt(MassTxt("hCog"), "Y")) & "," & Csv(MassFmt(MassTxt("hCog"), "Z")) & "," & _
           Csv(MassTxt("hNote")) & vbCrLf

    ' The first row is the whole document
    MassRow frm, root, 0, "", 1

    If isProduct Then

        Set qty = CreateObject("Scripting.Dictionary")
        Set seen = CreateObject("Scripting.Dictionary")

        CountQty root, qty

        WalkMass frm, root, 1, perInstance, qty, seen

    End If

    target = outFolder & CleanName(root.PartNumber) & "_Mass.csv"

    If Not WriteTextFile(target, mOut) Then
        message = MassTxt("msgWriteFail")
        Exit Function
    End If

    If CtlOn(frm, "chkOpen") Then OpenFile target

    message = MassFmt(MassTxt("msgDone"), CStr(mRowCount), CStr(mNoMat)) & " " & target

    MassRun = True

End Function


' Counts how many times each part number is used in the whole tree
Private Sub CountQty(ByVal prod As Object, ByVal qty As Object)

    Dim kids As Object
    Dim child As Object
    Dim rp As Object
    Dim key As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set rp = RefOf(child)

        If Not rp Is Nothing Then

            key = UCase$(rp.PartNumber)

            If qty.Exists(key) Then
                qty.Item(key) = qty.Item(key) + 1
            Else
                qty.Add key, 1
            End If

            CountQty child, qty

        End If

    Next i

End Sub


Private Sub WalkMass( _
        ByVal frm As Object, _
        ByVal prod As Object, _
        ByVal level As Long, _
        ByVal perInstance As Boolean, _
        ByVal qty As Object, _
        ByVal seen As Object)

    Dim kids As Object
    Dim child As Object
    Dim rp As Object
    Dim key As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set rp = RefOf(child)

        If rp Is Nothing Then

            ' Missing file or not loaded
            mOut = mOut & CStr(level) & "," & Csv(SafeName(child)) & ",,,,,,,,,,,," & Csv(MassTxt("nNotLoaded")) & vbCrLf
            mRowCount = mRowCount + 1

        Else

            key = UCase$(rp.PartNumber)

            If perInstance Then

                MassRow frm, rp, level, SafeName(child), 1
                WalkMass frm, child, level + 1, perInstance, qty, seen

            ElseIf Not seen.Exists(key) Then

                seen.Add key, 1

                MassRow frm, rp, level, "", CLng(qty.Item(key))
                WalkMass frm, child, level + 1, perInstance, qty, seen

            End If

        End If

    Next i

End Sub


' Measures one part or assembly and adds its row
Private Sub MassRow( _
        ByVal frm As Object, _
        ByVal rp As Object, _
        ByVal level As Long, _
        ByVal instName As String, _
        ByVal quantity As Long)

    Dim an As Object
    Dim d As Object
    Dim cog(2) As Variant
    Dim massKg As Double
    Dim volume As Double
    Dim area As Double
    Dim density As Double
    Dim kindText As String
    Dim matName As String
    Dim note As String
    Dim matState As Long
    Dim measured As Boolean

    Say frm, MassTxt("stItem") & " " & rp.PartNumber

    Set d = DocOf(rp)

    kindText = MassTxt("tComponent")

    If Not d Is Nothing Then
        If TypeName(d) = "PartDocument" Then kindText = MassTxt("tPart")
        If TypeName(d) = "ProductDocument" Then kindText = MassTxt("tProduct")
    End If

    cog(0) = 0
    cog(1) = 0
    cog(2) = 0

    On Error Resume Next

    Err.Clear

    Set an = rp.Analyze

    massKg = an.Mass
    volume = an.Volume
    area = an.WetArea
    an.GetGravityCenter cog

    measured = (Err.Number = 0)

    Err.Clear

    On Error GoTo 0

    If Not measured Then note = MassTxt("nFailed")

    If volume > 0 Then density = massKg / (volume * 0.000000001)

    ' Material is checked on parts only
    If Not d Is Nothing Then

        If TypeName(d) = "PartDocument" Then

            matName = MaterialName(d, matState)

            If matState = 0 Then
                note = MassTxt("nNoMat")
                mNoMat = mNoMat + 1
            ElseIf matState = 2 Then
                note = MassTxt("nMatUnknown")
            End If

        End If

    End If

    mOut = mOut & CStr(level) & "," & Csv(rp.PartNumber) & "," & Csv(instName) & "," & _
           Csv(kindText) & "," & CStr(quantity) & "," & Csv(matName) & "," & _
           Num(massKg, 4) & "," & Num(volume, 1) & "," & Num(area, 1) & "," & Num(density, 1) & "," & _
           Num(cog(0), 3) & "," & Num(cog(1), 3) & "," & Num(cog(2), 3) & "," & Csv(note) & vbCrLf

    mRowCount = mRowCount + 1

End Sub


' Name of the material applied to the part or to its main body.
' state: 0 = no material, 1 = found, 2 = could not be read
Private Function MaterialName(ByVal d As Object, ByRef state As Long) As String

    Dim prt As Object
    Dim mgr As Object
    Dim mat As Object

    state = 2

    On Error GoTo Failed

    Set prt = d.Part
    Set mgr = prt.GetItem("CATMatManagerVBExt")

    mgr.GetMaterialOnPart prt, mat

    If mat Is Nothing Then mgr.GetMaterialOnBody prt.MainBody, mat

    If mat Is Nothing Then
        state = 0
    Else
        state = 1
        MaterialName = mat.Name
    End If

    Exit Function

Failed:

    state = 2

End Function

' "" = nothing open, otherwise Product, Part, Drawing or Other
Public Function MassDocKind() As String

    Dim t As String

    On Error Resume Next

    If CATIA.Documents.Count > 0 Then t = TypeName(CATIA.ActiveDocument)

    On Error GoTo 0

    Select Case t
        Case "ProductDocument": MassDocKind = "Product"
        Case "PartDocument": MassDocKind = "Part"
        Case "DrawingDocument": MassDocKind = "Drawing"
        Case "": MassDocKind = ""
        Case Else: MassDocKind = "Other"
    End Select

End Function

' Replaces characters that are not allowed in a file name
Private Function CleanName(ByVal rawName As String) As String

    Dim i As Long
    Dim ch As String
    Dim code As Long
    Dim result As String

    For i = 1 To Len(rawName)

        ch = Mid$(rawName, i, 1)
        code = AscW(ch)

        If InStr("\/:*?""<>|", ch) > 0 Or (code >= 0 And code < 32) Then
            result = result & "_"
        Else
            result = result & ch
        End If

    Next i

    If Len(result) = 0 Then result = "Unnamed"

    CleanName = result

End Function

    Dim p As Long

    If p > 1 Then
        StripExt = Left$(fileName, p - 1)

        StripExt = fileName
    End If

End Function

' One CSV field, always in quotes
Private Function Csv(ByVal fieldText As String) As String

' A number written with a decimal point on every PC
Private Function Num(ByVal numberValue As Variant, Optional ByVal decimals As Long = 3) As String

    Dim pattern As String

    On Error Resume Next

    pattern = "0"

    If decimals > 0 Then pattern = "0." & String$(decimals, "0")

    Num = Replace(Format$(CDbl(numberValue), pattern), ",", ".")

End Function


' Saves text as UTF-8 so Excel shows Korean correctly
Private Function WriteTextFile(ByVal filePath As String, ByVal content As String) As Boolean

    Dim stm As Object

    On Error GoTo Failed

    Set stm = CreateObject("ADODB.Stream")

    stm.Type = 2
    stm.Charset = "utf-8"
    stm.Open
    stm.WriteText content
    stm.SaveToFile filePath, 2
    stm.Close

    WriteTextFile = True

    Exit Function

Failed:

    On Error Resume Next
    stm.Close

End Function

    Dim stm As Object

    On Error GoTo Failed

    Set stm = CreateObject("ADODB.Stream")

    stm.Type = 2
    stm.Charset = "utf-8"
    stm.Open
    stm.LoadFromFile filePath

    ReadTextFile = stm.ReadText

    stm.Close

    Exit Function

Failed:

    On Error Resume Next
    stm.Close

End Function


' Splits one CSV line into its fields
Private Function CsvSplit(ByVal lineText As String) As Collection

    Dim fields As New Collection
    Dim i As Long
    Dim ch As String
    Dim cur As String
    Dim inQuotes As Boolean

    i = 1

    Do While i <= Len(lineText)

        ch = Mid$(lineText, i, 1)

        If inQuotes Then
            If ch = """" Then
                If Mid$(lineText, i + 1, 1) = """" Then
                    cur = cur & """"
                    i = i + 1
                Else
                    inQuotes = False
                End If
            Else
                cur = cur & ch
            End If
        ElseIf ch = """" Then
            inQuotes = True
        ElseIf ch = "," Then
            fields.Add cur
            cur = ""
        Else
            cur = cur & ch
        End If

        i = i + 1

    Loop

    fields.Add cur

    Set CsvSplit = fields

End Function

Private Sub AddDoc(ByVal docs As Object, ByVal d As Object)

    Dim key As String

    key = UCase$(d.FullName)

    If Not docs.Exists(key) Then docs.Add key, d

End Sub


' Fills docs (a Dictionary) with every loaded document under prod
Private Sub CollectDocs( _
        ByVal prod As Object, _
        ByVal docs As Object, _
        ByVal wantParts As Boolean, _
        ByVal wantProducts As Boolean)

    Dim kids As Object
    Dim child As Object
    Dim d As Object
    Dim kind As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set d = DocOf(child)

        If Not d Is Nothing Then

            kind = TypeName(d)

            If kind = "PartDocument" And wantParts Then AddDoc docs, d
            If kind = "ProductDocument" And wantProducts Then AddDoc docs, d

            CollectDocs child, docs, wantParts, wantProducts

        End If

    Next i

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

' LOGO
' The logo picture is stored below as text.
' The form shows it with:
'     MassLoadLogo Me.Controls("imgLogo")
'=========================================================

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function MassLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    MassLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    MassLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

How to read the numbers

  • Units. The values are written as CATIA returns them: mass in kg, volume in mm3, area in mm2 and center of gravity in mm. Density is calculated as mass divided by volume and written in kg/m3. Confirm this on one known part.
  • Center of gravity. Each part row is measured on the part itself, so its center of gravity is in that part's own axis system. The first row is in the axis system of the top assembly.
  • Qty is the total number of times the part is used in the whole tree.

{0}, {1} and {2} are filled in with numbers, names and error details. The window title bar stays in English in both languages.

Known limitations

  • The assembly is switched to design mode so every part can be measured. On a large assembly this can take a while.
  • If the material cannot be read on your CATIA level, the Note says so and the part is not counted as missing a material.
  • A material applied to a body other than the main body is not detected.
  • Parts that are not loaded (missing files) get a row with the note "Not loaded".
  • The window is modal, so CATIA cannot be clicked while it is open. Anything that must be selected in CATIA has to be selected before running the macro.
  • If the credit image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
