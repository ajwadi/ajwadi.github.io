CATIA Tree Filter

Reads the tree of an open CATProduct or CATPart, then shows or hides parts, bodies and geometrical sets that match a name filter such as *T2.6*. Two code blocks to paste: the form and the module.

What it does

  • Window picker. Lists every open CATProduct and CATPart window and starts on the active one. Picking a window brings it to the front and reads its tree. Rescan reads it again after you change the model.
  • Collects the names first. In a CATProduct it reads every component at every level (instance name and part number). In a CATPart it reads every body. Tick the boxes to also read the bodies inside each part of a product, and geometrical sets.
  • Filter box with a live list. As you type, the list shows only the matching items and the count ("12 of 340 items match"). Nothing in CATIA changes until you press a button.
  • Show Only Matches shows the matching items and hides the rest. The assemblies that hold a match stay visible so the match can be seen, and everything inside a matching assembly stays visible too.
  • Hide Matches hides only the matching items and leaves everything else as it is.
  • Show All shows every item that was read, to undo a filter.
  • Match on (CATProduct only): instance name or part number, instance name only, or part number only.
  • English / Korean button in the top right corner. The language, your last filter and the checkbox choices are remembered for next time.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with TreeFlt (for example TreeFltTxt, TreeFltCollect, TreeFltLoadLogo), so there are no "Ambiguous name" errors with the box generator, colorizer, renamer, BOM exporter, text generator or tree exporter.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmTreeFilter. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. Set its (Name) to TreeFilter and paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATProduct or CATPart, then run CATMain from the TreeFilter module.

First run: this code was written and checked for structure but not run inside CATIA. Try it on a copy of a small assembly first, and use Show All to put everything back.

' Lists every open CATPart and CATProduct window.
' keepCaption selects that window again after a rescan.
Private Sub FillWindowList(ByVal keepCaption As String)

    Dim w As Object
    Dim d As Object
    Dim docType As String
    Dim activeCaption As String
    Dim pick As Long
    Dim i As Long

    Dim wasLoading As Boolean

    wasLoading = mLoading
    mLoading = True

    mWindowCombo.Clear
    mWinCount = 0
    pick = -1

    On Error Resume Next

    ReDim mWinIndex(0 To CATIA.Windows.Count)

    activeCaption = CATIA.ActiveWindow.Caption

    For i = 1 To CATIA.Windows.Count

        Set w = Nothing
        Set d = Nothing
        docType = ""

        Set w = CATIA.Windows.Item(i)
        Set d = w.Parent
        docType = TypeName(d)

        If docType = "ProductDocument" Or docType = "PartDocument" Then

            mWinIndex(mWinCount) = i

            If docType = "ProductDocument" Then
                mWindowCombo.AddItem w.Caption & "   [CATProduct]"
            Else
                mWindowCombo.AddItem w.Caption & "   [CATPart]"
            End If

            If Len(keepCaption) > 0 Then
                If w.Caption = keepCaption Then pick = mWinCount
            ElseIf w.Caption = activeCaption Then
                pick = mWinCount
            End If

            mWinCount = mWinCount + 1

        End If

    Next i

    Err.Clear

    On Error GoTo 0

    If mWinCount > 0 Then
        If pick < 0 Then pick = 0
        mWindowCombo.ListIndex = pick
    End If

    mLoading = wasLoading

End Sub


Private Function SelectedCaption() As String

    Dim t As String
    Dim p As Long

    SelectedCaption = ""

    If mWindowCombo.ListIndex < 0 Then Exit Function

    t = mWindowCombo.List(mWindowCombo.ListIndex)
    p = InStrRev(t, "   [")

    If p > 0 Then t = Left$(t, p - 1)

    SelectedCaption = t

End Function

'=========================================================
' READ THE TREE

Private Sub ScanTree()

    Dim errorText As String
    Dim ok As Boolean

    If mWinCount = 0 Or mWindowCombo.ListIndex < 0 Then
        TreeFltClear
        ShowStatusKey "stNoWin"
        UpdateEnabled
        RefreshList
        Exit Sub
    End If

    SetBusy True

    ShowStatusKey "stScanning"
    Me.Repaint
    DoEvents

    ok = TreeFltCollect(mWinIndex(mWindowCombo.ListIndex), _
            CBool(mBodiesCheck.Value), CBool(mSetsCheck.Value), errorText)

    SetBusy False

    If Not ok Then
        ShowStatusKey "msgError", errorText
    ElseIf gTreeFltIsProduct Then
        ShowStatusKey "stReadyProduct", CStr(gTreeFltCount)
    Else
        ShowStatusKey "stReadyPart", CStr(gTreeFltCount)
    End If

    UpdateEnabled
    RefreshList

End Sub

Private Sub RefreshList()

    Dim lst As Object
    Dim matched As Long
    Dim shown As Long
    Dim i As Long

    Set lst = Me.Controls("lstItems")

    lst.Clear

    matched = TreeFltComputeMatches(mFilterBox.Text, mMatchCombo.ListIndex)

    shown = 0

    For i = 1 To gTreeFltCount
        If gTreeFltMatch(i) Then
            If shown >= LIST_MAX Then Exit For
            lst.AddItem TreeFltDisplayText(i)
            shown = shown + 1
        End If
    Next i

    If matched > LIST_MAX Then
        Me.Controls("lblCount").Caption = TreeFltFmt(TreeFltTxt("countMore"), _
            CStr(matched), CStr(gTreeFltCount), CStr(LIST_MAX))
    Else
        Me.Controls("lblCount").Caption = TreeFltFmt(TreeFltTxt("count"), _
            CStr(matched), CStr(gTreeFltCount))
    End If

End Sub

Private Sub RunApply(ByVal mode As Long)

    Dim matched As Long
    Dim skipped As Long
    Dim errorText As String

    If gTreeFltCount = 0 Then
        ShowStatusKey "stNoWin"
        Exit Sub
    End If

    If mode <> TREEFLT_MODE_SHOW_ALL Then

        If Not TreeFltHasFilter(mFilterBox.Text) Then
            ShowStatusKey "msgNoFilter"
            Exit Sub
        End If

        matched = TreeFltComputeMatches(mFilterBox.Text, mMatchCombo.ListIndex)

        If matched = 0 Then
            ShowStatusKey "msgNoMatch"
            Exit Sub
        End If

        TreeFltSaveText "Filter", mFilterBox.Text

    End If

    SetBusy True

    ShowStatusKey "stWorking"
    Me.Repaint
    DoEvents

    If Not TreeFltApply(mode, skipped, errorText) Then
        SetBusy False
        ShowStatusKey "msgError", errorText
        Exit Sub
    End If

    SetBusy False

    Select Case mode
        Case TREEFLT_MODE_SHOW_ONLY
            ShowStatusKey "msgShowOnly", CStr(matched), skipped
        Case TREEFLT_MODE_HIDE
            ShowStatusKey "msgHide", CStr(matched), skipped
        Case Else
            ShowStatusKey "msgShowAll", CStr(gTreeFltCount), skipped
    End Select

End Sub


'=========================================================
' CLOSE
'=========================================================

Private Sub mCloseButton_Click()

    TreeFltSaveText "Filter", mFilterBox.Text

    Unload Me

End Sub


' The window cannot be closed while the tree is being
' read or visibility is being changed
Private Sub UserForm_QueryClose(Cancel As Integer, CloseMode As Integer)

    If mBusy Then Cancel = True

End Sub

Module code

TreeFilter

The long block of letters and numbers at the bottom is the credit image. Do not edit it.

Option Explicit

'=========================================================
' CATIA TREE FILTER - MAIN MODULE
' Module name: TreeFilter
' Run CATMain to open the window.
'=========================================================

' Button actions
Public Const TREEFLT_MODE_SHOW_ONLY As Long = 1
Public Const TREEFLT_MODE_HIDE As Long = 2
Public Const TREEFLT_MODE_SHOW_ALL As Long = 3

' CATIA show / hide values (catVisPropertyShowAttr, catVisPropertyNoShowAttr)
Private Const VIS_SHOW As Long = 0
Private Const VIS_HIDE As Long = 1

' Kinds of tree item
Private Const KIND_COMPONENT As Integer = 1
Private Const KIND_BODY As Integer = 2
Private Const KIND_SET As Integer = 3

Private Const REG_APP As String = "CatiaTreeFilter"
Private Const REG_SEC As String = "Settings"

' "EN" or "KO"
Public gTreeFltLang As String

' The items read from the tree, numbered 1 to gTreeFltCount
Public gTreeFltCount As Long
Public gTreeFltIsProduct As Boolean
Public gTreeFltMatch() As Boolean

Private mName() As String
Private mPN() As String
Private mKind() As Integer
Private mParent() As Long
Private mDepth() As Long
Private mObj() As Object
Private mDoc() As Object

Private mCap As Long
Private mRootDoc As Object


'=========================================================
' ENTRY POINT
'=========================================================

Sub CATMain()

    TreeFltLoadLanguage
    frmTreeFilter.Show

End Sub


'=========================================================
' READ THE TREE
' Items are stored parent first, so a parent always has a
' lower number than its children.
'=========================================================

Public Sub TreeFltClear()

    gTreeFltCount = 0
    mCap = 0

    Erase mName
    Erase mPN
    Erase mKind
    Erase mParent
    Erase mDepth
    Erase mObj
    Erase mDoc

    ReDim gTreeFltMatch(0 To 0)

    Set mRootDoc = Nothing

End Sub


Private Function AddNode( _
        ByVal itemName As String, _
        ByVal partNumber As String, _
        ByVal kind As Integer, _
        ByVal parentIdx As Long, _
        ByVal depth As Long, _
        ByVal obj As Object, _
        ByVal ownerDoc As Object) As Long

    If gTreeFltCount >= mCap Then

        If mCap = 0 Then mCap = 256 Else mCap = mCap * 2

        ReDim Preserve mName(0 To mCap)
        ReDim Preserve mPN(0 To mCap)
        ReDim Preserve mKind(0 To mCap)
        ReDim Preserve mParent(0 To mCap)
        ReDim Preserve mDepth(0 To mCap)
        ReDim Preserve mObj(0 To mCap)
        ReDim Preserve mDoc(0 To mCap)

    End If

    gTreeFltCount = gTreeFltCount + 1

    mName(gTreeFltCount) = itemName
    mPN(gTreeFltCount) = partNumber
    mKind(gTreeFltCount) = kind
    mParent(gTreeFltCount) = parentIdx
    mDepth(gTreeFltCount) = depth
    Set mObj(gTreeFltCount) = obj
    Set mDoc(gTreeFltCount) = ownerDoc

    AddNode = gTreeFltCount

End Function


' Reads the tree of one CATIA window.
' includeBodies: CATProduct only, also list the bodies inside each part.
' includeSets: also list geometrical sets.
Public Function TreeFltCollect( _
        ByVal windowIndex As Long, _
        ByVal includeBodies As Boolean, _
        ByVal includeSets As Boolean, _
        ByRef errorText As String) As Boolean

    Dim win As Object
    Dim doc As Object

    TreeFltCollect = False

    TreeFltClear

    On Error GoTo Failed

    Set win = CATIA.Windows.Item(windowIndex)

    ' Bring the chosen window to the front so the result is visible
    On Error Resume Next
    win.Activate
    Err.Clear
    On Error GoTo Failed

    Set doc = win.Parent
    Set mRootDoc = doc

    If TypeName(doc) = "ProductDocument" Then

        gTreeFltIsProduct = True
        CollectProducts doc.Product, 0, 0, includeBodies, includeSets

    ElseIf TypeName(doc) = "PartDocument" Then

        gTreeFltIsProduct = False
        CollectPartItems doc.Part, 0, 0, doc, True, includeSets

    Else

        errorText = TreeFltTxt("stNoWin")
        Exit Function

    End If

    ReDim gTreeFltMatch(0 To gTreeFltCount)

    TreeFltCollect = True

    Exit Function

Failed:

    errorText = Err.Description

End Function


Private Sub CollectProducts( _
        ByVal parentProd As Object, _
        ByVal parentIdx As Long, _
        ByVal depth As Long, _
        ByVal includeBodies As Boolean, _
        ByVal includeSets As Boolean)

    Dim prods As Object
    Dim child As Object
    Dim refDoc As Object
    Dim itemCount As Long
    Dim i As Long
    Dim idx As Long
    Dim itemName As String
    Dim partNumber As String

    On Error Resume Next

    Set prods = parentProd.Products
    If prods Is Nothing Then Exit Sub

    itemCount = prods.Count

    For i = 1 To itemCount

        Set child = Nothing
        Set child = prods.Item(i)

        If Not child Is Nothing Then

            itemName = ""
            partNumber = ""

            itemName = child.Name

            ' Unloaded components have no part number
            partNumber = child.PartNumber

            Err.Clear

            idx = AddNode(itemName, partNumber, KIND_COMPONENT, _
                    parentIdx, depth, child, mRootDoc)

            If includeBodies Or includeSets Then

                Set refDoc = Nothing
                Set refDoc = child.ReferenceProduct.Parent

                If TypeName(refDoc) = "PartDocument" Then
                    CollectPartItems refDoc.Part, idx, depth + 1, _
                        refDoc, includeBodies, includeSets
                End If

                Err.Clear

            End If

            CollectProducts child, idx, depth + 1, includeBodies, includeSets

        End If

        Err.Clear

    Next i

End Sub


Private Sub CollectPartItems( _
        ByVal partObj As Object, _
        ByVal parentIdx As Long, _
        ByVal depth As Long, _
        ByVal ownerDoc As Object, _
        ByVal includeBodies As Boolean, _
        ByVal includeSets As Boolean)

    Dim bodiesObj As Object
    Dim bodyObj As Object
    Dim i As Long

    On Error Resume Next

    If includeBodies Then

        Set bodiesObj = partObj.Bodies

        For i = 1 To bodiesObj.Count

            Set bodyObj = Nothing
            Set bodyObj = bodiesObj.Item(i)

            If Not bodyObj Is Nothing Then
                AddNode bodyObj.Name, "", KIND_BODY, parentIdx, depth, _
                    bodyObj, ownerDoc
            End If

            Err.Clear

        Next i

    End If

    If includeSets Then
        CollectSets partObj.HybridBodies, parentIdx, depth, ownerDoc
    End If

    Err.Clear

End Sub


' Geometrical sets, including sets inside sets
Private Sub CollectSets( _
        ByVal setsObj As Object, _
        ByVal parentIdx As Long, _
        ByVal depth As Long, _
        ByVal ownerDoc As Object)

    Dim setObj As Object
    Dim idx As Long
    Dim i As Long

    On Error Resume Next

    If setsObj Is Nothing Then Exit Sub

    For i = 1 To setsObj.Count

        Set setObj = Nothing
        Set setObj = setsObj.Item(i)

        If Not setObj Is Nothing Then

            idx = AddNode(setObj.Name, "", KIND_SET, parentIdx, depth, _
                    setObj, ownerDoc)

            CollectSets setObj.HybridBodies, idx, depth + 1, ownerDoc

        End If

        Err.Clear

    Next i

End Sub


' One line for the match list
Public Function TreeFltDisplayText(ByVal i As Long) As String

    Dim t As String

    t = String$(mDepth(i) * 3, " ") & mName(i)

    Select Case mKind(i)

        Case KIND_COMPONENT
            If Len(mPN(i)) > 0 And mPN(i) <> mName(i) Then
                t = t & "   (" & mPN(i) & ")"
            End If

        Case KIND_BODY
            t = t & "   " & TreeFltTxt("tagBody")

        Case KIND_SET
            t = t & "   " & TreeFltTxt("tagSet")

    End Select

    TreeFltDisplayText = t

End Function


'=========================================================
' FILTER MATCHING
' * matches any text, ? matches one character.
' Upper and lower case are treated the same.
' Several filters can be separated with ;
' A filter with no * or ? matches names that contain it.
'=========================================================

Private Function BuildTerms( _
        ByVal filterText As String, _
        ByRef terms() As String) As Long

    Dim parts() As String
    Dim t As String
    Dim n As Long
    Dim i As Long

    parts = Split(filterText, ";")

    ReDim terms(0 To UBound(parts) + 1)

    n = 0

    For i = 0 To UBound(parts)

        t = LCase$(Trim$(parts(i)))

        If Len(t) > 0 Then

            If InStr(t, "*") = 0 And InStr(t, "?") = 0 Then
                t = "*" & t & "*"
            End If

            terms(n) = t
            n = n + 1

        End If

    Next i

    BuildTerms = n

End Function


Public Function TreeFltHasFilter(ByVal filterText As String) As Boolean

    Dim terms() As String

    TreeFltHasFilter = (BuildTerms(filterText, terms) > 0)

End Function


' Marks gTreeFltMatch for every item and returns how many match.
' matchOn: 0 = instance name or part number, 1 = instance name,
' 2 = part number. Bodies and sets always match on their name.
' An empty filter matches everything.
Public Function TreeFltComputeMatches( _
        ByVal filterText As String, _
        ByVal matchOn As Long) As Long

    Dim terms() As String
    Dim termCount As Long
    Dim matched As Long
    Dim hit As Boolean
    Dim i As Long
    Dim k As Long

    ReDim gTreeFltMatch(0 To gTreeFltCount)

    termCount = BuildTerms(filterText, terms)

    If matchOn < 0 Or matchOn > 2 Then matchOn = 0

    ' In a CATPart only names are used
    If Not gTreeFltIsProduct Then matchOn = 0

    matched = 0

    For i = 1 To gTreeFltCount

        If termCount = 0 Then

            hit = True

        Else

            hit = False

            For k = 0 To termCount - 1

                If mKind(i) <> KIND_COMPONENT Or matchOn <> 2 Then
                    If WildMatch(LCase$(mName(i)), terms(k)) Then hit = True
                End If

                If Not hit And mKind(i) = KIND_COMPONENT And matchOn <> 1 Then
                    If WildMatch(LCase$(mPN(i)), terms(k)) Then hit = True
                End If

                If hit Then Exit For

            Next k

        End If

        gTreeFltMatch(i) = hit

        If hit Then matched = matched + 1

    Next i

    TreeFltComputeMatches = matched

End Function


' Both texts must already be lower case
Private Function WildMatch( _
        ByVal t As String, _
        ByVal p As String) As Boolean

    Dim ti As Long
    Dim pi As Long
    Dim starP As Long
    Dim starT As Long
    Dim pc As String

    ti = 1
    pi = 1
    starP = 0
    starT = 0

    Do While ti <= Len(t)

        If pi <= Len(p) Then
            pc = Mid$(p, pi, 1)
        Else
            pc = ""
        End If

        If pc = "*" Then
            starP = pi
            starT = ti
            pi = pi + 1
        ElseIf Len(pc) > 0 And (pc = "?" Or pc = Mid$(t, ti, 1)) Then
            pi = pi + 1
            ti = ti + 1
        ElseIf starP > 0 Then
            pi = starP + 1
            starT = starT + 1
            ti = starT
        Else
            WildMatch = False
            Exit Function
        End If

    Loop

    Do While pi <= Len(p)
        If Mid$(p, pi, 1) <> "*" Then Exit Do
        pi = pi + 1
    Loop

    WildMatch = (pi > Len(p))

End Function


'=========================================================
' SHOW / HIDE
' Call TreeFltComputeMatches first.
'
' Show only matches: matching items, everything inside them
' and the assemblies that hold them are shown. Everything
' else is hidden.
' Hide matches: only matching items are hidden.
' Show all: every item read from the tree is shown.
'=========================================================

Public Function TreeFltApply( _
        ByVal mode As Long, _
        ByRef skipped As Long, _
        ByRef errorText As String) As Boolean

    Dim ancMatch() As Boolean
    Dim descMatch() As Boolean
    Dim keep() As Boolean
    Dim setTo() As Long

    Dim n As Long
    Dim i As Long
    Dim p As Long

    TreeFltApply = False
    skipped = 0

    n = gTreeFltCount

    If n = 0 Or mRootDoc Is Nothing Then
        errorText = TreeFltTxt("stNoWin")
        Exit Function
    End If

    ReDim ancMatch(0 To n)
    ReDim descMatch(0 To n)
    ReDim keep(0 To n)
    ReDim setTo(0 To n)

    ' An item whose parent, grandparent... matches
    For i = 1 To n
        p = mParent(i)
        If p > 0 Then ancMatch(i) = gTreeFltMatch(p) Or ancMatch(p)
    Next i

    ' An item with a matching child, grandchild...
    For i = n To 1 Step -1
        p = mParent(i)
        If p > 0 Then
            If gTreeFltMatch(i) Or descMatch(i) Then descMatch(p) = True
        End If
    Next i

    For i = 1 To n

        p = mParent(i)
        setTo(i) = -1

        Select Case mode

            Case TREEFLT_MODE_SHOW_ONLY

                keep(i) = gTreeFltMatch(i) Or ancMatch(i) Or descMatch(i)

                ' Items inside a hidden parent are already out of
                ' sight, so they are left as they are
                If p = 0 Then
                    setTo(i) = IIf(keep(i), VIS_SHOW, VIS_HIDE)
                ElseIf keep(p) Then
                    setTo(i) = IIf(keep(i), VIS_SHOW, VIS_HIDE)
                End If

            Case TREEFLT_MODE_HIDE

                ' Hiding the parent already hides its children
                If gTreeFltMatch(i) And Not ancMatch(i) Then setTo(i) = VIS_HIDE

            Case Else

                setTo(i) = VIS_SHOW

        End Select

    Next i

    SetVisibility setTo, VIS_HIDE, skipped, errorText
    SetVisibility setTo, VIS_SHOW, skipped, errorText

    On Error Resume Next
    mRootDoc.Selection.Clear
    CATIA.RefreshDisplay = True
    Err.Clear

    TreeFltApply = True

End Function


' Selects every item marked with showValue and applies it in
' one step per document. Items that cannot be selected, for
' example unloaded components, are counted in skipped.
Private Sub SetVisibility( _
        ByRef setTo() As Long, _
        ByVal showValue As Long, _
        ByRef skipped As Long, _
        ByRef errorText As String)

    Dim sel As Object
    Dim curDoc As Object
    Dim added As Long
    Dim i As Long

    On Error Resume Next

    ' Items owned by the open document (components in a
    ' CATProduct, bodies and sets in a CATPart)
    Set sel = mRootDoc.Selection
    sel.Clear
    added = 0

    For i = 1 To gTreeFltCount
        If setTo(i) = showValue Then
            If mDoc(i) Is mRootDoc Then
                AddToSelection sel, mObj(i), added, skipped
            End If
        End If
    Next i

    FlushSelection sel, added, showValue, skipped, errorText

    ' Bodies and sets inside the parts of a CATProduct.
    ' These are changed in each part's own document.
    Set curDoc = Nothing
    Set sel = Nothing
    added = 0

    For i = 1 To gTreeFltCount

        If setTo(i) = showValue Then

            If Not (mDoc(i) Is mRootDoc) Then

                If Not (mDoc(i) Is curDoc) Then

                    If Not sel Is Nothing Then
                        FlushSelection sel, added, showValue, skipped, errorText
                    End If

                    Set curDoc = mDoc(i)
                    Set sel = Nothing
                    Set sel = curDoc.Selection

                    If Not sel Is Nothing Then sel.Clear

                    added = 0

                End If

                If sel Is Nothing Then
                    skipped = skipped + 1
                Else
                    AddToSelection sel, mObj(i), added, skipped
                End If

            End If

        End If

        Err.Clear

    Next i

    If Not sel Is Nothing Then
        FlushSelection sel, added, showValue, skipped, errorText
    End If

    Err.Clear

End Sub


Private Sub AddToSelection( _
        ByVal sel As Object, _
        ByVal obj As Object, _
        ByRef added As Long, _
        ByRef skipped As Long)

    On Error Resume Next

    Err.Clear
    sel.Add obj

    If Err.Number = 0 Then
        added = added + 1
    Else
        skipped = skipped + 1
    End If

    Err.Clear

End Sub


Private Sub FlushSelection( _
        ByVal sel As Object, _
        ByRef added As Long, _
        ByVal showValue As Long, _
        ByRef skipped As Long, _
        ByRef errorText As String)

    On Error Resume Next

    If added > 0 Then

        Err.Clear
        sel.VisProperties.SetShow showValue

        If Err.Number <> 0 Then
            skipped = skipped + added
            errorText = Err.Description
        End If

    End If

    sel.Clear
    added = 0

    Err.Clear

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

' LOGO
' The logo picture is stored below as text.
' The form shows it with:
'     TreeFltLoadLogo Me.Controls("imgLogo")
'=========================================================

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function TreeFltLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    TreeFltLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_treefilter_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    TreeFltLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

You typeMatches

T2.6Same as *T2.6*. A filter with no * or ? matches names that contain it.
T2.6*Names that start with T2.6

BRKT_0??BRKT_0 followed by exactly two characters

Upper and lower case are treated the same. Only * and ? are special, so dots, brackets and # in part names match as plain characters.

Known limitations

  • The window is modal, as with your other macros, so you can see the result in CATIA but need to close the window to rotate or pick in the model. To keep it open while you work, change frmTreeFilter.Show in CATMain to frmTreeFilter.Show 0.
  • Bodies and geometrical sets inside the parts of a CATProduct are hidden inside each part file, so the change applies to every instance of that part and marks the part as modified. If the same part is used twice and only one instance matches, the last instance processed wins.
  • Components that are not loaded have no part number and cannot be selected. They are counted in the "could not be changed" note on the status line.
  • The list shows the first 1000 matches. The count and the buttons still use every match.
  • Ordered geometrical sets are not read, only regular geometrical sets.
  • After changing the model, press Rescan before filtering again, so the macro works from the current tree.
  • If the image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
Prepared for CATIA V5 R21 VBA. Shows or hides components, bodies and geometrical sets by name in an open CATProduct or CATPart.
