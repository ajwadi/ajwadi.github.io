CATIA Text Generator

Raised or engraved text in any installed font, in a straight line at an angle or around a circle. Two code blocks to paste: the form and the module.

What it does

  • Font picker with preview. A dropdown of the TrueType fonts installed on the PC, with Bold and Italic. The white box shows your text in that font as you type.
  • Straight text at any angle. Centered on the position you enter, rotated counterclockwise.
  • Text around a circle. Enter the circle diameter and choose Outside or Inside the circle. Angle 0 centers the text at the top; 180 puts it at the bottom.
  • Depth in mm, as raised text (pad) or engraved text (pocket).
  • Preview in CATIA. Draws only the sketch so you can check size and placement. Create Text replaces it with the finished text. Closing the window removes a leftover preview.
  • English / Korean button and the credit image centered at the bottom, stored in the module as text.
  • Safe beside your other macros. Every shared name starts with TG, and the Windows declarations are private to this module.

Not tested in CATIA. This macro calls Windows directly to read letter shapes, which is riskier than your other macros. Save your work first, and try it on a new empty part with the default "CATIA" in Arial.

Setup

  1. In the VBA editor, use Insert, UserForm. Set its (Name) to frmTextGenerator. Leave it empty in the designer.
  2. Open the form's code, select all, delete, and paste the Form code below.
  3. Use Insert, Module. Set its (Name) to TextGenerator and paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Run CATMain from the TextGenerator module.

Red lines near the top of the module are normal. The module holds two sets of Windows declarations, one for newer VBA and one for older VBA. The set your CATIA does not use may show in red. It still compiles, so you do not need to tell me whether your CATIA is 32-bit or 64-bit.

How to use it

  1. Open a CATPart.
  2. Before running the macro, select the plane or flat face the text should sit on. With nothing selected, it uses the XY plane. The window shows which one it picked up.
  3. Run the macro, type the text, pick the font and fill in the sizes.
  4. Click Preview in CATIA and look at the sketch behind the window.
  5. Adjust and preview again, or click Create Text.

Private Sub FillFonts()

    Dim names As Variant
    Dim i As Long
    Dim wanted As String

    names = TGGetFontNames()

    For i = LBound(names) To UBound(names)
        mFontCombo.AddItem names(i)
    Next i

    ' Last font used, or Arial, or the first in the list
    wanted = TGLoadText("Font", "Arial")

    For i = 0 To mFontCombo.ListCount - 1
        If StrComp(mFontCombo.List(i), wanted, vbTextCompare) = 0 Then
            mFontCombo.ListIndex = i
            Exit For
        End If
    Next i

    If mFontCombo.ListIndex < 0 Then

        For i = 0 To mFontCombo.ListCount - 1
            If StrComp(mFontCombo.List(i), "Arial", vbTextCompare) = 0 Then
                mFontCombo.ListIndex = i
                Exit For
            End If
        Next i

    End If

    If mFontCombo.ListIndex < 0 And mFontCombo.ListCount > 0 Then
        mFontCombo.ListIndex = 0
    End If

End Sub

' Accepts numbers like 12, 12.5, 12,5 and -3
Private Function ReadNum( _
        ByVal ctlName As String, _
        ByRef result As Double) As Boolean

    Dim textValue As String
    Dim i As Long

    ReadNum = False

    textValue = Replace(Trim$(Me.Controls(ctlName).Text), ",", ".")

    If Len(textValue) = 0 Then Exit Function

    For i = 1 To Len(textValue)
        If InStr("0123456789.-", Mid$(textValue, i, 1)) = 0 Then Exit Function
    Next i

    result = Val(textValue)

    ReadNum = True

End Function

Private Sub RunBuild(ByVal makeSolid As Boolean)

    Dim letterHeight As Double
    Dim spacing As Double
    Dim angleDeg As Double
    Dim diameter As Double
    Dim posH As Double
    Dim posV As Double
    Dim depth As Double
    Dim radial As Boolean
    Dim numbersOk As Boolean
    Dim resultMessage As String

    If Len(Trim$(mTextBox.Text)) = 0 Then
        ShowStatus TGTxt("msgNoText")
        Exit Sub
    End If

    radial = (mOptRadial.Value = True)

    numbersOk = ReadNum("txtHeight", letterHeight)

    If numbersOk Then numbersOk = ReadNum("txtSpacing", spacing)
    If numbersOk Then numbersOk = ReadNum("txtAngle", angleDeg)
    If numbersOk Then numbersOk = ReadNum("txtPosH", posH)
    If numbersOk Then numbersOk = ReadNum("txtPosV", posV)
    If numbersOk Then numbersOk = ReadNum("txtDepth", depth)
    If numbersOk Then numbersOk = (letterHeight > 0 And depth > 0)

    If numbersOk And radial Then
        numbersOk = ReadNum("txtDia", diameter)
        If numbersOk Then numbersOk = (diameter > 0)
    End If

    If Not numbersOk Then
        ShowStatus TGTxt("msgBadNumber")
        Exit Sub
    End If

    TGSaveText "Font", mFontCombo.Text

    ShowStatus TGTxt("stWorking")
    SetBusy True

    On Error Resume Next

    TGBuildText _
        mTextBox.Text, _
        mFontCombo.Text, _
        (mBold.Value = True), _
        (mItalic.Value = True), _
        letterHeight, _
        spacing, _
        radial, _
        angleDeg, _
        diameter, _
        (Me.Controls("optInside").Value = True), _
        (Me.Controls("chkCenter").Value = True), _
        posH, _
        posV, _
        (Me.Controls("chkMirror").Value = True), _
        makeSolid, _
        (Me.Controls("optPocket").Value = True), _
        depth, _
        (Me.Controls("chkReverse").Value = True), _
        mSupport, _
        resultMessage

    If Err.Number <> 0 Then
        resultMessage = TGFmt(TGTxt("msgError"), Err.Description)
        Err.Clear
    End If

    On Error GoTo 0

    SetBusy False
    ShowStatus resultMessage

End Sub

        ByVal fontType As Long, _
        ByVal lParam As LongPtr) As Long

    Dim buf(0 To 63) As Byte
    Dim faceName As String
    Dim p As Long

    On Error Resume Next

    ' 1 = keep going
    TGEnumFontProc = 1

    ' Only TrueType fonts have outlines that can be read
    If (fontType And 4) = 0 Then Exit Function

    RtlMoveMemory buf(0), lpelf + 28, 64

    faceName = buf

    p = InStr(faceName, vbNullChar)

    If p > 0 Then faceName = Left$(faceName, p - 1)

    If Len(faceName) = 0 Then Exit Function
    If Left$(faceName, 1) = "@" Then Exit Function

    mFontDict(faceName) = 1

End Function


' Returns the installed TrueType font names, sorted
Public Function TGGetFontNames() As Variant

    Dim hdc As LongPtr
    Dim lf As LOGFONTW
    Dim names As Variant
    Dim i As Long
    Dim j As Long
    Dim temp As String

    Set mFontDict = CreateObject("Scripting.Dictionary")

    On Error Resume Next

    hdc = CreateCompatibleDC(0)

    If hdc <> 0 Then

        ' 1 = every character set
        lf.lfCharSet = 1

        EnumFontFamiliesExW hdc, lf, AddressOf TGEnumFontProc, 0, 0

        DeleteDC hdc

    End If

    On Error GoTo 0

    If mFontDict.Count = 0 Then
        TGGetFontNames = Array("Arial", "Courier New", "Malgun Gothic", _
            "Tahoma", "Times New Roman", "Verdana")
        Exit Function
    End If

    names = mFontDict.Keys

    For i = LBound(names) + 1 To UBound(names)

        temp = names(i)
        j = i - 1

        Do While j >= LBound(names)
            If StrComp(names(j), temp, vbTextCompare) <= 0 Then Exit Do
            names(j + 1) = names(j)
            j = j - 1
        Loop

        names(j + 1) = temp

    Next i

    TGGetFontNames = names

End Function


'=========================================================
' LETTER OUTLINES
'=========================================================

Private Function OpenFontDC( _
        ByVal fontName As String, _
        ByVal isBold As Boolean, _
        ByVal isItalic As Boolean, _
        ByRef hdc As LongPtr, _
        ByRef hFont As LongPtr, _
        ByRef hOld As LongPtr) As Boolean

    Dim weight As Long
    Dim italicFlag As Long

    OpenFontDC = False

    hdc = CreateCompatibleDC(0)

    If hdc = 0 Then Exit Function

    If isBold Then weight = 700 Else weight = 400
    If isItalic Then italicFlag = 1 Else italicFlag = 0

    ' Character set 1 = default, output precision 7 = TrueType only
    hFont = CreateFontW(-FONT_UNITS, 0, 0, 0, weight, italicFlag, _
        0, 0, 1, 7, 0, 0, 0, StrPtr(fontName))

    If hFont = 0 Then
        DeleteDC hdc
        hdc = 0
        Exit Function
    End If

    hOld = SelectObject(hdc, hFont)

    ' 1 = transparent background, so only the letters are outlined
    SetBkMode hdc, 1

    ' 24 = position letters by their baseline
    SetTextAlign hdc, 24

    OpenFontDC = True

End Function


Private Sub CloseFontDC( _
        ByRef hdc As LongPtr, _
        ByRef hFont As LongPtr, _
        ByRef hOld As LongPtr)

    On Error Resume Next

    If hdc <> 0 Then

        If hOld <> 0 Then SelectObject hdc, hOld
        If hFont <> 0 Then DeleteObject hFont

        DeleteDC hdc

    End If

    hdc = 0
    hFont = 0
    hOld = 0

End Sub


' Reads the outline of one letter as straight line points.
' pointCount is 0 for a space or a letter the font does not have.
Private Sub CharOutline( _
        ByVal hdc As LongPtr, _
        ByVal letter As String, _
        ByRef pts() As POINTAPI, _
        ByRef types() As Byte, _
        ByRef pointCount As Long, _
        ByRef advance As Long)

    Dim sz As SIZEAPI

    pointCount = 0
    advance = 0

    GetTextExtentPoint32W hdc, StrPtr(letter), Len(letter), sz

    advance = sz.cx

    BeginPath hdc
    TextOutW hdc, 0, 0, StrPtr(letter), Len(letter)
    EndPath hdc

    ' Turn curves into short straight lines
    FlattenPath hdc

    pointCount = GetPath(hdc, ByVal 0&, ByVal 0&, 0)

    If pointCount <= 0 Then
        pointCount = 0
        Exit Sub
    End If

    ReDim pts(0 To pointCount - 1)
    ReDim types(0 To pointCount - 1)

    pointCount = GetPath(hdc, pts(0), types(0), pointCount)

    If pointCount < 0 Then pointCount = 0

End Sub

' Whatever was selected before the macro started is used
' as the sketch plane. With nothing selected, the XY plane.
'=========================================================

        ByRef support As Object, _
        ByRef supportName As String) As Boolean

    Dim doc As Object
    Dim sel As Object

    TGGetSupport = False

    Set support = Nothing
    supportName = ""

    On Error Resume Next

    If CATIA.Documents.Count = 0 Then Exit Function

    Set doc = CATIA.ActiveDocument

        supportName = ""
    End If

    Err.Clear

    TGGetSupport = Not (support Is Nothing)

End Function


'=========================================================
' BUILD THE TEXT
' makeSolid = False : draw the sketch only (preview)
' makeSolid = True  : draw the sketch, then pad or pocket it
'=========================================================

Public Function TGBuildText( _
        ByVal textValue As String, _
        ByVal fontName As String, _
        ByVal isBold As Boolean, _
        ByVal isItalic As Boolean, _
        ByVal letterHeight As Double, _
        ByVal spacing As Double, _
        ByVal isRadial As Boolean, _
        ByVal angleDeg As Double, _
        ByVal diameter As Double, _
        ByVal isInside As Boolean, _
        ByVal topsToCenter As Boolean, _
        ByVal posH As Double, _
        ByVal posV As Double, _
        ByVal mirrorText As Boolean, _
        ByVal makeSolid As Boolean, _
        ByVal engrave As Boolean, _
        ByVal depth As Double, _
        ByVal reverseDir As Boolean, _
        ByVal support As Object, _
        ByRef resultMessage As String) As Boolean

    Dim doc As Object
    Dim partObj As Object
    Dim bodyObj As Object
    Dim skt As Object
    Dim fact As Object
    Dim feat As Object

    Dim hdc As LongPtr
    Dim hFont As LongPtr
    Dim hOld As LongPtr

    Dim pts() As POINTAPI
    Dim types() As Byte
    Dim pointCount As Long
    Dim advance As Long

    Dim charCount As Long
    Dim advs() As Double
    Dim letter As String

    Dim capUnits As Double
    Dim sc As Double
    Dim totalW As Double
    Dim pen As Double
    Dim center As Double
    Dim baseRadius As Double
    Dim minDist As Double

    Dim angleRad As Double
    Dim cosA As Double
    Dim sinA As Double
    Dim alpha As Double
    Dim ux As Double
    Dim uy As Double
    Dim tx As Double
    Dim ty As Double
    Dim r As Double

    Dim lx As Double
    Dim ly As Double
    Dim px As Double
    Dim py As Double

    Dim cx() As Double
    Dim cy() As Double
    Dim cn As Long

    Dim lineCount As Long
    Dim i As Long
    Dim k As Long

    Dim stage As Integer
    Dim editing As Boolean
    Dim errText As String

    TGBuildText = False
    stage = 0
    editing = False

    On Error GoTo Failed

    '---------------------------------------
    ' Check the document
    '---------------------------------------

    If CATIA.Documents.Count = 0 Then
        resultMessage = TGTxt("stNoPart")
        Exit Function
    End If

    Set doc = CATIA.ActiveDocument

    If TypeName(doc) <> "PartDocument" Then
        resultMessage = TGTxt("stNoPart")
        Exit Function
    End If

    Set partObj = doc.Part

    charCount = Len(textValue)

    If charCount = 0 Then
        resultMessage = TGTxt("msgNoText")
        Exit Function
    End If

    '---------------------------------------
    ' Open the font and measure it.
    ' The height of a capital H sets the scale, so
    ' "letter height" means the height of capitals.
    '---------------------------------------

    If Not OpenFontDC(fontName, isBold, isItalic, hdc, hFont, hOld) Then
        resultMessage = TGTxt("msgFont")
        Exit Function
    End If

    CharOutline hdc, "H", pts, types, pointCount, advance

    capUnits = 0

    For k = 0 To pointCount - 1
        If -pts(k).y > capUnits Then capUnits = -pts(k).y
    Next k

    If capUnits <= 0 Then
        resultMessage = TGTxt("msgFont")
        GoTo Done
    End If

    sc = letterHeight / capUnits

    minDist = letterHeight * DETAIL

    If minDist < 0.01 Then minDist = 0.01

    ' Width of every letter, and of the whole text, in mm
    ReDim advs(1 To charCount)

    totalW = 0

    For i = 1 To charCount

        letter = Mid$(textValue, i, 1)

        CharOutline hdc, letter, pts, types, pointCount, advance

        advs(i) = advance * sc
        totalW = totalW + advs(i)

    Next i

    totalW = totalW + spacing * (charCount - 1)

    '---------------------------------------
    ' Layout values
    '---------------------------------------

    angleRad = angleDeg * PI / 180#

    If isRadial Then

        ' baseRadius is the radius where the bottoms of the letters sit
        If topsToCenter Then
            If isInside Then
                baseRadius = diameter / 2#
            Else
                baseRadius = diameter / 2# + letterHeight
            End If
        Else
            If isInside Then
                baseRadius = diameter / 2# - letterHeight
            Else
                baseRadius = diameter / 2#
            End If
        End If

        If baseRadius <= 0 Then
            resultMessage = TGTxt("msgTooLong")
            GoTo Done
        End If

        If totalW >= 2# * PI * baseRadius * 0.98 Then
            resultMessage = TGTxt("msgTooLong")
            GoTo Done
        End If

    Else

        cosA = Cos(angleRad)
        sinA = Sin(angleRad)

    End If

    '---------------------------------------
    ' Remove the last preview, then start a new sketch
    '---------------------------------------

    TGDiscardPreview

    Set bodyObj = Nothing

    On Error Resume Next
    If TypeName(partObj.InWorkObject) = "Body" Then
        Set bodyObj = partObj.InWorkObject
    End If
    Err.Clear
    On Error GoTo Failed

    If bodyObj Is Nothing Then Set bodyObj = partObj.MainBody

    stage = 1

    Set skt = bodyObj.Sketches.Add(support)

    stage = 2

    On Error Resume Next
    skt.Name = "Text_" & Left$(textValue, 20)
    Err.Clear
    On Error GoTo Failed

    Set fact = skt.OpenEdition()
    editing = True

    '---------------------------------------
    ' Draw every letter
    '---------------------------------------

    ReDim cx(1 To 256)
    ReDim cy(1 To 256)

    lineCount = 0
    pen = -totalW / 2#

    For i = 1 To charCount

        letter = Mid$(textValue, i, 1)

        ' Middle of this letter, measured along the text from its center
        center = pen + advs(i) / 2#

        If isRadial Then

            ' alpha is the direction from the circle center to the
            ' letter. Angle 0 puts the text at the top of the circle.
            If topsToCenter Then
                alpha = PI / 2# - angleRad + center / baseRadius
            Else
                alpha = PI / 2# - angleRad - center / baseRadius
            End If

            ux = Cos(alpha)
            uy = Sin(alpha)

            If topsToCenter Then
                tx = -uy
                ty = ux
            Else
                tx = uy
                ty = -ux
            End If

        End If

        CharOutline hdc, letter, pts, types, pointCount, advance

        cn = 0

        For k = 0 To pointCount - 1

            ' 6 = start of a new closed shape
            If (types(k) And 6) = 6 Then
                DrawContour fact, cx, cy, cn, minDist, lineCount
                cn = 0
            End If

            ' Letter-local position in mm. Windows measures y downward.
            lx = (pts(k).x - advance / 2#) * sc
            ly = -pts(k).y * sc

            If isRadial Then

                If topsToCenter Then
                    r = baseRadius - ly
                Else
                    r = baseRadius + ly
                End If

                px = r * ux + lx * tx
                py = r * uy + lx * ty

            Else

                lx = lx + center
                ly = ly - letterHeight / 2#

                px = lx * cosA - ly * sinA
                py = lx * sinA + ly * cosA

            End If

            If mirrorText Then px = -px

            AddPoint cx, cy, cn, px + posH, py + posV, minDist

            ' 1 = this point closes the shape
            If (types(k) And 1) = 1 Then
                DrawContour fact, cx, cy, cn, minDist, lineCount
                cn = 0
            End If

        Next k

        DrawContour fact, cx, cy, cn, minDist, lineCount
        cn = 0

        pen = pen + advs(i) + spacing

    Next i

    skt.CloseEdition
    editing = False

    If lineCount = 0 Then
        RemoveFeature doc, skt
        resultMessage = TGTxt("msgNothing")
        GoTo Done
    End If

    '---------------------------------------
    ' Preview: keep the sketch and stop here
    '---------------------------------------

    If Not makeSolid Then

        On Error Resume Next
        partObj.Update
        Err.Clear
        On Error GoTo Failed

        Set mPreviewSketch = skt
        mPreviewDocName = doc.FullName

        resultMessage = TGFmt(TGTxt("msgPreview"), CStr(lineCount))

        TGBuildText = True

        GoTo Done

    End If

    '---------------------------------------
    ' Pad (raised) or pocket (engraved)
    '---------------------------------------

    stage = 3

    On Error Resume Next

    partObj.InWorkObject = bodyObj
    Err.Clear

    If engrave Then
        Set feat = partObj.ShapeFactory.AddNewPocket(skt, depth)
    Else
        Set feat = partObj.ShapeFactory.AddNewPad(skt, depth)
    End If

    If Err.Number = 0 Then

        ' 1 = inverse orientation
        If reverseDir Then feat.DirectionOrientation = 1

    End If

    If Err.Number = 0 Then partObj.Update

    If Err.Number <> 0 Then

        errText = Err.Description
        Err.Clear

        ' Take the failed solid away, but keep the sketch
        If Not feat Is Nothing Then RemoveFeature doc, feat

        partObj.Update
        Err.Clear

        On Error GoTo Failed

        resultMessage = TGFmt(TGTxt("msgSolid"), errText)

        GoTo Done

    End If

    On Error GoTo Failed

    resultMessage = TGFmt(TGTxt("msgDone"), CStr(lineCount))

    TGBuildText = True

Done:

    On Error Resume Next

    If editing Then skt.CloseEdition

    CloseFontDC hdc, hFont, hOld

    Exit Function

Failed:

    If stage = 1 Then
        resultMessage = TGTxt("msgSupport")
    Else
        resultMessage = TGFmt(TGTxt("msgError"), Err.Description)
    End If

    Resume Done

End Function


' Adds a point to the current shape, skipping points that
' are too close to the one before.
Private Sub AddPoint( _
        ByRef cx() As Double, _
        ByRef cy() As Double, _
        ByRef cn As Long, _
        ByVal px As Double, _
        ByVal py As Double, _
        ByVal minDist As Double)

    If cn > 0 Then
        If Abs(px - cx(cn)) < minDist Then
            If Abs(py - cy(cn)) < minDist Then Exit Sub
        End If
    End If

    If cn >= UBound(cx) Then
        ReDim Preserve cx(1 To UBound(cx) * 2)
        ReDim Preserve cy(1 To UBound(cy) * 2)
    End If

    cn = cn + 1

    cx(cn) = px
    cy(cn) = py

End Sub


' Draws one closed shape as lines that share their end points
Private Sub DrawContour( _
        ByVal fact As Object, _
        ByRef cx() As Double, _
        ByRef cy() As Double, _
        ByVal cn As Long, _
        ByVal minDist As Double, _
        ByRef lineCount As Long)

    Dim p() As Object
    Dim ln As Object
    Dim i As Long
    Dim j As Long

    ' The last point often repeats the first one
    Do While cn > 1

        If Abs(cx(cn) - cx(1)) >= minDist Then Exit Do
        If Abs(cy(cn) - cy(1)) >= minDist Then Exit Do

        cn = cn - 1

    Loop

    If cn < 3 Then Exit Sub

    ReDim p(1 To cn)

    For i = 1 To cn
        Set p(i) = fact.CreatePoint(cx(i), cy(i))
    Next i

    For i = 1 To cn

        j = (i Mod cn) + 1

        Set ln = fact.CreateLine(cx(i), cy(i), cx(j), cy(j))

        ln.StartPoint = p(i)
        ln.EndPoint = p(j)

        lineCount = lineCount + 1

    Next i

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function TGLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    TGLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    TGLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

Known limitations

  • The preview box in the window shows the font only. It cannot show the angle or the circle; use Preview in CATIA for that.
  • You cannot rotate or zoom the CATIA view while the window is open, and the plane or face must be selected before the macro starts.
  • Flat planes and flat faces only. Text cannot wrap around a cylinder or other curved surface.
  • Curves are drawn as short straight lines. To make them smoother, lower DETAIL near the top of the module; this adds lines and slows the update.
  • Script and decorative fonts often have overlapping outlines that CATIA will not pad. If that happens, the sketch is kept and the status line shows CATIA's error. Plain fonts such as Arial are the safest.
  • Engraved text needs existing material under the sketch. A pocket in an empty body fails.
  • The text goes into the body that is in work, or the main body if the in-work object is not a body.
  • Letter spacing follows each letter's standard width. Kerning pairs are not applied.
  • Long text makes a heavy sketch. The limit is 100 characters.
  • If the credit image cannot be loaded, the window opens without it.
