CATIA Drawing Batch PDF

Saves the sheets of the active drawing, every open drawing, or every CATDrawing in a folder as PDF, DXF or DWG. Two code blocks to paste: the form and the module.

What it does

  • Three sources. The active drawing, every drawing that is open, or every CATDrawing in a folder you choose.
  • One file per sheet or one per drawing. In per-sheet mode each sheet is activated in turn and saved as DrawingName_SheetName.pdf. Detail sheets are skipped.
  • PDF, DXF or DWG.
  • Save folder is optional. Leave it empty and each file is saved next to its drawing.
  • Optional date in the file name. Existing files with the same name are replaced.
  • English / Korean button in the top right corner. The language is remembered for next time.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with DPdf, so it does not clash with the other macros in the same VBA project.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmDrawingPdf. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. In the Properties window set its (Name) to DrawingPdf, then paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATDrawing (not needed for the folder option), then run CATMain from the DrawingPdf module.

First run: this code was written and checked for structure, but not run inside CATIA. Try it on one drawing with two sheets first and open the PDFs to check what each file contains.

    CATIA.DisplayFileAlerts = True

End Sub

'=========================================================
' EXPORT
'=========================================================

Public Function DPdfRun( _
        ByVal frm As Object, _
        ByVal actionId As Long, _
        ByRef message As String) As Boolean

    Dim drawings As New Collection
    Dim paths As New Collection
    Dim fso As Object
    Dim f As Object
    Dim d As Object
    Dim homeWindow As Object
    Dim outFolder As String
    Dim srcFolder As String
    Dim ext As String
    Dim source As Long
    Dim perSheet As Boolean
    Dim wasOpen As Boolean
    Dim i As Long
    Dim made As Long
    Dim files As Long
    Dim failed As Long
    Dim total As Long

    DPdfRun = False

    outFolder = WithSlash(CtlText(frm, "txtOut"))

    If Len(outFolder) > 0 And Not FolderExists(outFolder) Then
        message = DPdfTxt("msgNoOut")
        Exit Function
    End If

    Select Case CtlIndex(frm, "cboFormat")
        Case 1: ext = "dxf"
        Case 2: ext = "dwg"
        Case Else: ext = "pdf"
    End Select

    perSheet = (CtlIndex(frm, "cboMode") = 0)
    source = CtlIndex(frm, "cboSource")

    On Error Resume Next
    Set homeWindow = CATIA.ActiveWindow
    On Error GoTo 0

    CATIA.DisplayFileAlerts = False

    If source = 2 Then

        '---------------------------------------
        ' Every CATDrawing in a folder
        '---------------------------------------

        srcFolder = WithSlash(CtlText(frm, "txtSource"))

        If Not FolderExists(srcFolder) Then
            message = DPdfTxt("msgNoSrc")
            Exit Function
        End If

        Set fso = CreateObject("Scripting.FileSystemObject")

        For Each f In fso.GetFolder(srcFolder).Files
            If LCase$(fso.GetExtensionName(f.Name)) = "catdrawing" Then paths.Add CStr(f.Path)
        Next f

        total = paths.Count

        For i = 1 To paths.Count

            wasOpen = IsDocOpen(FileNameOf(CStr(paths.Item(i))))

            Set d = OpenDrawing(CStr(paths.Item(i)))

            made = 0

            If Not d Is Nothing Then
                made = ExportDrawing(d, outFolder, ext, perSheet, frm)
                If Not wasOpen Then CloseQuietly d
            End If

            If made > 0 Then
                files = files + made
            Else
                failed = failed + 1
            End If

        Next i

    Else

        '---------------------------------------
        ' Active drawing, or every open drawing
        '---------------------------------------

        If source = 1 Then

            For i = 1 To CATIA.Documents.Count
                If TypeName(CATIA.Documents.Item(i)) = "DrawingDocument" Then drawings.Add CATIA.Documents.Item(i)
            Next i

        ElseIf DPdfDocKind() = "Drawing" Then

            drawings.Add CATIA.ActiveDocument

        Else

            message = DPdfTxt("msgNeedDoc")
            Exit Function

        End If

        total = drawings.Count

        For i = 1 To drawings.Count

            Set d = drawings.Item(i)

            made = ExportDrawing(d, outFolder, ext, perSheet, frm)

            If made > 0 Then
                files = files + made
            Else
                failed = failed + 1
            End If

        Next i

    End If

    CATIA.DisplayFileAlerts = True

    On Error Resume Next
    homeWindow.Activate
    On Error GoTo 0

    If total = 0 Then
        message = DPdfTxt("msgNothing")
        Exit Function
    End If

    message = DPdfFmt(DPdfTxt("msgDone"), CStr(files), CStr(total), CStr(failed))

    DPdfRun = True

End Function

' Saves one drawing. Returns the number of files written.
Private Function ExportDrawing( _
        ByVal d As Object, _
        ByVal outFolder As String, _
        ByVal ext As String, _
        ByVal perSheet As Boolean, _
        ByVal frm As Object) As Long

    Dim sheets As Object
    Dim sh As Object
    Dim keep As Object
    Dim saveFolder As String
    Dim baseName As String
    Dim target As String
    Dim i As Long
    Dim made As Long

    On Error GoTo Failed

    saveFolder = outFolder

    If Len(saveFolder) = 0 Then saveFolder = WithSlash(d.Path)

    ' A drawing that was never saved has no folder of its own
    If Len(saveFolder) = 0 Then Exit Function

    baseName = CleanName(StripExt(d.Name))

    If CtlOn(frm, "chkDate") Then baseName = baseName & "_" & Format$(Date, "yyyymmdd")

    d.Activate

    Set sheets = d.Sheets

    If perSheet Then

        Set keep = sheets.ActiveSheet

        For i = 1 To sheets.Count

            Set sh = sheets.Item(i)

            If Not sh.IsDetail Then

                sh.Activate

                target = saveFolder & baseName & "_" & CleanName(sh.Name) & "." & ext

                Say frm, DPdfTxt("stItem") & " " & FileNameOf(target)

                DeleteFile target

                d.ExportData target, ext

                If FileExists(target) Then made = made + 1

            End If

        Next i

        keep.Activate

    Else

        target = saveFolder & baseName & "." & ext

        Say frm, DPdfTxt("stItem") & " " & FileNameOf(target)

        DeleteFile target

        d.ExportData target, ext

        If FileExists(target) Then made = made + 1

    End If

    ExportDrawing = made

    Exit Function

Failed:

    ExportDrawing = made

End Function

' "" = nothing open, otherwise Product, Part, Drawing or Other
Public Function DPdfDocKind() As String

    Dim t As String

    On Error Resume Next

    If CATIA.Documents.Count > 0 Then t = TypeName(CATIA.ActiveDocument)

    On Error GoTo 0

    Select Case t
        Case "ProductDocument": DPdfDocKind = "Product"
        Case "PartDocument": DPdfDocKind = "Part"
        Case "DrawingDocument": DPdfDocKind = "Drawing"
        Case "": DPdfDocKind = ""
        Case Else: DPdfDocKind = "Other"
    End Select

End Function

' Replaces characters that are not allowed in a file name
Private Function CleanName(ByVal rawName As String) As String

    Dim i As Long
    Dim ch As String
    Dim code As Long
    Dim result As String

    For i = 1 To Len(rawName)

        ch = Mid$(rawName, i, 1)
        code = AscW(ch)

        If InStr("\/:*?""<>|", ch) > 0 Or (code >= 0 And code < 32) Then
            result = result & "_"
        Else
            result = result & ch
        End If

    Next i

    If Len(result) = 0 Then result = "Unnamed"

    CleanName = result

End Function


Private Function StripExt(ByVal fileName As String) As String

    Dim p As Long

    p = InStrRev(fileName, ".")

    If p > 1 Then
        StripExt = Left$(fileName, p - 1)
    Else
        StripExt = fileName
    End If

End Function

' Splits one CSV line into its fields
Private Function CsvSplit(ByVal lineText As String) As Collection

    Dim fields As New Collection
    Dim i As Long
    Dim ch As String
    Dim cur As String
    Dim inQuotes As Boolean

    i = 1

    Do While i <= Len(lineText)

        ch = Mid$(lineText, i, 1)

        If inQuotes Then
            If ch = """" Then
                If Mid$(lineText, i + 1, 1) = """" Then
                    cur = cur & """"
                    i = i + 1
                Else
                    inQuotes = False
                End If
            Else
                cur = cur & ch
            End If
        ElseIf ch = """" Then
            inQuotes = True
        ElseIf ch = "," Then
            fields.Add cur
            cur = ""
        Else
            cur = cur & ch
        End If

        i = i + 1

    Loop

    fields.Add cur

    Set CsvSplit = fields

End Function

' Fills docs (a Dictionary) with every loaded document under prod
Private Sub CollectDocs( _
        ByVal prod As Object, _
        ByVal docs As Object, _
        ByVal wantParts As Boolean, _
        ByVal wantProducts As Boolean)

    Dim kids As Object
    Dim child As Object
    Dim d As Object
    Dim kind As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set d = DocOf(child)

        If Not d Is Nothing Then

            kind = TypeName(d)

            If kind = "PartDocument" And wantParts Then AddDoc docs, d
            If kind = "ProductDocument" And wantProducts Then AddDoc docs, d

            CollectDocs child, docs, wantParts, wantProducts

        End If

    Next i

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

' The form shows it with:
'     DPdfLoadLogo Me.Controls("imgLogo")

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function DPdfLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    DPdfLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    DPdfLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

Known limitations

  • Whether a PDF holds one sheet or all sheets depends on a CATIA option: Tools, Options, General, Compatibility, Graphics Formats, "Save multi-sheet document in a single vectorial file". For one file per sheet, leave it unticked. For one file per drawing with all sheets, tick it. The macro does not change this option.
  • Drawings that were never saved are skipped unless you choose a save folder.
  • In folder mode, files in sub-folders are not included, and drawings are opened one by one, which loads their linked parts if CATIA is set to do so.
  • The PDFs are separate files. Merging several PDFs into one needs a PDF tool outside CATIA.
  • The window is modal, so CATIA cannot be clicked while it is open. Anything that must be selected in CATIA has to be selected before running the macro.
  • If the credit image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
Prepared for CATIA V5 R21 and later, VBA. Saves drawing sheets to PDF, DXF or DWG in one run.
