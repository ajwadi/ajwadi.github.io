CATIA Balloon and BOM Checker

Reads every balloon on a drawing sheet and compares the numbers with the items of the bill of material: items with no balloon, balloons with no item, repeated numbers and balloons that are not numbers. Two code blocks to paste: the form and the module.

What it does

  • Missing balloons. Every item number from 1 to the number of BOM items that has no balloon is listed.
  • Balloons with no item. A balloon number higher than the number of BOM items is listed.
  • Repeated numbers and balloons whose text is not a number are listed as well.
  • The number of BOM items is counted from the assembly shown on the sheet (the different parts directly under it), or you can type it.
  • Active sheet or every sheet. Results go to a list, and Export CSV saves them as DrawingName_Balloons.csv.
  • English / Korean button in the top right corner. The language is remembered for next time.
  • Credit image centered at the bottom, stored inside the module as text, the same as your other macros.
  • Works beside your other macros. Every shared name starts with Bal, so it does not clash with the other macros in the same VBA project.

Setup

  1. In the VBA editor, use Insert, UserForm. In the Properties window set its (Name) to frmBalloonChecker. Leave the form empty in the designer.
  2. Open the form's code (right-click the form, View Code), select all, delete, and paste the Form code below.
  3. Use Insert, Module. In the Properties window set its (Name) to BalloonChecker, then paste the Module code below.
  4. Use Debug, Compile VBAProject.
  5. Open a CATDrawing, then run CATMain from the BalloonChecker module and click Run Check.

First run: this code was written and checked for structure, but not run inside CATIA. Try it on a drawing where you know one balloon is missing, and check that the summary row counts the balloons correctly.

BalloonChecker

The long block of letters and numbers at the bottom is the credit image. Do not edit it.

Option Explicit

' CATIA BALLOON AND BOM CHECKER - MAIN MODULE
' Module name: BalloonChecker
' Run CATMain to open the window.
'=========================================================

Private Const REG_APP As String = "CatiaBalloonChecker"
Private Const REG_SEC As String = "Settings"

' "EN" or "KO"
Public gBalLang As String

Private mRows As Collection


'=========================================================
' ENTRY POINT
'=========================================================

Sub CATMain()

    BalLoadLanguage
    frmBalloonChecker.Show

End Sub

'=========================================================
' BUTTONS
' 1 = Run Check, 2 = Export CSV
'=========================================================

Public Function BalRun( _
        ByVal frm As Object, _
        ByVal actionId As Long, _
        ByRef message As String) As Boolean

    Dim d As Object
    Dim sheets As Object
    Dim sheet As Object
    Dim countText As String
    Dim typedCount As Long
    Dim byLeader As Boolean
    Dim i As Long

    BalRun = False

    If actionId = 2 Then
        BalRun = ExportIssues(frm, "_Balloons", message)
        Exit Function
    End If

    countText = CtlText(frm, "txtCount")
    typedCount = -1

    If Len(countText) > 0 Then

        If Not IsWholeNumber(countText) Or Len(countText) > 6 Then
            message = BalTxt("msgBadCount")
            Exit Function
        End If

        typedCount = CLng(countText)

    End If

    byLeader = (CtlIndex(frm, "cboDetect") = 1)

    Set d = CATIA.ActiveDocument
    Set sheets = d.Sheets
    Set mRows = New Collection

    frm.Controls("lstRows").Clear

    If CtlIndex(frm, "cboSheets") = 1 Then

        For i = 1 To sheets.Count

            Set sheet = sheets.Item(i)

            If Not IsDetailSheet(sheet) Then CheckSheet frm, sheet, typedCount, byLeader

        Next i

    Else

        CheckSheet frm, sheets.ActiveSheet, typedCount, byLeader

    End If

    message = BalFmt(BalTxt("msgDone"), CStr(mRows.Count))

    BalRun = True

End Function


Private Function IsDetailSheet(ByVal sheet As Object) As Boolean

    On Error Resume Next

    IsDetailSheet = sheet.IsDetail

End Function


Private Function IsWholeNumber(ByVal textValue As String) As Boolean

    Dim i As Long

    If Len(textValue) = 0 Then Exit Function

    For i = 1 To Len(textValue)
        If InStr("0123456789", Mid$(textValue, i, 1)) = 0 Then Exit Function
    Next i

    IsWholeNumber = True

End Function


'=========================================================
' ONE SHEET
'=========================================================

Private Sub CheckSheet( _
        ByVal frm As Object, _
        ByVal sheet As Object, _
        ByVal typedCount As Long, _
        ByVal byLeader As Boolean)

    Dim views As Object
    Dim view As Object
    Dim texts As Object
    Dim t As Object
    Dim used As Object
    Dim keys As Variant
    Dim sheetName As String
    Dim content As String
    Dim expected As Long
    Dim balloons As Long
    Dim number As Long
    Dim i As Long
    Dim j As Long

    sheetName = sheet.Name

    Say frm, BalTxt("stItem") & " " & sheetName

    Set used = CreateObject("Scripting.Dictionary")
    Set views = sheet.Views

    For i = 1 To views.Count

        Set view = views.Item(i)
        Set texts = Nothing

        On Error Resume Next
        Set texts = view.Texts
        On Error GoTo 0

        If Not texts Is Nothing Then

            For j = 1 To texts.Count

                Set t = texts.Item(j)

                If IsBalloon(t, byLeader) Then

                    content = Trim$(t.Text)

                    balloons = balloons + 1

                    If IsWholeNumber(content) And Len(content) <= 6 Then

                        number = CLng(content)

                        If used.Exists(number) Then
                            used.Item(number) = used.Item(number) + 1
                        Else
                            used.Add number, 1
                        End If

                    Else

                        AddIssue frm, BalTxt("kText"), sheetName, BalFmt(BalTxt("dText"), content, view.Name)

                    End If

                End If

            Next j

        End If

    Next i

    ' How many items the bill of material should have
    expected = typedCount

    If expected < 0 Then expected = CountBomItems(sheet)

    If expected <= 0 Then

        AddIssue frm, BalTxt("kInfo"), sheetName, BalFmt(BalTxt("dNoCount"), CStr(balloons))

    Else

        AddIssue frm, BalTxt("kInfo"), sheetName, BalFmt(BalTxt("dInfo"), CStr(balloons), CStr(expected))

        For i = 1 To expected
            If Not used.Exists(i) Then AddIssue frm, BalTxt("kMissing"), sheetName, BalFmt(BalTxt("dMissing"), CStr(i))
        Next i

    End If

    keys = used.Keys

    For i = 0 To used.Count - 1

        number = CLng(keys(i))

        If expected > 0 And (number > expected Or number < 1) Then
            AddIssue frm, BalTxt("kExtra"), sheetName, BalFmt(BalTxt("dExtra"), CStr(number), CStr(expected))
        End If

        If CLng(used.Item(keys(i))) > 1 Then
            AddIssue frm, BalTxt("kRepeat"), sheetName, BalFmt(BalTxt("dRepeat"), CStr(number), CStr(used.Item(keys(i))))
        End If

    Next i

End Sub


' Decides whether a drawing text is a balloon
Private Function IsBalloon(ByVal t As Object, ByVal byLeader As Boolean) As Boolean

    Dim frameType As Long
    Dim leaderCount As Long

    On Error Resume Next

    If byLeader Then

        leaderCount = t.Leaders.Count

        If leaderCount > 0 Then IsBalloon = IsWholeNumber(Trim$(t.Text))

    Else

        ' CATIA frame types: 3 = circle, 4 = scored circle
        frameType = 0
        frameType = t.FrameType

        IsBalloon = (frameType = 3 Or frameType = 4)

    End If

End Function


' Number of different parts directly under the assembly shown
' on the sheet. This is how many numbered items CATIA creates.
Private Function CountBomItems(ByVal sheet As Object) As Long

    Dim src As Object
    Dim kids As Object
    Dim rp As Object
    Dim numbers As Object
    Dim key As String
    Dim i As Long

    Set src = LinkedProduct(sheet)

    If src Is Nothing Then Exit Function

    On Error Resume Next
    Set kids = src.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Function

    Set numbers = CreateObject("Scripting.Dictionary")

    For i = 1 To kids.Count

        Set rp = RefOf(kids.Item(i))

        If Not rp Is Nothing Then

            key = UCase$(rp.PartNumber)

            If Not numbers.Exists(key) Then numbers.Add key, 1

        End If

    Next i

    CountBomItems = numbers.Count

End Function


' The assembly shown by the first generated view of the sheet
Private Function LinkedProduct(ByVal sheet As Object) As Object

    Dim views As Object
    Dim obj As Object
    Dim i As Long

    On Error Resume Next

    Set views = sheet.Views

    If views Is Nothing Then Exit Function

    ' Views 1 and 2 are the main view and the background view
    For i = 3 To views.Count

        Set obj = Nothing
        Set obj = views.Item(i).GenerativeBehavior.Document

        If Not obj Is Nothing Then

            If TypeName(obj) = "Product" Then

                Set LinkedProduct = obj.ReferenceProduct

                If LinkedProduct Is Nothing Then Set LinkedProduct = obj

                Exit Function

            End If

        End If

    Next i

End Function

' Saves the list as a CSV file
Private Function ExportIssues( _
        ByVal frm As Object, _
        ByVal fileTag As String, _
        ByRef message As String) As Boolean

    Dim outFolder As String
    Dim target As String
    Dim content As String
    Dim rowData As Variant
    Dim i As Long

    ExportIssues = False

    If mRows Is Nothing Then
        message = BalTxt("msgRunFirst")
        Exit Function
    End If

    outFolder = WithSlash(CtlText(frm, "txtOut"))

    If Not FolderExists(outFolder) Then
        message = BalTxt("msgNoOut")
        Exit Function
    End If

    content = Csv(BalTxt("hCheck")) & "," & Csv(BalTxt("hWhere")) & "," & Csv(BalTxt("hDetail")) & vbCrLf

    For i = 1 To mRows.Count
        rowData = mRows.Item(i)
        content = content & Csv(CStr(rowData(0))) & "," & Csv(CStr(rowData(1))) & "," & Csv(CStr(rowData(2))) & vbCrLf
    Next i

    target = outFolder & CleanName(StripExt(BalDocName())) & fileTag & ".csv"

    If Not WriteTextFile(target, content) Then
        message = BalTxt("msgWriteFail")
        Exit Function
    End If

    OpenFile target

    message = BalFmt(BalTxt("msgExported"), CStr(mRows.Count), target)

    ExportIssues = True

End Function

' "" = nothing open, otherwise Product, Part, Drawing or Other
Public Function BalDocKind() As String

    Dim t As String

    On Error Resume Next

    If CATIA.Documents.Count > 0 Then t = TypeName(CATIA.ActiveDocument)

    On Error GoTo 0

    Select Case t
        Case "ProductDocument": BalDocKind = "Product"
        Case "PartDocument": BalDocKind = "Part"
        Case "DrawingDocument": BalDocKind = "Drawing"
        Case "": BalDocKind = ""
        Case Else: BalDocKind = "Other"
    End Select

End Function

' Replaces characters that are not allowed in a file name
Private Function CleanName(ByVal rawName As String) As String

    Dim i As Long
    Dim ch As String
    Dim code As Long
    Dim result As String

    For i = 1 To Len(rawName)

        ch = Mid$(rawName, i, 1)
        code = AscW(ch)

        If InStr("\/:*?""<>|", ch) > 0 Or (code >= 0 And code < 32) Then
            result = result & "_"
        Else
            result = result & ch
        End If

    Next i

    If Len(result) = 0 Then result = "Unnamed"

    CleanName = result

End Function


Private Function StripExt(ByVal fileName As String) As String

    Dim p As Long

    p = InStrRev(fileName, ".")

    If p > 1 Then
        StripExt = Left$(fileName, p - 1)
    Else
        StripExt = fileName
    End If

End Function

' A number written with a decimal point on every PC
Private Function Num(ByVal numberValue As Variant, Optional ByVal decimals As Long = 3) As String

    Dim pattern As String

    On Error Resume Next

    pattern = "0"

    If decimals > 0 Then pattern = "0." & String$(decimals, "0")

    Num = Replace(Format$(CDbl(numberValue), pattern), ",", ".")

End Function


' Saves text as UTF-8 so Excel shows Korean correctly
Private Function WriteTextFile(ByVal filePath As String, ByVal content As String) As Boolean

    Dim stm As Object

    On Error GoTo Failed

    Set stm = CreateObject("ADODB.Stream")

    stm.Type = 2
    stm.Charset = "utf-8"
    stm.Open
    stm.WriteText content
    stm.SaveToFile filePath, 2
    stm.Close

    WriteTextFile = True

    Exit Function

Failed:

    On Error Resume Next
    stm.Close

End Function


Private Function ReadTextFile(ByVal filePath As String) As String

    Dim stm As Object

    On Error GoTo Failed

    Set stm = CreateObject("ADODB.Stream")

    stm.Type = 2
    stm.Charset = "utf-8"
    stm.Open
    stm.LoadFromFile filePath

    ReadTextFile = stm.ReadText

    stm.Close

    Exit Function

Failed:

    On Error Resume Next
    stm.Close

End Function


' Splits one CSV line into its fields
Private Function CsvSplit(ByVal lineText As String) As Collection

    Dim fields As New Collection
    Dim i As Long
    Dim ch As String
    Dim cur As String
    Dim inQuotes As Boolean

    i = 1

    Do While i <= Len(lineText)

        ch = Mid$(lineText, i, 1)

        If inQuotes Then
            If ch = """" Then
                If Mid$(lineText, i + 1, 1) = """" Then
                    cur = cur & """"
                    i = i + 1
                Else
                    inQuotes = False
                End If
            Else
                cur = cur & ch
            End If
        ElseIf ch = """" Then
            inQuotes = True
        ElseIf ch = "," Then
            fields.Add cur
            cur = ""
        Else
            cur = cur & ch
        End If

        i = i + 1

Private Sub AddDoc(ByVal docs As Object, ByVal d As Object)

    Dim key As String

    key = UCase$(d.FullName)

    If Not docs.Exists(key) Then docs.Add key, d

End Sub


' Fills docs (a Dictionary) with every loaded document under prod
Private Sub CollectDocs( _
        ByVal prod As Object, _
        ByVal docs As Object, _
        ByVal wantParts As Boolean, _
        ByVal wantProducts As Boolean)

    Dim kids As Object
    Dim child As Object
    Dim d As Object
    Dim kind As String
    Dim i As Long

    On Error Resume Next
    Set kids = prod.Products
    On Error GoTo 0

    If kids Is Nothing Then Exit Sub

    For i = 1 To kids.Count

        Set child = kids.Item(i)
        Set d = DocOf(child)

        If Not d Is Nothing Then

            kind = TypeName(d)

            If kind = "PartDocument" And wantParts Then AddDoc docs, d
            If kind = "ProductDocument" And wantProducts Then AddDoc docs, d

            CollectDocs child, docs, wantParts, wantProducts

        End If

    Next i

End Sub

' Turns \uXXXX codes into real characters
Private Function U(ByVal coded As String) As String

    Dim i As Long
    Dim result As String

    i = 1

    Do While i <= Len(coded)

        If Mid$(coded, i, 2) = "\u" And i + 5 <= Len(coded) Then
            result = result & ChrW$(CLng("&H" & Mid$(coded, i + 2, 4)))
            i = i + 6
        Else
            result = result & Mid$(coded, i, 1)
            i = i + 1
        End If

    Loop

    U = result

End Function

' The form shows it with:
'     BalLoadLogo Me.Controls("imgLogo")

' Puts the logo into an Image control.
' Returns False if the picture could not be loaded.
Public Function BalLoadLogo(ByVal target As Object) As Boolean

    Dim data() As Byte
    Dim filePath As String
    Dim fileNo As Integer

    BalLoadLogo = False

    On Error GoTo Failed

    data = HexToBytes(LogoHex())

    ' VBA can only load a picture from a file, so the data is
    ' written to the Windows temp folder, loaded, then deleted.
    filePath = Environ$("TEMP") & "\catia_macro_logo.gif"

    If Len(Dir$(filePath)) > 0 Then Kill filePath

    fileNo = FreeFile

    Open filePath For Binary Access Write As #fileNo
    Put #fileNo, , data
    Close #fileNo

    Set target.Picture = LoadPicture(filePath)

    BalLoadLogo = True

    On Error Resume Next
    Kill filePath

    Exit Function

Failed:

    On Error Resume Next
    Close #fileNo

End Function


' Turns pairs of hex characters back into bytes
Private Function HexToBytes(ByVal hexText As String) As Byte()

    Dim count As Long
    Dim i As Long
    Dim data() As Byte

    count = Len(hexText) \ 2

    ReDim data(0 To count - 1)

    For i = 0 To count - 1
        data(i) = CByte("&H" & Mid$(hexText, i * 2 + 1, 2))
    Next i

    HexToBytes = data

End Function

{0}, {1} and {2} are filled in with numbers, names and error details. The window title bar stays in English in both languages.

Known limitations

  • CATIA does not expose the bill of material numbering to macros, so the check compares against the numbers 1 to N, where N is the number of BOM items. It cannot tell whether balloon 3 points at the right part.
  • N is counted as the different parts directly under the assembly, which is how CATIA numbers a one-level bill of material. For a multi-level BOM or a custom numbering, type the number yourself.
  • A balloon is recognised as a text with a circle frame. If your balloons use another frame, choose "Any number with a leader line", which also picks up other numbered notes that have a leader.
  • A repeated number is listed for information. The same part shown in two views is often ballooned twice on purpose.
  • Balloons inside 2D components (detail instances) are not read.
  • The macro only reports. It does not change the drawing.
  • The window is modal, so CATIA cannot be clicked while it is open. Anything that must be selected in CATIA has to be selected before running the macro.
  • If the credit image cannot be loaded, for example when the Windows temp folder is not writable, the window opens without it.
Prepared for CATIA V5 R21 and later, VBA. Compares drawing balloons with bill of material items.
